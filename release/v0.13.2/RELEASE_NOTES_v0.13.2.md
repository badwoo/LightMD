## 二、版本内容

### 2.1 新增功能

**0.13.0 块级交互**

- 🖱 **单击即编辑** — 代码块 / 块级公式 / Mermaid 图 / 表格单元格点一次直接进入编辑，不再「先激活块、再点一次」
- ⋮⋮ **常驻手柄与三点菜单** — 悬停块、光标在块内、整块选中时，左侧拖拽手柄与右上角 `⋮` 同时出现（仅代码块 / Mermaid / 公式 / 表格 / 含图片段落，正文不冒手柄）
- ⋮ **三点菜单 8 项** — 剪切 / 复制 / 粘贴 / 删除该块 / 格式刷 / 选中该块 / 移动到上方 / 移动到下方；空剪贴板与首末块自动置灰
- 📋 **块级复制 / 剪切** — 剪贴板同时写 Markdown 源码、渲染 HTML、LightMD 专用数据三份，粘回阅读模式精确还原块结构
- ↩️ **一次撤销** — 剪切 / 删除 / 移动 / 图片拖拽调整大小都是「一次操作 = 一次 `Ctrl+Z`」，删空文档自动补空段落

**0.13.0 数据安全**

- 🛡 **自动保存写盘前三路比对** — 写盘前先读盘：等于自身上次写入则正常保存、等于待写内容则跳过、第三方改过则**放弃写盘**并提示；读盘失败绝不写盘
- ⚙️ **外部修改处理策略** — 设置新增三选一：仅提示 / 三选一（取最新 · 保留本地 · 另存为）/ 每次询问
- 📁 **单文件也能刷新** — 不在任何已打开文件夹里的文件，挂父目录 watcher 兜底

**0.13.0 效率与呈现**

- 🖼 **图片左 / 中 / 右对齐** — `![alt|center](src)` 后缀存盘，预览与全部导出格式生效
- 📋 **代码块复制按钮** — 复制纯代码（不含行号与语言名），成功变 ✓ 1.5 秒
- ⚡ **`Ctrl+P` 快速切换文件** — 已打开标签 / 最近文件 / 工作区文件分组，子序列模糊匹配与命中高亮
- 📑 **大纲标题折叠** — 有子级的标题前 ▾，420ms 平滑动画，搜索时忽略折叠
- 🗒 **`Ctrl+/` 批量注释** — 选中多行（可跨块）置灰加删除线，无选区时切换当前块；六种导出格式都不输出注释内容
- 🏷 **块级源码标记补全** — 列表 / 任务列表 / 水平线 / 公式 / `[toc]` / Mermaid 显示对应符号，绝对定位零位移
- 😄 **Emoji 短码补全** — `:` + 字母弹候选（约 1900 条懒加载），存盘仍是短码
- 🗂 **图片管理面板** — 按文档顺序逐次列图、base64 ↔ assets 互转、重命名同步全部引用、清理未引用走回收站（仅当前文档）
- 📊 **表格单元格合并 / 拆分** — 拖拽跨格选矩形，横向 `colspan` 与纵向 `rowspan` 均支持

**0.13.1 / 0.13.2 打磨**

- 🧲 **分屏双向块映射** — 左右任一侧滚动，另一侧把对应顶层块对齐到顶部，250ms 方向锁避免互推回弹
- 🖼 **图片交互重做** — 点图 = 选中激活，右上角手柄进编辑，拖四边 / 四角调宽（只记宽度、一次拖拽 = 一次撤销）
- 🪄 **图片管理弹窗动效** — 从图标位置缩放展开、可拖拽移动、关闭缩回图标、背景不变暗
- 🎯 **大纲跟随与记忆** — 标题滚入屏幕任意位置即跟随，大纲滚动位置按文档记忆（重启保留）
- 🧩 **表格后可直接续写** — 文档以表格 / 代码块 / 公式 / Mermaid 结尾时自动补可落光标的空段落，且**不写进 `.md`**
- ⌨️ **列表内 `Ctrl+T`** — 把当前行提升为任务项并保留原序号（`- [ ] 2. 原文`）

## 四、已知范围

- **合并单元格仅 LightMD 自身可读**：合并信息以格内嵌 HTML `<td colspan>` / `rowspan` 承载，其它编辑器会显示字面文本；导出 DOCX / LaTeX 保留内容但不保留合并视觉。
- **图片对齐后缀跨编辑器不保真**：`![alt|center](src)` 在外部分编辑器中会作为 alt 文本的一部分显示。
- **合并只保留左上格内容**：被合并格的内容丢弃（与 Typora / Word 一致），拆分可恢复结构但不恢复内容。
- **补位空段落不落盘**：表格 / 代码块 / 公式 / Mermaid 后的补位段落不写进文件；自己打的尾随空行照常保存。
- **图片管理作用域限于当前文档**：「未引用」只表示本文档没引用，不代表其它文档未使用。
- 未支持功能清单不变（跨文件全文搜索、标签、frontmatter、双链 / 反链 / 图谱、书签、Git 集成、代码块只读切换等，详见 README）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）、窗口大小、大纲滚动位置等本地数据全部保留。
- **块交互习惯改变**：单击块现在是「直接编辑」，不再是「先选中」。需要整块选中 / 移动时用三点菜单、`Esc` 或双击。
- **图片交互改变**：点图片为选中，编辑请点右上角小手柄；拖图片四边 / 四角可调整大小。
- **表格文件形态**：不含合并格的表格保存后与旧版逐字节一致；含合并的表格首次保存会写入 `<td colspan>`，请勿再用不支持该写法的工具二次编辑后回存。
- **自动保存更保守**：检测到第三方改过磁盘时不会写盘，需要按 `Ctrl+S` 自行选择覆盖或另存为；没有外部改动时不会有任何提示。
