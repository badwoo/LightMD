## 二、版本内容

本版共 **42 项新增与修复**，分六个批次（B1~B6）。原计划中的 **B4-2（大纲三模式跳转）** 与 **B4-6（分屏预览内搜索）** 经确认取消，不计入。

### 2.1 P0 数据安全（B1）

- **代码块 / 公式块内 Shift+Enter 不再腰斩块结构** —— 此前会把 `code_block` 拆成两块并把剩余内容降级为段落写回磁盘（存盘变成 ```` ```js ```` 块 + 空段落），代码高亮失效、内容被改写。现复用 `inCodeLikeBlock` 判定交回默认键盘处理，并补 IME 组合态守卫（中文输入法候选确认时不再误触破坏性操作）。
- **表格「删除行」作用于表头不再丢数据** —— 此前删的是整个 `table_head`，而 schema 允许无表头，序列化又把数据首行当表头输出，实测 `| A | B |` 被删后变成 `| 1 | 2 |`，**A/B 永久消失**。现三重防线：`deleteRow` 在表头返回 null（拒绝）、工具栏按钮置灰并说明、序列化在无表头时补空表头行而不把数据行顶上去。
- **图片 Typora 尺寸语法 `![alt|300](a.png)` 全链路生效** —— 此前宽度逻辑只存在于编辑器解析层，分屏预览与导出（HTML/PDF/PNG）走的 markdown-it 不识别 → 宽度丢失**且 alt 被污染成 `alt|300`**。现于渲染管线补 inline 规则，宽度输出为 `width` 属性、alt 保持纯净。

### 2.2 导出保真（B2）

- **导出 HTML 真正自包含、可离线** —— 此前实现从 Tauri `resourceDir` 读 vendor 资源，但 `public/vendor` 经 Vite 进 dist 由 webview 源提供、且未配置 `bundle.resources` → 该路径恒失败、**静默回退 jsdelivr CDN**，离线/内网打开公式与图表全空白且无任何提示。现改为经应用自身 webview 源读取（开发态与打包态同一条真实路径），KaTeX（CSS/JS/字体 base64）全内联、mermaid 旁置 `_assets/mermaid.min.js`；读不到资源时**明确提示**已回退 CDN 及离线后果。
  > ⚠️ 代价：含公式的导出 HTML 约 600KB+；mermaid 需与 `_assets/` 目录一起拷贝才能显示图表。
- **PDF 页眉页脚每页齐全** —— 此前用 CSS margin box（`@page { @top-center }`），被 Chromium `--print-to-pdf` 静默忽略，属"看似可选、实则无效"。现改用 `position:fixed` 常规元素；**并修掉引入的偏移问题**：负偏移会让页眉在末页丢失、页脚在首页丢失，且短文档多出一页空白页（实测 29 页文档 28/29、4 段文档 1 页变 2 页），改为零偏移后恢复 29/29 且页数等于基线。
- **PDF 不再泄漏内部临时路径与页码** —— `--print-to-pdf-no-header` 在 Edge 154 上完全无效（加/不加输出字节一致），每页都印着日期、`file:///C:/Users/.../Temp/lightmd-export/export_temp.html` 与页码 `N/M`。改用生效的 `--no-pdf-header-footer`。
- **PNG 导出公式字体正确** —— `html-to-image` 此前 `skipFonts:true` 导致公式丢失 web 字体；现显式提供内联字体 CSS，公式字形正确（已目视确认 ∑/上下限/分式均正常）。
- **DOCX 不再丢内容** —— 补齐任务列表与定义列表（此前落 `default` 分支被整段静默丢弃）；图片恢复为 `ImageRun`（含相对路径解析，此前 `![图](assets/img.png)` 退化为 `[图片: alt]`）；有序列表起始序号保留（`5. x` 不再从 1 开始）；行内公式与块级统一渲染为图片（此前输出 LaTeX 源码）；表格保留行内格式并应用列对齐（此前表头被无条件加粗、单元格只取纯文本）。未识别内容改为**显式提示**而非静默丢弃。
- **LaTeX / EPUB 修正** —— LaTeX 转义与表格列宽计算；EPUB 目录支持 h3+ 分层、`nav.xhtml` 引入样式表、已完成任务项正确显示删除线。

### 2.3 编辑一致性（B3）

- **命令面板补齐 7 条格式命令**（标题 4-6 / 正文 / 无序列表 / 有序列表 / 引用）—— 此前只有回落路由、面板没有条目，属不可达配置；「正文（移除标题）」在源码模式也不再是空操作。
- **源码模式 `Ctrl+Shift+8 / 9 / .` 真正可用** —— 此前只改了快捷键 scope、漏了 id→action 映射，按键后完全无反应（死键）。
- **`~` / `^` 仅在真能配对时转义** —— 此前按"出现 ≥2 次"判定，导致 `x^2 + y^2`、`a ~ b ~ c` 被凭空加上反斜杠、每次编辑重现 git diff 噪音。现按子/上标插件的真实配对规则（分隔符间非空且无未转义空白）判定，且判定以整段行内文本为上下文，兼顾跨节点配对。
- **有序列表 `1)` 双向对称** —— 可输入、编辑后不再被改写成 `1.`；起始序号与分隔符同时保留。
- **`Alt+↑/↓` 改为真正的块移动** —— 此前绑的是 `joinUp`/`lift`（合并/提升），与 UI 宣称的「移动块」语义完全不符；原语义移至 `Alt+Shift+↑/↓`，能力不丢失。
- 脚注标签动态取号（连续插入不再产生重复 `[^1]`）；命令面板解锁 `format.math` 等死键。

### 2.4 阅读体验（B4）

- **字号/字体与三项排版设置真实生效**（内容宽度 / 行高 / 段间距），此前只作用于编辑区元素、分屏预览读的是 `:root` 而回退默认值。
- **标题锚点可用**：锚点 id 提升为标题节点属性，阅读模式下 `[链接](#标题)` 可正常跳转（此前只在分屏/导出生效），跳转后留出顶部余量不被贴顶遮挡；重名标题去重口径与渲染层统一（修掉 `-1` 与 `-2` 不一致导致 TOC 点击跳不过去的问题）。
- **主题判定单源化**：`night` 正确归为暗色（此前所有判断都是 `theme === "dark"` 的二元判断）；切换主题后分屏 mermaid 重新着色。
- **`[toc]` 在阅读模式实时更新**；**emoji 短码在阅读模式渲染为图形**（存盘仍保留短码原文，不改文档）。
- **阅读模式图片灯箱**：点击图片全屏查看、支持缩放/前后切换/Esc 关闭；可编辑标签保持原有「编辑图片」对话框行为不变。
- **状态栏显示阅读进度**百分比。

### 2.5 文档一致性（B6）

- 修正 README / USER_GUIDE 四处夸大表述（Emoji「自动补全」、设置「自定义 CSS」、「侧栏全局文件搜索」、主题仅列亮/暗）。
- 新增「⚠️ 当前不支持（请勿误以为可用）」清单。
- 设置项说明补齐本版新增内容；导出体积变化已注明。

## 四、已知范围

- **导出 HTML 体积增大**（含公式约 600KB+）是"离线可用"的必要代价；mermaid 需与 `_assets/` 目录一同拷贝。
- **PDF 页码**：当前导出引擎（Edge/Chromium `--print-to-pdf`）无法自定义页码文本；本版已移除该失效选项并在 UI 注明，不再宣传 `{page}` 变量。
- 排版三项设置默认值表示"沿用主题默认"，需手动调整才生效。
- 尚未支持（详见 README 清单）：跨文件全文搜索、标签、frontmatter、双链/反链/图谱、书签、Git 集成、合并单元格、代码块复制按钮与只读切换、Emoji 输入补全、Snippets、插件 API。
- 原计划 B4-2（大纲三模式跳转）、B4-6（分屏预览内搜索）经确认取消，不在本版范围。
- DOCX / EPUB / LaTeX 尚无「包含样式」等对等样式定制入口（HTML / PDF 已有）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性 schema 变更；设置、快捷键、收藏、最近打开等本地数据全部保留。
- 表格删除行在表头时**不再删除表头**（此前会丢数据），如需删除表头请改用表格工具栏的列/表结构操作。
- 导出 HTML 若需离线查看，请连同其旁的 `_assets/` 目录一起移动。
- `Alt+↑/↓` 语义变更：现在是真正的块上移/下移；原「与上块合并 / 提升层级」请使用 `Alt+Shift+↑/↓`。
