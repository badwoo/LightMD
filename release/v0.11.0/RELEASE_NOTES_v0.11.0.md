## 二、版本内容

本版共 **42 项新增与修复**（原计划的大纲三模式跳转、分屏预览内搜索两项经确认取消，不计入）。

### 2.1 新增功能

- **阅读模式图片灯箱** — 点击图片全屏查看，支持缩放、同文档多图前后切换、`Esc` 关闭；编辑模式下点击图片仍是选中/拖拽，行为不变
- **排版三项设置** — 内容宽度 / 行高 / 段间距设置真实生效并持久化（此前只作用于编辑区元素），状态栏新增阅读进度百分比
- **导出 HTML 离线自包含** — KaTeX（CSS/JS/字体 base64）全内联、mermaid 旁置 `_assets/mermaid.min.js`，离线/内网打开公式与图表正常；资源缺失时明确提示回退 CDN，不再静默失败

### 2.2 问题修复

| 问题 | 修复要点 |
|---|---|
| 代码块 / 公式块内 `Shift+Enter` 腰斩块结构 | 此前会把代码块拆成两块、剩余内容降级为段落写回磁盘，高亮失效、文档被改写；现交回默认键盘处理，并补输入法组合态守卫 |
| 表格「删除行」作用于表头丢数据 | 此前删除整个表头且序列化把数据首行顶替为表头，列名永久消失；现三重防线——删除命令在表头拒绝执行、工具栏按钮跟随选区置灰、序列化补空表头行 |
| 图片尺寸语法仅编辑器生效 | `![alt\|300](src)` 在分屏预览与导出（HTML/PDF/PNG）中宽度丢失且 alt 被污染；现渲染管线补 inline 规则，全链路生效 |
| PDF 页眉页脚缺失 | CSS margin box 被 Chromium 静默忽略；改用 `position:fixed` 零偏移，29 页文档逐页齐全且不再多出空白页 |
| PDF 泄漏内部临时路径与页码 | `--print-to-pdf-no-header` 在 Edge 154 上完全无效；改用生效的 `--no-pdf-header-footer` |
| PNG 导出公式字体错误 | 显式内联字体 CSS，∑/上下限/分式字形正确 |
| DOCX 静默丢内容 | 补齐任务列表、定义列表（此前整段丢弃）；图片恢复为真实图片（含相对路径解析）；有序列表起始序号保留；行内公式渲染为图片；表格保留行内格式并应用列对齐；未识别内容显式提示 |
| LaTeX / EPUB 细节 | LaTeX 转义与表格列宽修正；EPUB 目录支持 h3+ 分层、`nav.xhtml` 引入样式表、已完成任务项正确显示删除线 |
| 命令面板缺条目与死键 | 补齐标题 4-6 / 正文 / 有序 / 无序列表 / 引用 7 条格式命令；解锁 `format.math` 等死键；脚注标签动态取号 |
| 源码模式格式快捷键无效 | `Ctrl+Shift+8`（无序）/ `Ctrl+Shift+9`（有序）/ `Ctrl+Shift+.`（引用）此前漏了映射，按键无反应；现真正可用 |
| `~` / `^` 转义噪音 | `x^2 + y^2`、`a ~ b` 被凭空加反斜杠且每次编辑重现；现按真实配对规则判定，不再误转义 |
| 有序列表 `1)` 不对称 | 可输入但编辑后被改写为 `1.`；现双向对称，起始序号与分隔符同时保留 |
| `Alt+↑/↓` 语义不符 | 此前绑定的是「合并 / 提升层级」而非宣称的「移动块」；现改为真正的块上移 / 下移，原语义移至 `Alt+Shift+↑/↓` |
| 排版设置不生效 | 字号/字体与内容宽度/行高/段距此前读错作用域，分屏预览回退默认值；现统一生效 |
| 标题锚点跳转不可用 | 锚点 `id` 提升为标题节点属性，阅读模式文内链接可跳转，跳转后留出顶部余量；重名标题去重口径统一 |
| 主题判定错误 | `night` 主题此前被判为亮色；现明暗判定单源化，切换主题后分屏 mermaid 重新着色 |
| `[toc]` 不更新 / emoji 不渲染 | 阅读模式下 `[toc]` 实时更新；emoji 短码渲染为图形（存盘仍保留短码原文） |
| 自定义 CSS 不生效 | 设置项存在但未接线；现保存后立即注入编辑器与阅读视图 |
| 文档表述失实 | 修正 README / USER_GUIDE 四处夸大表述，新增「⚠️ 当前不支持」清单 |

### 2.3 快捷键与行为变更

| 变更 | 说明 |
|---|---|
| `Alt+↑/↓` 语义变更 | 现为**块上移 / 下移**；原「与上块合并 / 提升层级」改用 `Alt+Shift+↑/↓` |
| 表格删除行 | 光标在表头时不再删除表头（此前会丢数据），需要删表头请用表格工具栏的列/表结构操作 |
| PDF 页码 | 导出引擎无法自定义页码文本，已移除失效选项并不再宣传 `{page}` 变量 |
| 导出 HTML 体积 | 含公式的 HTML 约 600KB+（离线可用的必要代价），且需与 `_assets/` 目录一同拷贝 |
| 源码模式快捷键 | `Ctrl+Shift+8/9/.` 新增生效（此前按下无反应） |

## 四、已知范围

- **导出 HTML 体积增大**（含公式约 600KB+）是"离线可用"的必要代价；mermaid 需与 `_assets/` 目录一同拷贝。
- **PDF 页码**：当前导出引擎（Edge/Chromium `--print-to-pdf`）无法自定义页码文本，本版已移除该失效选项。
- 排版三项设置默认值表示"沿用主题默认"，需手动调整才生效。
- 尚未支持（详见 README 清单）：跨文件全文搜索、标签、frontmatter、双链/反链/图谱、书签、Git 集成、合并单元格、代码块复制按钮与只读切换、Emoji 输入补全、Snippets、插件 API。
- DOCX / EPUB / LaTeX 尚无「包含样式」等对等样式定制入口（HTML / PDF 已有）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性 schema 变更；设置、快捷键、收藏、最近打开等本地数据全部保留。
- `Alt+↑/↓` 语义变更：现在是真正的块上移/下移；原「与上块合并 / 提升层级」请使用 `Alt+Shift+↑/↓`。
- 表格删除行在表头时不再删除表头，如需调整表头请使用表格工具栏。
- 导出 HTML 若需离线查看，请连同其旁的 `_assets/` 目录一起移动。
