# LightMD v0.14.0 发布说明

> 发布日期：2026-10-26 ｜ 基线：v0.13.2 ｜ 定位：**交互收敛（三模式 → 二模式）+ 搜索能力增强 + 内置检查更新 + 实机缺陷收敛**
>
> 本版把「阅读 / 编辑 / 分屏」三个模式收敛为**两个**（编辑即原分屏，右侧预览可滑出滑回），把查找替换补成一套完整能力（全词 / 大小写 / 选取范围 / 跨文件 / 可撤销），并在设置里内置「检查更新」。
> 全部功能与修复均在**打包安装产物 + WebView2 真实鼠标键盘手势 / CDP 帧采样**下逐条实测（累计 111 项验收）。

## 二、版本内容

### 2.1 新增功能

**交互收敛**

- 📝 **两种编辑模式** — 标题栏只剩「阅读 / 编辑」；点「编辑」直接进入原分屏观感（左源码 + 右预览），
  不再有独立的「分屏」入口。命令面板原「分屏模式」改名「切换预览面板（编辑模式）」
- 🪟 **预览面板可滑出滑回** — 分割线正中悬停浮出竖排呼吸小字「关闭预览」：点击后右屏滑到语法辅助栏左侧、
  编辑区铺满，右缘保留 18px 静默 rail 可随时滑回；开关状态按上次记忆，>5MB 大文件自动关预览

**搜索与替换**

- 🔍 **四个勾选项** — 全词匹配（Unicode 词边界）/ 匹配大小写 / 选取范围内 / 正则
  - 「选取范围内」在勾选瞬间捕获选区、随替换自动平移；无选区时匹配数为 0 并提示，
    **绝不静默退回全文**（避免一次「全部替换」改掉整篇）
- 🗂 **查找所有打开文件** — 结果条幅列出「文件名 + 命中行」并高亮，汇总「N 处（M 个文件）」，
  点击跳到对应文件与位置；条幅展开时「全部替换」同时替换所有命中文件，并置脏提醒保存
- ↩️ **替换可撤销** — 替换结果进入撤销栈；跨文件批量替换按「整篇一步」记录，
  切到被改文件（含从未激活过的标签）也能 `Ctrl+Z` 撤回 / `Ctrl+Y` 恢复，阅读模式的键盘撤销同样生效
- 🔄 **跨文档自动重搜** — 不关搜索框直接切文档，搜索词立即在新文档上重新计算

**更新与持久化**

- 🔄 **检查更新** — 设置面板末尾「软件更新」：查询 GitHub 最新版本、可折叠更新说明、
  下载进度条、下载完成后启动安装向导、打开发布页；网络不通与「已是最新」严格区分
- 📊 **表格尺寸持久化** — 拖过的列宽 / 行高随文档保存，关闭重开、重启后仍生效；
  以表格后的 HTML 注释指令承载（其它编辑器当注释忽略），**没调整过尺寸的表格保持零 diff**

**阅读联动**

- 🧲 **左右屏块级对齐** — 分屏联动由百分比改为顶层块锚点映射，两屏落到同一个标题 / 段落 / 表格 / 代码块，
  且能一起到底；含 mermaid 图表的文档此前完全没有锚点，本版一并修好

### 2.2 问题修复

| 问题 | 修复要点 |
|---|---|
| 分屏分割线只能往一侧拖，往右拖不回来 | 分割条紧贴预览 iframe，指针进入后父文档丢失拖拽事件。指针捕获 + 拖拽期屏蔽 iframe 指针事件 + pointer/mouse 双通道去重 |
| 竖排「关闭预览 / 打开预览」点不动 | 按钮是分割条子元素，拖拽的指针捕获把 `click` 重定向走了；改为对落在按钮上的按下直接放行 |
| 阅读↔编辑切换丢阅读进度 | 容器不可滚动时不再写 0 并重试到可滚动；右屏独立恢复；预览内容未变时也会消费待恢复位置 |
| 关闭文档重新打开，进度被重置 | 删除 4 处「关闭即清进度」的旧逻辑（v0.7.0 旧语义），改为同一会话内保留 |
| 关闭预览后阅读焦点下移（3.1 变 3.3） | 分屏与全宽下正文列宽不同、软换行不同 → 改为按**视口中央内容锚点**还原，贴底仍按底部还原；重开预览按块锚点重新对齐右屏 |
| 反复开合预览，文档持续往上漂 | 正文列宽的百分比 `padding` 加过渡消除 `scrollHeight` 突变；开合期间冻结联动，关窗后多次裁决校验；用户主动滚动优先 |
| 阅读模式与分屏模式进度联动丢失 | 冻结窗口增加 `viewMode` 闸门，只在真开合预览时启动，阅读↔编辑切换交给原有进度恢复 |
| 点「检查更新」误报「无法连接 GitHub」 | 根因在 TLS/代理：改为 `rustls-tls-native-roots` + `system-proxy`（读系统证书库）；网络失败单独编码，界面显示「网络不可用」，不再谎报「已是最新」 |
| 搜索/替换后撤销，搜索框失效 | 阅读模式下替换与撤销只改 `state.doc`、依赖全没变 → 结果冻结。改用 `MutationObserver` + doc 身份闸门 + 150ms 短防抖 |
| 跨文件替换后切到被改文件，键盘撤销无效 | 撤销有两条入口，键盘那条绕过跨文件记录；且点完标签后焦点不在编辑器。PM 键位改为「有宿主转交宿主」，全局按键按焦点四类互斥处理 |
| 阅读模式下搜索/替换文本不立即生效，切模式还被冲掉 | 新增统一写回入口，阅读模式走 ProseMirror 事务（立即生效），源码模式写状态并记撤销 |
| 「最近打开」点时钟不出面板 | ① 判定只看最近文件，只开过文件夹时不挂载；② 面板落在滚动视口之外。统一 `recentHasData` 口径 + 布局稳定后至多一次滚动校正 |
| 文件夹栏只显示 7 个条目 | 按实测行高把默认高度定为 **11 个条目位（10 文件 + 1 常驻空白）**；并修掉「被撑满的栏还原成内容自然高度」把文件夹栏缩成 5~7 行的根因 |
| 收藏 / 最近打开展开卡顿、左侧栏抖动 | `scrollbar-gutter: stable` 消除宽度抖动、双高度动画合并为同一段过渡、reveal 只在布局稳定后校正一次 |
| 标题栏下拉菜单被编辑区挡住 | stacking context 三层失效，给标题栏建独立层级（内容区不加 `z-index`，避免把内部 fixed 弹层关进低上下文） |
| 预览开关动画生硬、打开时只有右屏在动 | 0.28s → 0.42s 并换对称缓动；左栏宽度改由 flex 派生（`auto` ↔ `calc()` 不可插值导致首帧跳终态）；分割条宽度也逐帧过渡 |
| 左右屏篇幅差异导致滚不到一起 | 长行软换行改用真实行轴测量、补末尾锚点并修正「到底该用哪一行」、把 mermaid/katex 注入节点从锚点基数里过滤 |
| **表格拖拽改列宽/行高后重开失效（回归）** | 尺寸**已**写入 markdown（指令行在），断在渲染层：NodeView 的 constructor 先于 ProseMirror 把 `tr/td` 填进 DOM 执行，构造期查不到行 → 只设上了表格总宽，每个 `td/th` 的 width/height 一个没写；而渲染完成后 ProseMirror 不会再调 `update()`（节点未变），尺寸于是永久缺失。改为构造后由微任务 + `requestAnimationFrame` + `MutationObserver` 三层兜底，DOM 一出现 `<tr>` 就应用尺寸 |

### 2.3 快捷键与行为变更

| 变更 | 说明 |
|---|---|
| 模式入口 | 「分屏」不再是独立模式：点「编辑」即原分屏；`双击 Shift` 在编辑模式内开关右侧预览 |
| 阅读进度 | 关闭文档再打开**保留**阅读位置（旧版会重置）；重启软件不恢复已关闭文件 |
| 文件夹栏高度 | 默认 11 个条目位（362px）；此前手动拖过高度的老用户保留自己的值 |
| 表格存盘形态 | 调过尺寸的表格会在表格后多一行 `<!-- lightmd-table-size: ... -->` 注释指令 |
| 撤销语义 | 跨文件批量替换是「整篇一步」；该文件事后被手工改过则这条记录自动失效 |
| 检查更新 | 设置面板末尾新增「软件更新」区，快捷键总数不变 |

## 四、已知范围

- **左右两屏篇幅天然不等**：Markdown 规范下块间空行不产生元素，右屏本就更短（实测篇幅比 0.30~0.81）。
  本版解决的是「两屏滚不到一起」，**没有**为「看起来一样长」伪造空行间距。
- **表格尺寸指令是 LightMD 扩展语法**：其它编辑器会当作 HTML 注释忽略（不影响表格渲染）；
  在 LightMD 阅读模式下不可见。
- **表格尺寸只有「阅读模式」可直接拖拽**：编辑模式下 ProseMirror 视图不显示
  （`display:none`，量不到几何），拖拽需切到阅读模式；右侧 iframe 预览是渲染产物，不参与拖拽。
- **跨文件撤销是整篇文本级**：一次 `Ctrl+Z` 撤回「那轮批量替换」，且只在该文件本轮未被手工编辑过时生效。
- **阅读进度只保留在当前会话内存**：同一会话关闭→重开可恢复；重启应用不恢复已关闭文件。
- **「选取范围内」的快照不跟随事后改选区**：勾选瞬间捕获一次，之后只随替换平移。
- **老用户文件夹栏高度**：曾把该栏拖到非历史默认值（250/392）的会保留自己的高度，
  想回到新默认请拖回默认附近或双击标题栏折叠/展开一次。
- 未支持功能清单不变（跨文件全文搜索、标签、frontmatter、双链 / 反链 / 图谱、书签、Git 集成等，详见 README）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）、
  窗口大小、大纲滚动位置等本地数据全部保留。
- **交互习惯变化**：标题栏不再有「分屏」按钮，原来点分屏的场合请点「编辑」；
  需要纯源码时点分割线正中（或右缘）的竖排小字收起预览。
- **阅读进度行为变化**：关闭标签再打开会回到上次位置（旧版回到顶部），这是本版的刻意改动。
- **文件夹栏**：默认高度改为 11 个条目位（10 文件 + 1 空白），老用户的拖拽值会被尊重。
- **表格文件**：调过尺寸的表格首次保存会新增一行注释指令；未调过尺寸的表格保存内容与旧版逐字节一致。
- **检查更新**：可从「设置 → 软件更新」直接升级后续版本；本机若使用代理，走系统代理与系统证书库。
