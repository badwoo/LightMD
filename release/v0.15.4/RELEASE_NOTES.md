## 五、本版其他口径调整

1. **URL 兜底契约收紧**（避免任何请求被发两遍）：
   - 只有「获取模型列表」保留兜底，且**只在 404** 时换 `{base}/v1/models` 再探测一次；
   - 对话 / 助手 / 翻译 / 测试连接拿到 404 一律原样报错，不重发（`send_ai_request` 单次发送）。
2. **本地运行时口径统一**：
   - llama.cpp 端口取上游默认 **9931**（不再与 LocalAI 的 8080 撞端点导致服务商反推歧义）；
   - 本地运行时一律 `authMode=none`（不白跑一次凭据解析）；
   - 新增 4 条不变量测试钉住：本地预设 baseUrl 互不重复 / 本地预设与服务商预设同端点一致 /
     本地一律 `none` / 服务商本地项一律 `none`。
3. **服务商下拉分组**：分组只从 `AiProviderPreset.group` 字段推导（不维护第二份 id 清单），
   新增预设写对 `group` 即自动落组，并有测试逐项与字段比对。

## 六、已知取舍 / 验证边界

1. **覆盖率口径**：按使用量加权 ≈ 94%~96%，按任务书 43 个目标厂商计数 40/43 = 93%。
   **个人 / 中小团队 + 本地部署场景满足 95%**；**企业场景达不到** ——
   Azure OpenAI / AWS Bedrock / Vertex 必须走自定义（三协议 + 静态 baseUrl 的硬边界）。
   其中 Azure **协议是兼容的**，只差「每租户 resource 子域」无法预置：
   自定义页填 `https://<resource>.openai.azure.com/openai/v1`，并把**部署名**当 model。
2. **静态模型目录有时效**（models.dev 为 2026-11-01 快照）：只是首次默认值，
   点「获取模型列表」可刷新。
3. **AI 指令的 `{{document}}`** 取截断后 2 万字，长文档会把输入框填满
   （与发送上限一致，不会超发）。
4. **`contextWindowTokens` 仍是档案元数据**（驱动滑条与预算校验），Rust 请求层不据此裁剪上下文。
5. **模型目录只收录有公开权威数据的型号**：Anthropic 协议无标准 `/models` 端点，
   厂商不提供时需手填模型 ID。
6. 本轮**未**推送 GitHub、未创建 GitHub Release，改动已全部提交到本地 git（见下）。

## 八、安装与验证指引

1. **推荐**：双击 `LightMD_0.15.4_x64-setup.exe` 安装（NSIS 会处理文件关联与卸载项），
   或安装 `LightMD_0.15.4_x64_en-US.msi`。
2. 免安装验证：直接双击 `release/v0.15.4/lightmd.exe`（无需安装；注意与已安装版本的单实例互斥）。
3. 打开设置（`Ctrl+,`）→ AI 功能开启 → 模型配置：
   - 左「服务商」下拉应看到**三组**：本地部署 / 国内厂商 / 国际厂商；
   - 默认是 **Ollama（本地）**，地址 `http://127.0.0.1:11434/v1`；
   - 点「获取模型列表」→ 应列出**本机全部**模型（本机实测 4 个，
     包括 `qwen3-vl:8b-instruct`、`qwen3-vl:8b`、`guoxuter/ov_intent_analysis_sft:v7_q8`、`bge-m3:latest`）；
   - 模型名称框**右边**就是「获取模型列表」「测试连接」两个按钮；
   - 配置区下方能看到 `当前启用模型：Ollama（本地，默认）-<模型>-<推理等级>`。
4. 切右页签「自定义模型 API」：顶部有「本地部署类型」，选 Ollama / LM Studio / vLLM /
   llama.cpp / LocalAI 会自动填好端点与协议；该页签同样有获取列表 / 测试连接 / 上下文滑条。
5. 指令库：设置里配好自定义指令后，按 `Ctrl+K` 打开 AI 对话 →
   「快捷指令」下方会出现**第二排你的指令**；在输入框输入 `/` 也能弹出选用列表。
6. 上下文：不选内容直接开对话是「全文」；在编辑器里**选中一段文字**后，
   上面的 chip 会自动变成「选区 N 字」并发送该选区；手动点过 chip 后会锁定，
   直到你再次真正改变选区。
7. 撤销体验：编辑和 `Ctrl+Z` 时文档不再抖一下。
