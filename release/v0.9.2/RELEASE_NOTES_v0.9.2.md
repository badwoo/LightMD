**发布日期**：2026-10-01
**基线版本**：v0.9.1
**主题**：P0 编辑缺陷清零 · 段内换行设置 · 标题栏与侧栏体验（2 项需求）
**实现依据**：《LightMD 0.9.1 全方位测评报告》v0.9.2 任务卡（E1/E2/E3/E4/E5/E14）+ 用户补充的 2 项需求；技术细节见 `.trae/documents/lightmd-0.9.1-assessment-report.md` 与 `lightmd-p1-remediation-plan.md`

## 一、修复

### 1.1 阅读模式下格式命令是"假命令"（E1）

**现象**：阅读（富文本）模式下，工具栏 / 命令面板点「加粗」「斜体」「标题」等，得到的只是 `****`、`## ` 这样的字面文本，格式并未生效；而键盘 `Ctrl+B` 却是正常的——两条路径行为不一致。

**根因**：阅读模式分支用程序化 `insertText` 插入 Markdown 语法串，该通道不触发输入规则（InputRules），语法永远不会被转换。

**修法**：命令路由改走 ProseMirror 真命令（与快捷键共用同一张命令表，并补上此前缺失的「高亮」命令）；插入类命令构造真实文档节点（表格 / 代码块 / 任务列表 / 脚注定义）；链接、图片命令改为打开对话框，确认后直接写入富文本（此前阅读模式下确认后会静默丢失）。

### 1.2 Tab 键在代码块、任务列表、表格中失效（E2）

**现象**：代码块内按 Tab 焦点直接跳出编辑器；任务列表无法用 Tab 嵌套；表格无法用 Tab 逐格移动。

**修法**：

- **表格**：Tab 在行内逐格前进、行末自动换到下一行首格、**末行末格按 Tab 自动追加一行**并落入新行首格；Shift+Tab 反向，首行首格保持不动（吞掉事件防止焦点丢失）；
- **代码块 / Mermaid 块**：Tab 插入 2 空格缩进，Shift+Tab 删除一个缩进单位（行中退化为删 1 空格）；
- **任务列表**：Tab 嵌套 / Shift+Tab 提升，与普通列表对齐；
- 优先级：表格 > 代码块 > 任务项 > 列表项，普通段落内 Tab 保持浏览器默认行为不变。

### 1.3 列表项、引用内输入 `---` / ` ``` ` 被误转换（E3）

**现象**：在列表项或引用块内输入三个 `-`、`*`、`_` 会被转换成水平线，输入三个反引号会转成代码块，导致结构错乱、内容损坏。

**修法**：水平线与代码块输入规则补齐守卫——仅**顶层段落 / 标题的行首**触发转换，嵌套块内一律保持字面文本。水平线同时新增 `___` 变体（与 `---` / `***` 等价）。

> 附带修掉同源缺陷：行内代码规则此前会把打代码块路径中的 `` `` `` / ```` ``` ```` 吞成行内代码（顶层被代码块规则掩盖，嵌套场景暴露）。

### 1.4 表格右键菜单英文界面穿帮、表头可"删除行"（E4）

**现象**：右键菜单 7 项文案硬编码中文，英文界面显示中文；"危险操作"样式靠文案里是否含"删除"二字判定；表头行上"删除行"实际会删掉整个表头，行为反直觉。

**修法**：菜单改为 i18n 数据驱动（中英文双语）；危险样式改为显式标记；**表头行不再提供「删除行」**（仍可删除列、插入行/列）。

### 1.5 拼音未上屏按退格误删配对符号（E5）

**现象**：中文输入法组合输入期间按 Backspace 删拼音时，可能误触发空配对（如 `()`、`“”`）的成对删除，把刚输入的括号/引号一并删掉。

**修法**：富文本与源码模式两处成对删除逻辑均补 IME 组合态守卫（`isComposing` / `keyCode 229`），组合期完全不拦截退格；正常输入法的成对删除不受影响。

### 1.6 需求：「最近打开」改为默认关闭

侧边栏「最近打开」区块默认收起（与「收藏」区块一致），需要时点击侧栏顶部时钟图标展开；当前会话内的选择即时生效。

### 1.7 需求：标题栏文件名在整体标题栏居中

**现象**：打开文件后，标题栏中央的文件名没有落在窗口正中，整体偏右。

**根因**：文件名位于「左段（品牌 + 模式切换 + 菜单）— 中段 — 右段（图标 + 窗口控制）」的三段弹性布局中段，左段远宽于右段，中段的几何中心随之外偏。

**修法**：文件名改为相对整个标题栏绝对居中（实测中心与窗口中心偏差 0px）；超长文件名自动省略号截断，截断边界不遮挡左右按钮的点击。

## 二、新增与优化

### 2.1 段内换行语义设置（E14）

新增设置项「**段内换行**」（设置 → 编辑器分类）：

| 选项 | 语义 |
| --- | --- |
| GFM（即换行） | 段内单换行渲染为换行（**默认**，与历史版本一致） |
| CommonMark（需两空格） | 段内单换行渲染为空格，`行尾两空格 + 回车` 才是换行 |

- 读取 / 分屏预览 / 导出（HTML、PDF、PNG、DOCX、EPUB、LaTeX）全管线跟随该设置；
- 底层把 markdown-it 的三处独立实例统一为单一工厂，后续任何解析配置只需改一处；
- 切换设置后**重新打开当前文档**生效（设置项旁有提示）。

## 三、兼容性

- 设置、快捷键自定义、最近打开、收藏夹、会话等数据格式**完全不变**，从 0.9.1 覆盖安装即可；
- 新增 `paragraphBreaks` 设置项默认值即历史行为，未改动设置的用户感知不到任何变化；
- 旧文档无需迁移：`---`、```` ``` ```` 等语法在行首的正常转换行为保持不变，仅嵌套块内的误转换被禁止；
- 表格右键菜单的「删除行」在表头上不再提供，如需重建表头可切换源码模式编辑。
