# LightMD v0.15.6 发布说明

> 发布日期：2026-11-03 ｜ 基线：v0.14.0 ｜ 定位：**AI 深度配置 + 编辑体验收敛**
>
> 本说明汇总 **0.15.0 ~ 0.15.6** 七个版本：0.15.0 编辑体验与 AI 底座（7 项新增，另修 2 项）、
> 0.15.1 实机反馈 13 项修复、0.15.2 模式切换动画与三轮返修（5 项）、0.15.3 AI 配置深化、
> 0.15.4 用户点名 10 项（含服务商覆盖 26 → 54）、0.15.5 配置可见性与快速选字 3 项、
> 0.15.6 两个配置页签统一为条目式交互。
> 0.15 系列的共性问题是「功能写了但真实交互不成立」（撤销栈只接了一半、对齐用两把尺子、
> 选区判断读的是焦点而非编辑器状态），因此返修全部以实机探针取证，
> 关键项在**实际分发的 exe** 上验证。

## 二、版本内容

### 2.1 新增功能

**0.15.0 编辑体验**

- ↩️ **跨模式统一撤销** — 每篇文档只有**一条逻辑时间线**，阅读 / 编辑 / 右侧预览共用同一撤销栈；`Ctrl+Z` 可以穿过任意次模式切换，模式切换本身不算一步；跨文件替换、选区翻译、AI 润色 / 替换 / 插入 / 续写采纳都各算一步
- 📑 **阅读区标题折叠** — 阅读模式与右侧预览的标题前出现折叠按钮，收起该标题下的全部内容；纯视觉，不改 Markdown、不写文件、不进撤销，导出不受影响，大纲跳转会先展开祖先
- 🧭 **阅读 ↔ 编辑内容对齐** — 对齐基准从滚动百分比改为**内容锚点**（顶层块 + 块内比例），同一段落始终落在两屏对应位置
- 🔎 **工作区全文搜索** — `Ctrl+F` 可切到「工作区」范围，流式结果、可取消、脏文档按内存内容校正；命中可精确跳到第几处，行号与状态栏同一套口径
- 🖼 **图片灯箱** — 覆盖应用视口查看：25%~800% 缩放（按钮 / 滚轮 / 双击在适应窗口与 100% 间切换）、放大后拖拽平移、`←`/`→` 切图、`Home` 复位、`Esc` / 遮罩 / ✕ 关闭
- 📤 **PDF 导出改应用内 WebView2** — 不再依赖 Edge / Chrome 外部进程，导出期间使用独立隐藏窗口，主编辑区不受打扰；带真实就绪信号（字体 / 图片 / Mermaid / KaTeX 渲染完成）
- 🧩 **表格合并跨编辑器提示** — 首次合并弹一次说明，表格菜单「兼容性说明」可随时重看，只弹窗不改文件
- 🧭 **打开所在文件夹不重复挂载** — 文件已在本窗口某个工作区内时（多根嵌套取最深），只展开并定位、复用现有工作区，不新增侧栏栏位、不重复注册文件监听

**0.15.0 AI 底座**

- 🔌 **AI 连接档案** — 与翻译配置彻底解耦：改翻译模型不再连带改变助手 / 对话所用模型
- 🧠 **双协议 + 深度参数** — OpenAI 兼容 / Anthropic 双协议，自定义 system prompt，上下文与输出预算，真实 token 用量显示（未上报显示「未上报」而不是 0）
- 📚 **AI 指令库** — 7 个内建模板，可复制后自定义
- 🏠 **Ollama 本地预设** — 选中即预填本地端点、免密钥

**0.15.1 / 0.15.2 打磨**

- 🎞 **模式切换滑入动画** — 阅读 → 编辑时编辑区左右屏由左往右滑入，编辑 → 阅读时文档从右往左滑回（380ms，只动 `transform`，不破坏滚动锚点）
- 🌀 **折叠顺滑动效** — 收起 / 展开 440ms、三角旋转 360ms，收起与展开**一样慢一样顺**，动画期间反复点击收敛到终态
- 🔍 **搜索面板重做** — 面板 620×38（宽高比约 16:1）、圆角分三级、窄屏自动收窄；展开 / 收起结果条幅时高度平滑过渡，两个范围按钮位置不变
- ✨ **全命中高亮** — 一出结果所有命中同时高亮，↑/↓ 定位时当前那处换成强调色（上限 2000 处，超出显式提示）

**0.15.3 AI 配置深化**

- 🗂 **设置窗加宽 50%** — 520px → 780px（窄屏按视口安全收缩）
- 🌲 **AI 树状配置** — 「启用 AI 功能」为总开关，开启后依次嵌套：模型配置 → AI 翻译 → AI 指令库；关总开关整棵子树收起
- 🔀 **模型配置双页签** — 左「服务商」、右「自定义模型 API」，能力对等
- 🌐 **三协议真正落地** — OpenAI Chat / OpenAI Responses / Anthropic Messages 统一走 HTTP/SSE（修掉 0.15.0 只把协议传到命令边界、实际仍发 OpenAI Chat 的缺口）
- 🏢 **厂商 Plan 预设** — Kimi / 火山引擎 Coding Plan / 智谱 GLM Coding Plan / 阿里云 Token Plan
- 📏 **上下文滑条与推理等级** — 拉取模型后可选上下文窗口（默认最大档，1M 级模型多一档 600K），推理等级六档 `off / low / medium / high / xhigh / max`
- 🔗 **获取模型列表 / 测试连接** — 真实请求端点（不用 mock），上下文元数据只取端点真实返回，不按模型名猜

**0.15.4 AI 覆盖与入口**

- 🧾 **服务商预设 26 → 54** — 按「本地部署 / 国内厂商 / 国际厂商」三组下拉；明确不收录会必然失败的预设
- 💻 **本地部署五选一** — Ollama / LM Studio / vLLM / llama.cpp / LocalAI，选中即预填官方端点、协议、免鉴权（另有 Text Generation WebUI / Jan / Xinference / SGLang 走服务商预设）
- 📦 **Ollama 全量模型** — `/v1/models` 与原生 `/api/tags` 按 id 求并集，本机模型不再漏
- ⚡ **AI 指令应用入口** — 对话窗「快捷指令」下方第二排自定义指令 chips；输入 `/` 弹出选用列表（↑↓ / Enter / Esc，输入法组合态不触发），选中按当下选区或全文预填
- 🎯 **对话上下文自动跟随** — 出现可用选区自动切「选区 N 字」，选区消失回落全文；手动点芯片后锁定，下一次真实选区变化才解锁
- 🏷 **当前启用模型摘要** — `服务商 - 模型名称 - 推理等级` 常显

**0.15.5 / 0.15.6 配置条目化**

- 📋 **自定义配置条目列表** — 每条显示名称 + Provider ID + 端点，点击载入编辑、行尾删除、启用条目带绿色圆点；删除启用条目时安全回落
- 🔆 **摘要上移总开关下方** — 总开关关掉也可见（它描述的是「当前启用哪个模型」）
- 🗃 **两个页签统一条目式** — 一条配置 = 一个条目：点条目主体只展开 / 收起（手风琴，同屏一条），条目上的启用 / 关闭按钮只切启用状态，两者互不影响；服务商页签只列已配置项，「添加服务商」下拉只给未配置预设

| 0.15.4 | Ollama「获取模型列表」拿不到本机全部模型 | 旧实现只用 `/api/tags` 补上下文。改为两个端点按 id 求并集并合并 `context_length`，`/v1/models` 全失败时以原生结果返回 |

## 四、已知范围

- **工作区搜索只读**：不支持正则、不建索引、不支持全库替换、不解析 frontmatter。
- **撤销历史是会话内的**：不跨重启持久化，上限 200 步 / 32MB 每文档；阅读模式撤销后**光标**不回现场（内容与滚动已由内容锚保住）。
- **表格合并仍用行内 HTML 扩展**：`<td colspan/rowspan>` 不是 GFM 标准，其它编辑器可能显示原始标签；Word / LaTeX 导出保留内容但不保留合并视觉。
- **AI 覆盖边界**：个人 / 中小团队 + 本地部署场景满足 95%；企业级（Azure OpenAI / AWS Bedrock / Vertex）需走自定义配置（Azure 协议兼容，填每租户 resource 子域即可）。厂商 Plan 只实测了端点可达性与鉴权要求，首次使用请点一次「测试连接」。
- **`contextWindowTokens` 是档案元数据**：驱动滑条与预算校验，Rust 请求层不据此裁剪上下文。
- **右屏对齐是最终收敛**：异步渲染（Mermaid / KaTeX / 图片）期间几何不定型，编辑后 160ms 仍可能差约 9 行，480ms 内收敛到 0.5 行以内。
- **阅读区折叠状态仅在会话内保留**；折叠动效依赖 `interpolate-size`，不支持时退化为瞬时显隐。
- **仅提供 Windows 安装包**；macOS / Linux 未构建。
- 未支持功能清单不变（双链 / 反链 / 图谱、标签、frontmatter、Git 集成、CM6 源码高亮、编辑区标题折叠等，详见 README）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）、窗口大小、阅读进度等本地数据全部保留。
- **撤销行为改变**：撤销栈现在跨模式共享，`Ctrl+Z` 可能撤到「上一次在阅读模式里的修改」，这是预期行为；模式切换本身不占撤销步。
- **图片交互改变**：双击打开灯箱，单击只选中；编辑态下拖四边 / 四角调宽。
- **搜索行为改变**：搜索一出结果全部命中高亮，↑/↓ 只移动「当前项」的强调色；超过 2000 处只高亮前 2000 处并提示。
- **AI 配置迁移**：老的 `translate` 连接字段只在迁移时读取，翻译运行时统一用当前 AI 档案；已有档案不需要手工迁移，`source` 标记缺失时按兼容规则推断。
- **PDF 导出的前提变了**：不再需要本机安装 Edge / Chrome；如遇白屏请先反馈（离屏窗口在极端多显示器 / 缩放配置下的风险尚未复现）。
- **「打开文件所在目录」已修复**：路径含空格时（如 `D:\AI\markdown view`）现在会正确打开资源管理器并选中文件。
