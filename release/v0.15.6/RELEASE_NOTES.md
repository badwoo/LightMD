## 二、本版需求与实现

### 用户原话

1. 「自定义模型配置，每进行了一个配置就对应一个条目，而且每点击一个条目都要能展开或收起它对应的配置信息，条目右边绿色亮点左边再增加一个启用或关闭按钮，用来启用某个条目。」
2. 「服务商配置也改为一样的配置条目交互。」

用户补充确认的交互口径：
> 「点一下当前已启用的那条应该展开该条的配置信息，点击其他已配置的条目同理，但如果点击配置条目上的启用/关闭就是开启或关闭该条目」

即：**点条目主体 = 只展开/收起**；**点条目上的启用/关闭按钮 = 只切换启用状态**。两者互不影响。

### 实现结果

| 要点 | 实现 |
| --- | --- |
| 一条配置 = 一个条目 | 两个页签都改为列表；每条一行显示 名称 + Provider ID + 端点摘要（不再是下拉选择） |
| 点条目 = 展开/收起 | 点击条目主体只切换该条配置信息是否展开（`aria-expanded`），**同屏只展开一条**（手风琴：点 B 自动收起 A）；**不会顺带启用** |
| 条目上的启用/关闭按钮 | 独立于展开状态的开关（`aria-pressed`）：点未启用条目 → 启用；点已启用条目 → 关闭 |
| 允许全部关闭 | 全部关闭时 `activeProfileId` 置空，顶部摘要显示「尚未配置任何连接」（既有 `settings.ai.model.active.none`），不会出现悬空 id |
| 绿点标启用 | 启用中的条目在启用/关闭按钮**右侧**显示绿色圆点（`role="img"` + `aria-label` + `title`，不只靠颜色区分） |
| 服务商页签只列已配置项 | 列表只显示已配置的服务商；上方「添加服务商」下拉只列**尚未配置**的预设（按 本地/国内/国际 分 3 个 optgroup），选中即新增一条、自动展开、**不自动启用** |
| 展开条目的表单编辑它自己 | 服务商页签表单整体改为绑定**展开的那一条**（彻底删除了写死 `activeProfile` 的 `patchActive` 路径）；拉取模型列表 / 测试连接 / 密钥保存与清除也都作用于展开条目 |

### 两个实现要点（工程侧）

1. **不能"展开 A 却在改 B"**：服务商页签表单全部改为接收 `profile` 参数，
   所有写操作走 `updateProfile(expandedProfile.id, ...)`。这一点有专项测试与实机判据双重锁定
   （见下方 P5a/P5b/P5c：先让「启用项 ≠ 展开项」，再验证只改展开项、启用项不被误改）。
2. **草稿安全（自定义页签）**：保留「草稿 + 保存并启用」语义；展开/收起或切换条目前做一次
   best-effort 提交 ——
   - 校验通过 → 静默写回该档案（**不改变启用状态**）；
   - 校验不通过（例如把模型清空）→ **拒绝切换并提示**（新增 i18n `settings.ai.model.error.unsavedDraft`）。

   取舍理由：既不静默丢弃用户改动，也不把不合法数据写进持久配置。删除正在展开的条目会连带收起并重置草稿。

3. **顺手修掉的一个坑**：`upsertProviderProfile` 为「切换服务商即生效」会把 `activeProfileId` 指过去；
   本版「添加服务商」显式还原为原值，保证**新增不自动启用**（否则"添加"会静默改掉当前启用的模型）。

## 五、已知取舍 / 验证边界

1. **「添加服务商」按钮目前是「聚焦下拉」的入口**，真正的新增由下拉的 change 触发。
   若你希望改成「点按钮弹出选择层」的形态，属新交互需求，可另行安排。
2. **服务商页签的展开体沿用无后缀 testid**（`ai-model-base-url` / `ai-model-name` / `ai-model-fetch` 等）：
   因为同屏只展开一条，展开体里的表单天然唯一。若后续要做"多条同时展开"，需要加 id 后缀。
3. **自定义页签收起时的草稿提交是 best-effort**：校验不过就阻止切换（而不是强行保存）。
   如果你更希望"收起即保存、不校验"，需明确口径。
4. **允许全部关闭**是用户确认的行为（未强制保留一条启用）。此时 AI 功能不可用，
   顶部摘要会明确显示「尚未配置任何连接」。
5. 本轮**未**推送 GitHub、未创建 Release（与前几版口径一致，改动已提交本地 git）。

## 六、安装与验证指引

1. **推荐**：双击 `LightMD_0.15.6_x64-setup.exe` 安装，或安装 `LightMD_0.15.6_x64_en-US.msi`。
2. 免安装验证：直接双击 `release/v0.15.6/lightmd.exe`（注意与已安装版本的单实例互斥）。
3. **复测步骤**：`Ctrl+,` → AI 功能开启 → 模型配置：
   - 「自定义模型 API」页签：保存一条配置 → 列表出现一个条目；
     点该条目 → 展开它的配置信息；再点一次 → 收起；点另一条 → 前一条自动收起。
   - 条目右侧有启用/关闭按钮：点它 → 该条启用（绿点出现在按钮右边）；
     再点它 → 关闭（绿点消失，顶部摘要显示「尚未配置任何连接」）。
   - 「服务商」页签：只看到已配置的服务商；用「添加服务商」下拉选一个没配过的 →
     新增一条并自动展开（此时**不会**自动启用，需点它的启用按钮）。
   - 展开某条服务商后改 API 地址 → 保存后确认改的是**这一条**（与当前启用的那条无关）。
