## 二、版本内容

### 2.1 新增功能

**v0.8.1（2026-09-19）**

- 无边框一体化窗口，最小化 / 最大化 / 关闭三键移到右上角（macOS 交通灯配色）

- 跨会话记住文档阅读位置
- 「最近打开」扩容到 66 条并显示打开日期；启动恢复定位到最后停留的标签
- 滚动性能优化：选区变化不再全量序列化、图片懒加载、滚动监听全部 passive

**v0.8.4（2026-09-24）**

- 标题栏排序按钮：文件名 / 修改时间 / 创建时间 × 升降序，按文件夹记忆

### 2.3 快捷键与行为变更（升级请注意）

| 项 | 说明 |
| --- | --- |
| `Ctrl+R` | **新增** — 刷新文件树（外部改动未同步时的兜底） |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴选中文件，仅在焦点位于侧栏文件树时生效 |
| 其他快捷键 | 0.8.1 ~ 0.8.5 **无变更**（版本快照仍为 `Ctrl+Alt+V`） |

行为变化：

1. **删除改为进回收站**（此前为永久删除），确认弹窗文案同步更新
2. 「最近打开」不再因关闭条目而移除，仅在路径失效时标注 ⚠；展示上限 66 条
3. 窗口尺寸与位置会被记忆；如需恢复默认，删除 `%APPDATA%\com.lightmd.app` 下的窗口状态文件后重启
4. 关闭「启动时载入上次打开的文件」开关后，已记录的阅读位置会一并清除
5. 文件管理工具栏的全局刷新按钮已移除，改用右键菜单或 `Ctrl+R`

## 四、已知范围

1. **标签「固定」状态不跨重启保留**：重启后恢复的是「最近打开」与未保存的临时文件，固定标记与标签顺序不保留
2. **分屏模式的滚动同步仍按百分比**：阅读 / 编辑模式已按编辑锚点对齐，split ↔ textarea 侧保留百分比策略
3. **ePub 中 Mermaid 图表与 KaTeX 公式不会渲染**：ePub 阅读器不执行脚本，二者以源码 / 占位形式呈现
4. **LaTeX 导出的字符转义**：`\href` 的 URL 与图片路径未做全量特殊字符处理；代码块含中文注释时请使用 XeLaTeX 编译
5. **手动排序与最近打开等偏好存于本机**（localStorage / 应用数据目录），换机不迁移
6. **文件系统实时监听在部分场景不可用**（网络盘、极端权限目录）：此时自动提示，并保留右键「刷新」/ `Ctrl+R` 兜底
