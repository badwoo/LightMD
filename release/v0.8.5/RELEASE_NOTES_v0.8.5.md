## 二、版本内容

### 2.1 新增功能

#### v0.8.1 · 细节与交互体验优化（2026-09-19）

- **无边框一体化窗口** — 去掉系统原生标题栏，最小化 / 最大化 / 关闭三键移到右上角设置按钮旁，采用 macOS 交通灯配色（黄 / 绿 / 红），悬停显示操作符号；顶部省下一条系统横条
- **默认最大化启动** — 打开应用即最大化（保留任务栏），还原后为 1200×800
- **侧栏滚动条统一收细** — 左右两侧栏（文件树 / 大纲）统一为 2px 细线，静止时透明、悬停该栏才以浅色显形
- **默认栏宽各加宽 0.5cm** — 左侧栏 260 → 279px、右侧大纲栏 240 → 259px（已手动调整过宽度的用户保持原值）
- **文件属性改为应用内对话框** — 不再调用系统原生弹窗，彻底消除提示音；路径等信息可选中复制
- **固定 AI 入口时底栏平滑居中** — 抽屉常驻占位时底栏整组按钮顺滑重排居中，不再遮挡右侧字数统计

#### v0.8.2 · 侧栏收展动画与排序（2026-09-21）

**动画**

- **打开即从左到右平滑进入** — 文件夹栏、文件夹内子目录、文件条目统一从左侧滑入并伴随高度展开，下方内容被平滑推下去
- **关闭改为严格串行三拍** — 先水平滑出（占位高度不变）→ 停一拍 → 再收起高度让下方内容上移补位
- **关闭中间那一项，原位消失** — 滑出块留在它原来的位置，不再统一跑到列表末尾
- **文件夹树节点收展动画** — 展开时子节点左滑入 + 高度展开，收起时先左滑出再收高度；动画容器按文件夹路径固定 key，父节点刷新不会打断动画

**排序调整**

- 最新打开的文件夹栏置顶（超出上限时挤掉最久未打开的）
- 「打开的文件」条目**仅"新打开"时置顶**，栏内点击切换不再重新排序（只更新选中态）

#### v0.8.3 · 交互优化 · 小功能（2026-09-22）

**新增功能**

- **状态栏实时显示光标行列** — 右下角显示 `行 N 列 M`，选中文字时追加 `已选 N 字`（取消选区即消失）；阅读模式与源码模式均生效
- **窗口大小记忆** — 首次安装仍默认最大化；此后以什么状态关闭，下次就以什么状态打开（多显示器位置同样保留）。状态标志显式收窄为「大小 / 位置 / 是否最大化」，不记忆全屏等状态
- **跨会话记住文档阅读位置** — 读到文档中部后关闭软件，重启并恢复该文档时仍在原位置；被一同恢复的其它文档、以及未落盘的临时文档都各自记住位置。位置按标签记录，落盘走「5 秒心跳 + 关闭前冲刷」，滚动路径零新增开销

**功能调整**

- **「最近打开」扩容到 66 条 + 显示打开日期** — 此前界面只渲染前 10 条；现完整展示并可在栏内滚动，最新打开的排在最上面，超过 66 条后最早打开的那条被清除；悬停显示完整路径 + `最近打开：YYYY/MM/DD HH:mm`
- **启动恢复定位到最后停留的标签** — 此前写死"激活第一个真实文件"，若关闭前最后停留在临时文档会被强制切走；现按上次会话的活跃标签定位（临时标签按 id、真实文件按路径）

**性能优化**

- **选区变化不再全量序列化文档** — 18k 行（66 万字符）文档实测：单次选区变化成本 **0.778ms → 0.072ms**（约 1/11）
- **图片懒加载** — 图片节点输出 `loading="lazy"` + `decoding="async"`，大图解码不再阻塞合成帧
- **滚动监听全部声明 `passive`**
- **滚动性能评测** — 用真实 Chromium 对 1.8 万行 / 9000 顶层块文档实测：基线滚动 avg **16.67ms（60fps、0 长任务）**，说明瓶颈既不在框架层也不在"整篇 DOM"这一层。计划中的 `content-visibility: auto` 方案实测反而把滚动拖慢到 avg **70.4ms（14fps）**，**故不采用**，结论与数据已写入源码注释

#### v0.8.4 · 左侧文件夹栏功能细化（2026-09-24）

**新增功能**

- **文件 / 文件夹拖拽复制与移动** — 拖到目标文件夹即复制，按住 `Shift` 拖拽为移动（标签与侧栏路径自动同步）；**支持跨盘**（跨盘自动改为「复制到目标 + 删除源」两步完成）；拖进自身子目录被拒绝并提示
- **同目录拖拽重排** — 同一目录内上下拖拽即可调整显示顺序（手动顺序），重启后保持；重命名后顺序自动跟随
- **树内右键复制 / 剪切** — 文件树节点右键菜单新增「复制 / 剪切」，配合粘贴完成跨目录操作
- **空白区右键菜单** — 文件树空白处右键：新建文件 / 新建文件夹 / 刷新 / 粘贴
- **新建文件居中弹窗** — 输入名称即创建：重名自动避让、无扩展名自动补 `.md`；创建后自动展开父目录并打开新文件
- **标题栏排序 6 模式** — 每个目录标题栏新增排序按钮：文件名 / 修改时间 / 创建时间 × 升序 / 降序，**按文件夹记忆**、重启保持；再次点击激活项取消排序
- **文件树实时刷新** — 外部（资源管理器等）对已打开文件夹的新增 / 删除 / 改名 / 修改自动同步到树，无需手动刷新；后端 200ms + 前端 300ms 双层去抖
- **大纲栏搜索** — 鼠标悬停大纲栏顶部平滑出现搜索框，实时过滤标题（大小写不敏感）
- **最近打开 stale 提示** — 已打开文件被移动后，旧路径条目保留并标记淡黄 ⚠，新位置生成新条目；外部删除文件同样触发标记

**功能调整**

- 文件夹展开 / 收起动画垂直化（子项自上而下依次进入 / 退出），替代原先的水平滑动
- 移除文件夹标题栏刷新按钮（实时刷新已覆盖），全局刷新、`Ctrl+R`、右键「刷新」保留
- 大纲搜索框移入标题栏「大纲」右侧，鼠标移入右侧栏时以宽度 + 透明度过渡平滑出现，不再单独占一行；输入过程中移出鼠标不收起
- 大纲搜索框新增清空按钮，点击即刻清空并保持输入焦点

#### v0.8.5 · 删除更安心 · 界面动效（2026-09-26）

**新增功能**

- **文件删除进回收站** — 文件树中删除文件或子文件夹时统一移入**系统回收站**（Windows 原生 `IFileOperation`），误删可随时还原；删除确认弹窗与提示文案同步改为「移到回收站」语义
- **「最近打开」支持文件夹** — 最近打开的文件夹与文件按时间混排在同一列表（文件夹带专属图标），点击文件夹条目即打开为文件夹栏；列表总量上限 66 条合并计数

**界面与动效**

- **文件树搜索框动画** — 从左往右顺滑展开（220ms）、从右往左顺滑收回（180ms），收回期间不响应误点击
- **排序下拉动画** — 排序菜单从按钮方向顺滑下拉 / 收回，三条关闭路径（点外部 / 点菜单项 / 再点按钮）均走收回动画
- **新建弹窗过渡动画** — 新建文件夹 / 新建文件弹窗打开时 overlay 淡入 + 弹窗上浮缩放（180ms），弹窗本体不做透明度动画
- **底部搜索面板呼出 / 收回动画** — 搜索窗口从底栏搜索按钮顺滑冒出：起点正好贴在按钮上（压扁、并朝按钮那一侧收拢），随后舒展升到屏幕中间落位；关闭时原路压扁缩回按钮
- **文件条目图标** — 文件树中 Markdown 文件为 📝；「打开的文件」面板条目改用自绘「打开的小书本」图标，真实文件为蓝色、未保存的临时文件为黄色，两类条目一眼可辨

**交互调整**

- **移除「文件管理」工具栏全局刷新按钮** — 刷新入口收敛为**右键菜单「刷新」**（右键深层子文件夹只刷新它自己的子树）与 `Ctrl+R`；外部增删改仍自动实时同步到文件树
- **「最近打开」改为纯历史记录** — 关闭文件或文件夹不再移除对应条目；条目只在文件被移动或删除（含外部操作）时显示 ⚠ 提示，**永不自动删除**；重新打开同一路径时提示自动清除。应用启动时恢复的文件夹改用独立的会话快照，与「最近打开」历史彻底解耦（旧版本数据自动兼容）

> 所有动效均使用合成层属性（`transform` / `opacity` / `filter`），不引发布局抖动；系统开启「减弱动态效果」时自动降级为直接显示 / 隐藏。

### 2.2 问题修复

#### v0.8.2（9 项）

- **点击子文件夹导致软件卡死** — 树节点动画容器在渲染期调用 `setState`，展开含子目录的文件夹时触发「渲染 → setState → 再渲染」的无限循环，React 抛 `Too many re-renders` 后整棵侧栏被卸载；现状态更新全部移入 effect。**该崩溃同时是「侧栏偶尔拖不动」与「打开文件夹后打开 md 图片渲染异常」的根因**
- **标题栏「新建 > 新建文件夹」没反应** — 旧实现走原生 `prompt()` + 保存对话框，现改为应用内新建文件夹弹框（居中显示，可勾选已打开文件夹或自定义路径）
- **从文件树打开的 md 图片不渲染** — 根因是 Windows 扩展长度路径前缀 `\\?\` 被转义成 `%3F%2F` 导致资源协议找不到文件；现 Rust 侧统一剥离该前缀，前端再兜一层
- 另有：折叠目录子目录缓存被清空导致收起动画跳变、「打开的文件」栏条目与标签数量 / 选中色不一致、栏标题栏结构与新样式不匹配、关闭文件夹栏快照提前卸载（360ms → 960ms）等

#### v0.8.3（2 项）

- **「打开的文件」栏双高亮** — 栏内点击条目 A 后从标签栏切到 B，A 残留的键盘选中背景与 B 的激活背景同时高亮；现键盘选中项随激活条目变化失效，并把键盘选中指示改为左侧 2px 竖线，任何状态组合下都不会再出现两个高亮块
- **状态栏"行"号恒为 1** — 旧实现用 `doc.textBetween(0, pos).split("\n").length` 算行号，而 `textBetween` 未传块分隔符时不在块之间插入换行，导致行号永远显示 1；现改为结构化行号计算

#### v0.8.4（3 项存量问题 + 2 项同版本迭代）

- **打开深层路径文件时中间目录显示为空** — 展开祖先目录此前只写展开集合、不逐级加载中间层数据；现逐级加载，层级完整展开
- **展开目录 ref 滞后** — 展开目录只靠 `useEffect` 同步 ref，紧随其后的刷新读不到新展开目录；现 `setState` 与 ref 同步双写
- **右键深层子文件夹「刷新」刷错对象** — 此前刷新的是根目录；现以右键目标自身路径调用，仅刷新其子树
- **同目录拖拽排序失效** — 两个根因：子文件夹的子列表容器缺少投放标识，拖到子列表内被最外层区域根截获而误判为「复制 / 移动到根目录」；文件夹根路径可能为反斜杠写法，与前端归一化后的正斜杠写法不一致导致重排静默失效。前者补齐投放标识，后者加入路径归一容错；同时把拖拽准入谓词与自嵌套守卫改为**仅对目录源生效**，消除后续误用风险
- **右键「粘贴」状态不正确** — 右键文件夹节点的菜单此前没有「粘贴」项，且空白区菜单的可用状态取的是"打开菜单那一刻"的快照。现在右键**文件夹节点**也会出现「粘贴」，可用状态改为**实时读取**剪贴板（复制或剪切后恢复可点击，剪贴板为空时置灰）；顺带修复「菜单已打开时右键另一处，菜单被立刻关闭」的交互问题

#### v0.8.5（含三轮同版本迭代）

- **新建弹窗「打开动画期间背景杂乱闪动」** — 根因经逐帧定格复核确认：弹窗本体动画里带了 `opacity: 0 → 1`，而弹窗是不透明方块，淡入前半程背后编辑器 / 文件树的文字会**透过弹窗**显形，同时弹窗还在做 `scale`，透出的背景逐帧位移，观感即"背景在弹窗里杂乱闪动"；此外遮罩也从全透明起步且比弹窗慢，动画第一帧整屏还全亮、随后才压暗，形成一次全屏明暗跳变。修法：弹窗本体**完全不做透明度动画**（第一帧起即为不透明实体），观感由 `transform`（上浮 + 轻微缩放，180ms）承担；遮罩淡入改挂到 overlay 的独立伪元素层。配套把两个弹窗的表单重置由 `useEffect` 改为 `useLayoutEffect`，目标文件夹列表加 `useMemo` 避免多跑一次重置
- **底部搜索面板呼出 / 收回动画重做** — 曾实现过"与窗口同色同边的橡皮尾"，验收后**整体移除尾巴**，相关 DOM、CSS 规则、关键帧与几何变量一并删除；最终改为窗口从底栏搜索按钮顺滑冒出 / 原路缩回，开合瞬间重新测量面板下沿对齐按钮所需的位移与按钮相对面板左沿的位置，方向随窗口位置变化，且**面板只做 `transform`、不做透明度动画**（与新建弹窗同一处理，避免淡入期间背景透出）
- **文件树搜索面板动画方向修正** — 由下拉展开改为**从左往右展开（220ms）/ 从右往左收回（180ms）**，收回期间不响应误点击
- **排序按钮图标对齐优化** — 箭头与字母尺寸统一：时间组箭头缩短、字母大写并与字母对齐成一条水平线；名称组字母改小写、箭头拉长，与竖排徽标等高等宽对齐

### 2.3 快捷键与行为变更（升级请注意）

| 项 | 说明 |
| --- | --- |
| `Ctrl+R` | **新增** — 刷新文件树（外部改动未同步时的兜底） |

## 四、已知范围

1. **标签「固定」状态不跨重启保留**：重启后恢复的是「最近打开」与未保存的临时文件，固定标记与标签顺序不保留
2. **分屏模式的滚动同步仍按百分比**：阅读 / 编辑模式已按编辑锚点对齐，split ↔ textarea 侧保留百分比策略
3. **ePub 中 Mermaid 图表与 KaTeX 公式不会渲染**：ePub 阅读器不执行脚本，二者以源码 / 占位形式呈现
4. **LaTeX 导出的字符转义**：`\href` 的 URL 与图片路径未做全量特殊字符处理；代码块含中文注释时请使用 XeLaTeX 编译
5. **手动排序与最近打开等偏好存于本机**（localStorage / 应用数据目录），换机不迁移
6. **文件系统实时监听在部分场景不可用**（网络盘、极端权限目录）：此时自动提示，并保留右键「刷新」/ `Ctrl+R` 兜底
