# LightMD v0.9.4 发布说明

**发布日期**：2026-10-01
**基线版本**：v0.9.3
**主题**：显示与粘贴补课——行内语法标记显示、Markdown 感知粘贴、撤销历史跨模式边界、代码块语言下拉与换行开关
**实现依据**：《LightMD 0.9.1 全方位测评报告》v0.9.4 任务卡（E6 / E9 / E12 / E17）；技术细节见 `.trae/documents/lightmd-p1-remediation-plan.md`

## 一、新增

### 1.1 行内语法标记显示（E6，本档最大单项）

此前阅读模式只有**标题 / 引用 / 代码块**三种块级节点在光标所在处显示源码前缀，列表标记、`$$`、`![]()` 以及**所有行内标记**（`**`、`*`、`` ` ``、`~~`、`==`、`~`、`^`、`<u>`）从不显示，用户常想不起来某段是不是加粗、链接指向哪里。

现在：**光标进入某个行内标记区间（含紧邻边界）时，该区间两侧即时显示对应 Markdown 源码符号**，移出即隐藏——向 Typora「光标所在元素显示源码」的语义靠拢。

| 标记 | 光标进入时显示 |
| --- | --- |
| 加粗 / 斜体 / 删除线 / 高亮 / 上下标 / 下划线 | `**` `*` `~~` `==` `~` `^` `<u>` |
| 行内代码 | `` ` `` |
| 链接 | `[` … `](https://完整地址)`（过长时截断，鼠标悬停可见完整地址） |

- 实现方式为 `Decoration.inline` + CSS 伪元素，**不新增可编辑 DOM 节点**，撤销 / 重做后状态自动跟随；
- **性能**：仅扫描光标所在文本块（O(块内)），不做全文档遍历；
- 与既有块级前缀显示并存互补；有选区时不显示（与块级行为一致）。

### 1.2 Markdown 感知粘贴 + 富文本粘贴（E9）

此前全项目无剪贴板转换：粘贴 Markdown 文本按纯文本处理，粘贴网页富文本只能靠结构降级（表格 / 任务列表易丢）。

现在粘贴按优先级处理：

1. **图片 / 文件**：仍走原有图片处理（保存到 assets 或转 Base64），不受影响；
2. **代码块 / 公式内**：一律字面粘贴，不做转换；
3. **富文本（text/html）**：转换 Markdown 后还原为真实结构（标题 / 列表 / 表格 / 粗体 / 链接…）；
4. **纯文本（text/plain）**：命中 Markdown 特征（标题 / 列表 / 引用 / 围栏 / 粗体 / 斜体 / 删除线 / 行内代码 / 链接 / 表格 / 分隔线）**≥2 项**时按 Markdown 解析，否则保持字面粘贴；
5. 转换异常一律降级为字面粘贴，不阻塞。

设置 → 编辑器新增开关「**粘贴 Markdown 自动转换**」（默认开启）。

### 1.3 撤销历史跨模式边界优化（E12）

- **消除空撤销步骤**：此前「阅读 → 源码 → 不改 → 阅读」会因整树替换写入一条无意义的撤销记录；现在内容一致时跳过替换，撤销链不再被空步骤占用；
- **撤销历史不再被误清空**：此前「阅读 → 源码」无条件清空源码模式差异栈；现在仅在文档确有变化（旧栈基线失效）时才清空，"切一圈回来"历史仍然保留；
- **撤销边界明确提示**：源码模式撤到底再按 `Ctrl+Z` 此前是静默无反应，现在给出「已到本模式撤销边界」提示。

### 1.4 代码块语言下拉 / 自动换行 / 高亮语言（E17）

- **语言下拉**：代码块右上角新增语言下拉（默认"自动检测"），切换即改写文档语言标识并即时重新高亮；源码模式序列化同步保留（如 ` ```python `）；
- **自动换行开关**：设置 → 编辑器新增「代码块自动换行」（默认开启）。关闭后代码块改为横向滚动，高亮层与编辑层**同步切换并联动横向滚动**，不会错位；
- **高亮语言**：静态注册语言由 27 种扩到 **34 种**（新增 TOML / Docker / INI / GraphQL / Makefile / Diff），README 文案与实际注册数对齐（此前宣称"200+ 语言"为 PrismJS 上游理论值）。

## 二、兼容性

- 设置、快捷键、会话等数据格式不变，从 0.9.3 覆盖安装即可；新增 2 个设置项默认值与既有行为一致（粘贴转换开、自动换行开）；
- 旧文档解析 / 序列化行为零变化：行内标记显示、粘贴转换均为纯交互层能力，不写回文档；
- 代码块语言下拉会写回 `language` / `info` 属性——仅在用户主动切换时发生。
