## 二、版本内容

本版合计交付 **9 项新增/细化功能 + 2 项功能调整 + 3 项存量问题修复**（基线 0.8.3，需求编号沿用实施计划）。

### 新增功能

1. **文件夹/文件拖拽复制与移动（需求 1）**：文件与子文件夹均可拖拽，默认复制、按住 Shift 移动；移动支持跨盘（自动降级复制+删除）；拖拽悬停自身子文件夹不再显示可投放高亮（防误操作）。
2. **同目录拖拽排序（需求 3）**：把文件拖到所在目录的其他位置即可手动排序，顺序持久保存、重启保持；重命名文件顺序自动跟随；手动排序与排序模式互斥（激活排序时拖拽自动切回手动）。
3. **树内右键复制/剪切（需求 2）**：任意文件/子文件夹右键可直接复制、剪切，配合粘贴完成跨目录操作。
4. **空白处右键菜单（需求 8）**：文件夹空白区域右键新增"新建文件 / 新建文件夹 / 刷新"，与原有"粘贴"合并为四项菜单。
5. **新建文件居中弹窗（需求 5/9）**：新建文件改为应用内居中弹窗（不再使用系统原生 prompt），默认名自动避让重名、无扩展名自动补 `.md`、目标目录只读展示、重名错误内联提示。
6. **标题栏排序（需求 7）**：每个文件夹区域标题栏新增排序按钮，支持文件名（A-Z/Z-A）、修改时间、创建时间 × 升/降序共 6 种模式；文件与文件夹混排，整棵树统一生效；模式按文件夹记忆、重启保持；再次点击激活项取消排序。
7. **文件树实时刷新（需求 10）**：基于文件系统监听，外部（资源管理器/其他程序）对已打开文件夹的增删改自动同步到文件树，无需手动刷新；后端 200ms + 前端 300ms 双层去抖，保存文件不引发刷新风暴；网络盘等监听不可用场景自动提示并保留右键/工具栏刷新兜底。
8. **大纲栏搜索（需求 11）**：鼠标悬停大纲栏顶部平滑出现搜索框，实时过滤标题（大小写不敏感包含匹配）；输入/聚焦期间移出鼠标不收起；过滤态自动禁用拖拽手柄。
9. **最近打开 stale 提示（需求 1b）**：移动处于打开状态的文件后，"最近打开"旧条目保留并标记淡黄 ⚠（悬停提示"该文件可能已变更位置或删除"），新位置生成新条目；外部删除文件同样触发标记；收藏夹条目同步标记。

### 功能调整

1. **展开/收起动画垂直化（需求 6）**：文件夹展开改为顺滑向下展开、收起顺滑向上收回（原水平滑入/滑出改为轻微下沉/上浮 + 淡入淡出）。
2. **刷新入口收敛**：移除文件夹标题栏刷新按钮（实时刷新已覆盖）；工具栏全局刷新、Ctrl+R、空白右键"刷新"全部保留。
3. **新建文件夹/文件后立即刷新**：修复新建后目录展开但内容为空的时序问题（S2）。
4. **深层文件夹右键"刷新"修复（S7）**：右键子文件夹刷新时只刷新该子树，不再误刷整个区域。

### 存量问题修复

- **S1**：「打开所在文件夹工作区」时深层文件定位后显示"空文件夹"——现逐级加载中间目录，层级完整展开。
- **S2**：向未展开的子目录新建文件/文件夹后内容为空，需手动刷新——已修复。
- **S7**：右键深层子文件夹"刷新"刷错对象——已修复。

### 其他

- 版本号四处同步 0.8.3 → 0.8.4（package.json / tauri.conf.json / Cargo.toml / Cargo.lock）。
- 新增 Rust 依赖 `notify = "6"`（文件系统监听）。
- 新增测试 11 个文件（v0.8.4-*.test，共 100+ 用例），全量回归 158 文件 / 2841 用例通过，`cargo test` 90 用例通过，`tsc --noEmit` 零错误。
