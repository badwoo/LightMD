## 二、版本内容

本版合计交付 **16 项用户需求/修复**（划分 WP1–WP6 六个工作包），并在发版前质量评审与三轮追加反馈后完成全部修复。

### 2.1 新增功能

#### F1 · 临时文件（未命名标签）

- `Ctrl+N`、侧边栏 📄 按钮或**双击标签栏空白处**均可新建临时文件，**不再立即写盘**
- 首次 `Ctrl+S` 时才弹出保存位置；保存成功后临时标签自动「转正」为磁盘文件
- 未保存的临时文件在重启后恢复（受「启动时恢复上次打开文件」开关控制）
- 侧边栏「打开的文件」面板合并显示临时标签；新建后自动聚焦编辑器、按 Markdown 处理并显示大纲

#### F2 · 标签栏增强

- **溢出滚动**：标签过多时出现左右滚动按钮，点击按「一个标签」为单位平滑滚动（rAF 缓动）；鼠标滚轮横向滚动同样支持
- **切换标签自动滚入可视区**
- **固定标签页**：右键固定，显示图钉图标并固定排在最前；批量关闭时可选「关闭固定标签页以外所有」
- **右键菜单 9 项**：重命名 / 固定 / 打印 / 另存为 / 关闭其他 / 关闭固定以外 / 关闭左侧 / 关闭右侧 / 关闭所有未修改
- **打印**：自动先切到阅读模式并等待渲染完成，只输出正文（修复「打印到上一个标签」与「编辑模式被截断」）
- 关闭按钮改为常驻占位 + `opacity` 切换，修复 hover 时标签抖动

#### F3 · 文件操作增强

- **复制 / 剪切 / 粘贴**：右键菜单或 `Ctrl+C` / `Ctrl+V`，写入应用内存剪贴板（不占用系统剪贴板）；剪切后粘贴即移动
- **拖拽**：拖到文件夹即复制，按住 `Shift` 拖拽为移动（标签与全局文件路径自动同步）
- **重名自愈**：目标已存在同名文件时自动生成「 - 副本N」
- **删除联动关标签**：删除文件或父文件夹时，对应标签自动关闭并同步活跃标签、最近文件与滚动进度
- **新建文件夹弹框**：可多选目标目录，也可手填自定义路径（优先），部分失败时列出明细
- **打开所在文件夹工作区**：标签 / 文件 / 最近记录三处入口
- 文件夹区域头部新增 ➕ 新建入口

#### F4 · 侧栏布局重做

- 分区标题栏拖拽语义重做：拖动的是「本区上边界」，与上方相邻区域高度**此消彼长、总高守恒**；最下方区域可一直拖到底部填满侧栏
- 关闭末区后上一区自动撑满；重新打开新区域时新区域紧跟上一区出现（用户手动拖过的高度会被尊重）
- 各分区高度持久化，重启后保留
- 新增**浮动滚动箭头**（呼吸动画、悬停显形、支持点击与滚轮）
- 滚动条收细至 `1.2px` 并默认透明，悬停才显形

#### F5 · 导出 ePub / LaTeX

- **ePub**：按标题拆分章节，生成 `mimetype`（STORE 无压缩）/ `container.xml` / OPF / nav 目录，图片转为二进制打包；章节 XHTML 做规范化（`<br>` / `<img>` / `<hr>` / `<input>` 正确自闭合），严格阅读器（epubcheck 级别）可打开；内嵌样式覆盖正文/代码块/引用/表格/图片
- **LaTeX**：自研转换器，输出 ctexart 文档类 + XeLaTeX 可编译源码（支持中文）；与 Word 导出共用中间结构 `exportBlocks`
- 导出对话框新增格式网格与说明文案，中英双语

#### F6 · 编辑体验

- **中文标点自动补全**：新增 `「」『』《》【】（）` 等成对补全，`Backspace` 成对删除，且跳过行内代码与行内公式区间
- **跳过已有右符号（overtype）**：紧邻右侧已有相同字符时只移动光标（修复「输入两个双引号变出四个」）
- **模式切换锚点定位**：阅读 ↔ 编辑 ↔ 分屏互切时按当前编辑位置同比例对齐，不再跳到无关位置（并修复锚点跨文件残留）
- **打字机模式开启即时居中**

## 四、已知范围（本版未做）

1. **标签「固定」状态不跨重启保留**：重启后恢复的是「最近打开的文件」与未保存的临时文件，固定标记与标签顺序不保留
2. **分屏模式的滚动同步仍按百分比回退**：阅读 / 编辑模式已按编辑锚点对齐，split ↔ textarea 侧保留百分比策略
3. **LaTeX 导出的字符转义**：`\href` 的 URL 与图片路径未做全量特殊字符处理（`%` / `#` / `&` / 空格 / 中文路径）；代码块含中文注释时请使用 XeLaTeX 编译
4. **分栏高度按文件夹路径存键**，长期使用会使设置对象持续增长（不影响功能）
5. **ePub 中 Mermaid 图表与 KaTeX 公式不会渲染**：ePub 阅读器不执行脚本，二者以源码 / 占位形式呈现（内嵌样式仅覆盖正文、代码块、引用、表格与图片）

- 覆盖安装即可，用户设置与历史版本快照保留
- 首次使用请注意快捷键变更（版本快照改为 `Ctrl+Alt+V`）
- 若习惯用 `Ctrl+N` 直接落盘建文件，改用侧边栏「新建文件」或新建后立即 `Ctrl+S`
