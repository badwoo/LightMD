# LightMD v0.9.0 发布说明

**发布日期**：2026-09-27  
**基线版本**：v0.8.5  
**主题**：对等多窗口 —— 独立标签·全局同步·冲突检测·会话恢复  
**实现依据**：`.trae/documents/LightMD_MultiWindow_PRD_v0.9.0.md` + `.trae/documents/lightmd-v0.9.0-implementation-plan.md`

---

## 一、版本内容

### 1.1 对等多窗口（Peer Window）

**窗口模型**

- 每个窗口拥有**独立的标签页集合、编辑器状态、浏览进度、AI 对话窗**；主题 / 字体 / 侧栏宽度 / AI 配置 / 最近打开 / 收藏夹在**所有窗口间实时同步**。
- 窗口上限 **8 个**（`main` + `sec-1` ~ `sec-7` 固定槽位），超出时 toast 提示。
- 关闭主窗口后由**最老的辅助窗口自动晋升**为主窗口，应用不退出；关闭最后一个窗口才退出。

**打开入口**

| 入口 | 行为 |
| --- | --- |
| 文件树右键 →「在新窗口中打开」 | 新建窗口并打开该文件 |
| 标签右键 →「移动到新窗口」 | 原窗口关闭该标签，新窗口打开（临时标签连内容一起迁移） |
| `Ctrl+Shift+N` / 标题栏「窗口」菜单 / 命令面板 | 新建空白窗口 |
| `Ctrl+Alt+O` / 命令面板 | 选择文件并在**新窗口**打开 |
| 双击 `.md` 等关联文件 | 按设置「外部文件打开方式」路由（当前窗口 / 新窗口 / 每次询问） |

**标题栏「窗口」菜单**：动态窗口列表（显示每个窗口的标签与未保存圆点），点击窗口项激活该窗口，点击标签子项**激活窗口并切换标签**；另有「新建窗口」「关闭当前窗口」「合并到主窗口」。

### 1.2 状态隔离与同步

- **窗口级**（严格隔离）：编辑器标签与活跃标签、视图模式、光标选区、临时（未命名）标签、上次活跃标签、浏览进度、AI 对话窗、侧栏打开的文件夹、冲突检测登记。
- **全局级**（实时同步）：主题、字体、侧栏/大纲宽度、分屏比例、AI 配置、文件树排序、最近文件/文件夹、收藏夹、会话文件夹快照。
- 同步实现为 Tauri 事件广播 + 对端 `rehydrate`，广播携带 `sourceWindowId` 自忽略，并对同一 tick 内的多次变更做合并，无乒乓风暴。
- **零迁移**：主窗口沿用 v0.8.5 的无后缀 localStorage key，老数据原地可用；辅助窗口使用 `-sec-N` 后缀。

### 1.3 文件冲突与外部变更

- 打开文件前查询「是否已在其他窗口打开且含未保存更改」：是则弹**应用内四选一对话框**（只读打开 / 强制编辑 / 切换到已有窗口 / 取消）。
- **只读打开**：编辑器不可编辑，标题栏显示 `[只读]`，仍可阅读、复制、导出。
- **强制编辑**：两个窗口均可编辑；若保存前检测到磁盘已被外部修改，弹「覆盖 / 另存为 / 取消」。
- **文件级监听**（上限 50 个文件）：干净标签被外部修改时自动重载并提示；脏标签只打标记并在保存时确认；文件被删除时自动关闭对应标签。
- 目录 watcher 改为**按窗口引用计数**：多个窗口打开同一目录只注册一个 watcher，最后一个窗口关闭才注销。

### 1.4 AI 任务按窗口分桶

- 划词翻译 / AI 续写 / 润色 / 摘要 / 对话的单任务槽**按窗口隔离**：窗口 A 发起的任务不再顶掉窗口 B 的任务；同一窗口内新任务仍自动取消旧任务（v0.6.0 语义不变）。
- 全文翻译并发槽同时记录所属窗口，取消本窗口任务不会误杀其他窗口正在跑的批次。
- 窗口关闭时清理本窗口任务槽，不留孤儿流式请求。

### 1.5 多窗口会话恢复

- 会话文件 `%APPDATA%\com.lightmd.app\session.json` 记录**退出时仍存活的窗口**的标签、活跃下标与打开的文件夹；**不存窗口几何**（由 `tauri-plugin-window-state` 按固定槽位 label 负责，跨会话自动复用）与**不存未保存正文**（与 v0.8.5 一致）。
- **用户主动关闭的窗口不会在下次启动时复活**：窗口关闭的那一刻它就从会话快照中移除（用户反馈修正）。
- 新增显式退出动作「**退出 LightMD**」（标题栏「窗口」菜单 / 命令面板 / `Ctrl+Q`）：此时所有窗口仍存活，会记录**完整窗口集合**。
- 新增设置「**启动时恢复其他窗口**」（设置 → 通用，位于「外部文件打开方式」下方，默认**关闭**）：
    - **关闭**（默认）：重启只恢复主窗口（主窗口的标签与打开文件夹仍按会话精确恢复）；
    - **开启**：把上次退出时仍存活的全部窗口一并恢复。
- 「启动载入上次文件」关闭时**不恢复任何窗口与标签**，且不残留会话文件。
- 纯单窗口会话不写会话文件，行为与 v0.8.5 一致。

### 1.6 新增快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Shift+N` | 新建窗口 |
| `Ctrl+Shift+W` | 关闭当前窗口（`Ctrl+W` 仍是关闭标签） |
| `Ctrl+Alt+O` | 打开文件到新窗口（`Ctrl+Shift+O` 已被「切换大纲栏」占用） |
| `Ctrl+Q` | 退出 LightMD（记录完整窗口集合，供「恢复其他窗口」下次还原） |

### 1.7 设置

- 设置 → 通用新增「**外部文件打开方式**」：当前窗口（默认）/ 新窗口 / 每次询问。
- 设置 → 通用新增「**启动时恢复其他窗口**」：关闭（默认，只恢复主窗口）/ 开启（恢复全部仍存活的窗口）。

## 二、用户反馈修复（v0.9.0 实机验证阶段）

| # | 反馈现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 「在新窗口打开文档 → 关掉新窗口 → 重启后又冒出那个已关闭的窗口」 | 会话快照为满足「多窗口恢复」把**已关闭窗口**也一并记录 | 快照只记录退出时仍存活的窗口；新增「启动时恢复其他窗口」开关（默认关）+「退出 LightMD」显式退出动作 |
| 2 | 「按快捷键保存却提示文档已被外部修改，弹覆盖/另存为，之后每次保存都跳黄色提示」 | 文件监听把**应用自己保存**产生的事件当成外部修改：保存 → 误判 → 覆盖 → 再误判，无限循环 | Rust 侧 `write_file` 写盘后登记新 mtime，watcher 据此去重自身写入（覆盖手动保存/自动保存/版本回滚/另存为全部调用点） |
| 3 | 「只有临时文件未保存时，关闭软件也弹保存确认」 | 关闭确认把所有 `isDirty` 标签都算进去 | 关闭窗口/退出应用只对**已落盘且未保存**的文件确认；临时标签由窗口级 localStorage 记忆、下次启动自动恢复，且不参与版本快照，不再拦截 |

顺带加固：重命名/移动文件产生的「移出」事件不再被误判为删除（关闭标签前先确认文件确实不存在）。

## 二、兼容性

- **向后兼容**：不创建辅助窗口时，v0.8.5 的全部行为（标签、AI、导出、快照、搜索、实时刷新、启动恢复）完全一致。
- **数据迁移**：`lightmd-settings` / `lightmd-file-store` 结构不变；新增字段缺省即默认值。v0.8.5 的临时标签、上次活跃标签、滚动进度等主窗口数据**原地可用**。
- **降级**：从 v0.9.0 降级回 v0.8.5 时，辅助窗口的 `-sec-N` 数据被忽略，主窗口数据正常读取。

## 四、验证情况

- **前端单测**：176 个文件 / 3065 个用例全绿（含 114 个 v0.9.0 新增用例）
- **Rust 单测**：135 个用例全绿
- **实机功能测试**：在生产等价构建（`cargo build --features tauri/custom-protocol`，嵌入前端产物）上通过 WebView2 DevTools Protocol + Win32 窗口枚举完成端到端验证，覆盖 AC-1 ~ AC-18 与 REG-1 ~ REG-8；用户反馈的三个问题单独做了 24 项实机断言，**全部通过**。详见 `.trae/documents/lightmd-v0.9.0-test-report.md`

实机测试期间发现并修复的缺陷（均已补充回归用例）：

1. **定向事件跨窗口泄漏**：Tauri v2 的 `emit_to(label)` 只过滤监听器注册目标，JS 侧 `listen()` 注册目标为 `Any`，导致所有窗口都会收到本该只发给某一个窗口的事件 —— 表现为「关闭主窗口时所有窗口一起关闭」「双击一个文件时每个窗口都打开它」。已改为 `{ target, payload }` 信封 + 前端按 label 过滤。
2. **路径分隔符不一致**：Rust 事件中的路径为正斜杠，而「用原生文件对话框打开」的标签存的是反斜杠，导致 `getTabByPath` 匹配失败、外部修改/删除联动静默失效。已引入 `pathCompareKey`（分隔符 + 大小写归一）统一比较。
3. **自身写入被误判为外部修改**：见「用户反馈修复」第 2 条（保存即弹覆盖框、之后每次保存都跳黄色提示）。
4. **已关闭窗口复活**：见「用户反馈修复」第 1 条。

## 五、升级提示

- 从 v0.8.5 覆盖安装即可，无需卸载；设置、最近打开、收藏夹、临时标签全部保留。
- 首次使用多窗口时，建议在设置中确认「外部文件打开方式」符合习惯（默认与 v0.8.5 一致：当前窗口）。
