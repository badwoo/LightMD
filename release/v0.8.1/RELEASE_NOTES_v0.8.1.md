## 二、版本内容

本版合计交付 **6 项交互体验优化**（基线 0.8.0）。

### 2.1 新增功能 / 优化

#### O1 · 去掉原生标题栏

- 窗口改为**无边框一体化外观**，最小化 / 最大化 / 关闭三键移到右上角设置按钮旁
- 采用 macOS 交通灯配色（黄 / 绿 / 红），悬停显示操作符号
- 顶部省下一条系统横条，界面更紧凑

#### O2 · 默认最大化启动

- 打开应用即**最大化**（保留任务栏），还原后为 1200×800

#### O3 · 侧栏滚动条统一收细

- 左右两侧栏（文件树 / 大纲）滚动条统一为 **2px** 细线
- 静止时透明、悬停该栏才以浅色显形，尽量不干扰阅读

#### O4 · 默认栏宽各加宽 0.5cm

- 左侧栏 260 → **279px**、右侧大纲栏 240 → **259px**
- 已手动调整过宽度的用户保持原值

#### O5 · 文件属性改为应用内对话框

- 不再调用系统原生弹窗，**彻底消除提示音**
- 路径等信息可选中复制

#### O6 · 固定 AI 入口时底栏平滑居中

- 勾选「固定」后 AI 抽屉常驻占位，底栏整组按钮顺滑重排居中
- 不再遮挡右侧字数统计
