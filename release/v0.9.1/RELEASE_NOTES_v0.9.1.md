**实现依据**：用户提交的 6 项需求/缺陷；技术细节与实测数据见 `.trae/documents/lightmd-v0.9.1-implementation-report.md`

## 一、修复

### 1.1 `Ctrl+,` 打不开设置（根因在输入法，不在应用）

**现象**：任何时候按 `Ctrl+,` 都没有反应；用鼠标（标题栏菜单 / 命令面板）能正常打开设置。

**定位**（真实硬件级按键注入 + 页面内 keydown 取证）：中文输入法（微软拼音等）把 `Ctrl+,` 当**输入法保留键**在消息进入应用之前消费掉——页面只能收到 `Ctrl` 的 keydown，**逗号的 keydown 根本不存在**。对照实验里 `Ctrl+F` / `Ctrl+P` / `Ctrl+;` 都能正常到达页面，只有 `Ctrl+,` 与 `Ctrl+.`（微软拼音「中/英文标点切换」）被吞。

**修法**：在原生层用系统热键（`RegisterHotKey`）把该组合抢回来——它注册在 win32k 的原始输入层，位于输入法与所有用户态钩子之前。只在**本应用处于前台**时注册，失焦立即注销，因此不影响其它程序与输入法；抢到后转成应用内事件，仍按当前生效键位复核（用户把「打开设置」改绑到别的键后，`Ctrl+,` 不再触发设置）。

> 附带修掉同源问题：WebView2 默认接管 `F11` / `Ctrl+P` / `Ctrl+F` 等**浏览器加速键**，页面里的按键处理从不执行（真实 `F11` 走的是 WebView2 自带全屏）。现已关闭该接管，按键原样交给应用。

### 1.2 打开设置瞬间"背景杂乱、不平滑"

**根因**：遮罩原本挂在弹窗容器本体上做淡入，**父元素的透明度会把弹窗整棵子树作为一组合成**——半透明期间背后的编辑器文字透过弹窗显形，又随弹窗的 20px 位移逐帧移动；遮罩自身还从全透明起步，第一帧整屏仍亮。

**修法**：遮罩移到独立 `::before` 层（只动一个纯色层的透明度），弹窗本体只做一次淡入 + 8px 上浮，且遮罩淡入比弹窗更快。背景不再透出，第一帧不再整屏跳亮。

### 1.3 其它修复

- **快捷键弹窗被压成 520px 宽**：该弹窗是 `position: fixed` 全屏覆盖层，原渲染在带 `transform` 的设置弹窗内部，被当成"包含块"压成设置弹窗尺寸（实测 519×983）。现改为与设置弹窗平级渲染，并阻止点击冒泡误关设置弹窗。
- 设置弹窗 `Esc` 现在可以关闭（此前只能点 ✕ / 取消）。

## 二、新增与优化

### 2.1 设置弹窗淡入淡出

打开/关闭都有动画；关闭走「延迟卸载」（先播 160ms 淡出 + 轻微下沉，动画结束才真正卸载），不会出现"动画被卸载截断"的生硬感。

### 2.2 自定义快捷键弹窗改为横向 3×3

- 由单列纵向滚动列表改为 **3 列 × 最多 3 层分类卡片**，按各分类条目数均衡分列：

| 列 | 分类（条目数） | 视觉高度 |
| --- | --- | --- |
| 1 | 格式 (15) + 插入 (2) | 19 行 |
| 2 | 视图 (10) + 编辑 (8) | 20 行 |
| 3 | 文件 (5) + 窗口 (5) + 标签 (3) | 16 行 |

- 弹窗加宽到 **1180px**、行高压缩到 26px：**48 条快捷键一屏全部可见**，不再需要滚动；分类卡片带浅底与描边，7 个分组边界一眼可辨；
- 窄窗口自动降级：≤1120px 两列、≤760px 单列。

### 2.3 快捷键弹窗开启/关闭动画

开启时以**窗口横轴中线**为轴上下平滑铺开，关闭时上下沿中线平滑收缩。用 `clip-path` 裁切而不是 `scaleY` 缩放，文字与键帽不会被压扁拉伸；动画挂在覆盖层上，弹窗投影保持完好。

### 2.4 `F11` 沉浸式全屏（按需求重做）

```
按下 F11
  → 屏幕中央出现大字「全屏模式」
  → 大字消失后，窗口进入系统全屏
  → 上栏（标题栏 + 标签栏）、左栏（文件树）、右栏（大纲）、下栏（状态栏）同时自动收起
  → 整个窗口只剩中间的文档内容
再按 F11 或 Esc → 立即退出，四栏恢复
```

- 面板收放用根节点 class 控制，**不改写侧栏/标签栏自身的折叠状态**：退出即一键复原，不污染用户已有的折叠偏好；
- 进入沉浸态会先关闭屏幕上残留的模态弹窗，保证"只有中间文档内容"；
- 系统开启「减少动态效果」时，大字与面板动画自动降级。

## 三、兼容性

- 设置、快捷键自定义、最近打开、收藏夹、会话等数据格式**完全不变**，从 0.9.0 覆盖安装即可；
- 新增的原生能力仅作用于 Windows 平台；`Ctrl+,` 热键只在本应用前台期间占用，退出/失焦立即释放；
- 命令面板「窗口全屏」、菜单等鼠标入口行为与 `F11` 一致。
