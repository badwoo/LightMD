## 二、版本内容

### 2.1 新增功能

**v0.9.0（2026-09-27）· 对等多窗口 + 自定义快捷键**

- **对等多窗口（最多 8 个）** — 每个窗口拥有**独立的标签页、编辑器状态、浏览进度与 AI 对话窗**；主题、字体、侧栏宽度、AI 配置、最近打开、收藏夹在所有窗口间**实时同步**
- **多入口在新窗口打开** — 文件树 / 「打开的文件」右键「在新窗口中打开」；标签右键「移动到新窗口」（临时标签连内容迁移）；**按住标签拖出标签栏**直接移到新窗口；`Ctrl+Alt+O` 选择文件并在新窗口打开；双击关联文件按设置路由
- **标题栏「窗口」菜单** — 动态列出各窗口及其标签（含未保存圆点），可切换 / 新建 / 关闭当前窗口 / 合并到主窗口；把辅助窗口或其标签拖到主窗口标签栏可**合并回主窗口**
- **文件冲突检测与外部变更** — 同一文件已在其他窗口打开且有未保存修改时，可选「只读打开 / 强制编辑 / 切换到已有窗口 / 取消」；文件级监听让干净标签自动重载、脏标签标记待确认；同文件多窗口**双向即时刷新**；目录 watcher 按窗口引用计数
- **AI 任务按窗口分桶** — 窗口 A 的翻译 / 续写 / 润色 / 摘要 / 对话不再顶掉窗口 B 的任务
- **多窗口会话恢复** — 会话快照记录各窗口标签与打开文件夹；新增「启动时恢复其他窗口」开关（默认关闭）与「退出 LightMD」（`Ctrl+Q`）显式退出动作
- **自定义快捷键** — 全部快捷键按分类改键，冲突拦截、单项 / 一键恢复默认；键位显示在命令面板、右键菜单、提示中同步更新，并在多窗口间同步
- 新设置：「外部文件打开方式」「启动时恢复其他窗口」

**v0.9.1（2026-09-30）· 设置与快捷键体验**

- `F11` **沉浸式全屏重做** — 大字提示 → 进入系统全屏 → 上 / 左 / 右 / 下四栏自动收起，只剩文档内容；`Esc` 或再按 `F11` 退出
- 设置弹窗淡入淡出 + `Esc` 关闭，出现瞬间背景不再透出闪动
- 自定义快捷键弹窗改为 **3×3 分类卡片布局**，全部快捷键一屏可见，带开启 / 关闭动画

**v0.9.2（2026-10-01）· 编辑缺陷清零**

- 段内换行语义设置（GFM 即换行 / CommonMark 行尾两空格），读取、预览与全部导出跟随
- 「最近打开」默认收起；标题栏文件名在整体标题栏居中（偏差 0px）

**v0.9.3（2026-10-01）· 输入与格式补课**

- **下划线** `Ctrl+U`（源码模式插入 `<u></u>`）与 **插入链接** `Ctrl+Shift+K`
- **六类输入规则（打字即所得）** — `$公式$`、`$$` 块级公式、`[文本](url)` 链接、`![alt|300](src)` 图片、`[^1]` 脚注引用与 `[^1]:` 定义、`[toc]` 自动目录、两行表格语法
- **HTML 最小白名单** — `<u>` `<br>` `<sub>` `<sup>` `<mark>` 解析为对应格式，其他行内标签剥离后保留内容，块级 HTML 字面保留
- **图片体验** — `![alt|300](src)` 尺寸语法、编辑对话框新增替代文本与宽度、拖入图片落点即插入位置

**v0.9.4（2026-10-01）· 显示与粘贴补课**

- **行内语法标记显示** — 光标进入加粗 / 斜体 / 删除线 / 高亮 / 上下标 / 下划线 / 行内代码 / 链接等行内标记区间时，两侧即时显示对应 Markdown 源码符号，移出即隐藏
- **Markdown 感知粘贴** — 富文本自动转换为真实结构；纯文本命中 Markdown 特征 ≥2 项才按 Markdown 解析；代码块 / 公式内一律字面粘贴
- **撤销历史跨模式优化** — 不再产生空撤销步骤、不再误清空历史，源码模式撤到底有明确提示
- **代码块语言下拉与自动换行开关** — 切换语言即时重新高亮；内置高亮语言 27 → 34 种

**v0.9.5（2026-10-02，本版）· 正确性与性能收尾**

- **任务项与脚注内容模型无损化** — 任务项内的嵌套列表 / 多段落 / 代码块不再被压平，多段落脚注保持分段，可直接在编辑器内编辑
- **专注模式性能** — 装饰集合缓存进插件状态，大文档判定 O(1)，重算只在活跃块附近局部遍历；十万字符级文档打字不再卡顿
- **Mermaid 渲染缓存** — 按内容比对命中缓存，选区移动、拖拽表格等无关操作不再触发完整重渲染
- **文档内链接点击跳转** — 相对 / 绝对路径打开目标文档、`#锚点` 平滑滚动、外链交给系统默认浏览器；分屏预览内同样生效

### 2.3 快捷键与行为变更（升级请注意）

| 快捷键 | 说明 |
| --- | --- |
| `Ctrl+Shift+N` / `Ctrl+Shift+W` | **新增** — 新建窗口 / 关闭当前窗口 |
| `Ctrl+Alt+O` | **新增** — 选择文件并在新窗口打开 |
| `Ctrl+Q` | **新增** — 退出 LightMD（只记录主窗口） |
| `Ctrl+U` / `Ctrl+Shift+K` | **新增** — 下划线 / 插入链接（`Ctrl+K` 已被 AI 对话占用） |
| `Ctrl+T` / `Ctrl+Alt+T` | **新增** — 插入任务列表 / 插入表格 |
| `Ctrl+Alt+←` / `Ctrl+Alt+→` / `Ctrl+Shift+B` | **新增** — 左侧栏 / 大纲栏 / 标签栏展开收起 |
| `F11` | **重做** — 沉浸式全屏（大字提示 → 系统全屏 → 四栏自动收起） |
| `Ctrl+Alt+S` | 阅读模式删除线统一为该键（0.9.0 起，原 `Ctrl+Shift+S` 让位「另存为」） |
| 其他快捷键 | 均可在 **设置 → 编辑器 → 自定义快捷键** 中改键 |

行为变化：

1. **多窗口**：不创建辅助窗口时，行为与 v0.8.5 完全一致；会话恢复默认只恢复主窗口
2. **「最近打开」默认收起**，点击侧栏顶部时钟图标展开
3. **段内换行**默认 GFM（即换行），与历史版本一致；切换为 CommonMark 后需重新打开文档生效
4. **表头行不再提供「删除行」**；列表项 / 引用内输入 `---`、``` ``` 不再被转换
5. 行内语法标记显示、粘贴转换为纯交互层能力，不写回文档
6. **导出 HTML 中此前被转义的 HTML 现在按原样渲染**（0.9.3 起，与 Typora 惯例一致）——请仅对可信文档使用

## 四、已知范围

1. **任务项内嵌套内容若「普通列表与子任务交错」**，保存时子块顺序规范化为「嵌套任务列表在前」（内容无损，未编辑的块逐字节保留原文）
2. **空脚注（无内容定义）** 需存在正文引用才会在重新打开后还原为脚注结构（markdown-it-footnote 既有行为）
3. **导出 HTML 按原样渲染 HTML**（0.9.3 起），文档含 `<script>` 等标签时会在导出文件中生效——请仅对可信文档使用
4. **人工验收项**（原生对话框无法自动化）：另存为全流程、另存为 `.py` 后高亮切换、临时文件图片持久化全流程
5. 沿用自 v0.8.5：标签「固定」状态不跨重启保留；分屏模式滚动同步按百分比；ePub 中 Mermaid / KaTeX 不渲染；LaTeX 导出的特殊字符转义有限

## 五、升级说明

- 从任意 0.8.x / 0.9.x 版本直接覆盖安装即可，设置、收藏、最近打开与历史版本快照全部保留
- **零迁移**：不创建辅助窗口时，v0.8.5 的全部行为与数据完全一致（主窗口沿用原有无后缀数据文件，辅助窗口使用 `-sec-N` 后缀）
- 从 v0.9.0 降级回 v0.8.5 时辅助窗口数据被忽略、主窗口数据正常读取；残缺会话文件启动时自动自愈，无需手动清理 `session.json`
- 快捷键默认表新增若干条目，已有自定义绑定不受影响；`Ctrl+Shift+S` 现专用于「另存为」，阅读模式删除线为 `Ctrl+Alt+S`
