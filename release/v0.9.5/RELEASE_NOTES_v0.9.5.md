# LightMD v0.9.5 发布说明

**发布日期**：2026-10-02
**基线版本**：v0.9.4
**主题**：正确性与性能收尾 + 六项使用问题修复——任务项/脚注内容模型无损化、专注模式与 Mermaid 渲染性能、另存为体验、文档内链接跳转、临时文件图片持久化、分屏预览残留、收藏/最近打开栏布局
**实现依据**：《LightMD 0.9.1 全方位测评报告》v0.9.5 任务卡（E15 / E16）；技术细节见 `.trae/documents/lightmd-p1-remediation-plan.md`

---

## 一、正确性与性能（E15 / E16）

### 1.1 任务项与脚注内容模型无损化（E15）

- **任务项内嵌套内容不再压平**：此前任务项内的嵌套普通列表 / 多段落 / 代码块序列化时被取文本合并进首行，重新打开后结构丢失。现在输出为缩进续行（嵌套任务列表 2 空格、段落前空行），解析端按缩进树把「与子任务平级的普通列表」正确挂回父任务项，往返结构不丢；
- **多段落脚注保持分段**：脚注定义内容模型由单行 inline 升级为块级容器，`[^1]: 第一段` + 缩进续行的第二段往返后仍为两个段落；单行脚注、无嵌套任务等旧文档解析与保存完全不受影响（B6 逐字节保留）；
- **编辑器内直接编辑**：脚注定义内回车即可分段，任务项内缩进嵌套列表（输入规则原有能力）保存后不再退化为纯文本。

### 1.2 性能优化（E16）

- **专注模式（focus-mode）**：装饰集合缓存进插件状态——纯光标移动直接复用（零开销）；大文档判定改用 `doc.content.size`（O(1)），重算只在活跃块 ±10000 字符范围内局部遍历。此前每次按键做两次全文档遍历，十万字符级文档打字卡顿；
- **Mermaid 渲染缓存**：此前任何无关事务触碰图表节点（选区移动、拖拽表格等）都会强制清除缓存触发完整 `mermaid.render()`；现在按内容比对命中缓存，内容未变不重渲染。

## 二、使用问题修复

### 2.1 另存为后文件夹树立即刷新（问题 1）

临时文件「另存为」到打开的文件夹后，文件夹树**立即出现该文件**。此前完全依赖操作系统目录监听事件（监听器注册失败或事件去抖丢弃时，必须手动刷新才能看到）。现在保存成功后由应用主动派发定向刷新，与文件夹树既有刷新链路复用；目标目录不在打开文件夹内时静默忽略。

### 2.2 另存为代码文件后语法高亮立即生效（问题 2）

临时文件写 Python 代码另存为 `.py` 后，**语法高亮立即切换**为对应语言（Python/JS/C 等全部支持格式），无需关闭重新打开。此前保存后语言标识未同步，需重开文件才高亮。

### 2.3 文档内链接点击跳转（问题 3）

阅读模式下点击文档内链接现在按类型分发：

| 链接类型 | 行为 |
| --- | --- |
| 相对路径（`./其他文档.md`、`../共享/笔记.md`、`笔记.md`） | 解析为绝对路径后直接打开目标文档（中文文件名支持，复用标签去重 / 冲突检测链路） |
| 绝对路径（`D:\docs\x.md`） | 直接打开 |
| 锚点（`#标题`） | 编辑器内平滑滚动到对应标题 |
| `http(s)` / `mailto` / `ftp` | 调用系统默认浏览器 / 邮件客户端打开 |
| `javascript:` / `file:` 等危险协议 | 不动作（与链接渲染白名单一致） |

分屏预览面板内点击链接同样生效（iframe 点击桥接回主文档）。

### 2.4 临时文件粘贴图片重启后正常渲染（问题 4）

临时文件粘贴的图片（以 base64 内联存储）在软件重启后**正常渲染**。此前重新解析文档时 `data:` URL 被链接安全白名单整体拒绝，图片退化为 alt 字符；现在按 markdown-it 标准语义放行图片类 MIME（png/jpeg/webp/gif/svg/avif/bmp），`data:text/html` 等仍拒绝，安全性不降级。

### 2.5 分屏预览不再残留上一文档内容（问题 5）

新建空临时文件切换到分屏模式，右侧预览**显示空白**（此前残留上一个打开文档的内容）。同时消除了文件切换瞬间预览面板闪现旧内容的 300ms 窗口。

### 2.6 收藏 / 最近打开栏紧贴「打开的文件」栏（问题 6）

打开「收藏」或「最近打开」栏时，面板以**紧凑形态**接到「打开的文件」栏列表的正下方，中间**空一个文件条目的位置**（例如打开文件有 5 条，收藏条目从第 7 行开始）：

- 紧凑形态为无标题栏、高度自适应内容的单行条目列表，与「打开的文件」条目 30px 行高对齐；
- 条目右键菜单（从收藏移除 / 打开所在目录）、失效标记（⚠）、悬停完整路径提示等行为不变；
- 关闭收藏 / 最近打开栏后，「打开的文件」栏恢复原有记忆高度，拖拽记录不丢。

### ✋ 人工验收项（原生对话框无法自动化）

1. **另存为全流程**：新建临时文件 → 输入内容 → `Ctrl+Shift+S` 保存到当前打开的文件夹内 → 确认文件夹树立即出现该文件，且标签名 / 标题栏更新；
2. **另存为 .py 高亮**：临时文件粘贴 Python 代码 → 另存为 `xxx.py`（保存对话框手输扩展名）→ 确认编辑区立即切换为 Python 语法高亮；
3. **临时文件图片持久化全流程**：临时文件粘贴截图 → 关闭软件 → 重新打开 → 确认图片正常显示（自动化已覆盖解析层修复点）。

## 四、已知限制

- 任务项内嵌套内容若「普通列表与子任务交错」，保存时子块顺序规范化为「嵌套任务列表在前」（内容无损，未编辑的块仍逐字节保留原文）；
- 空脚注（无内容定义）需存在正文引用才会在重新打开后还原为脚注结构（markdown-it-footnote 既有行为）。
