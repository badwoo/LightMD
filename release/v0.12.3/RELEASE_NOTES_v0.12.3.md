## 二、版本内容

### 2.1 新增功能

**0.12.0 阅读与编辑体验**

- 📄 **文档整体缩放** — `Ctrl+滚轮` 或右下角缩放尺（hover 显现、点击刻度跳转、可拖动）在阅读 / 编辑 / 分屏全部生效，范围 50%~200%，重启保持
- 🖌 **格式刷（三模式通用）** — 右键菜单或格式栏入口，单击应用一次即失效、双击进入持续应用模式（状态栏显示剩余次数，`Esc` 退出）；块级与行内格式均可刷
- ⌨️ **块级选中与鼠标拖拽** — 阅读模式单击代码块 / Mermaid 图 / 公式 / 表格 / 分隔线即整块选中（`Delete` 删除）；从块左侧 `⋮⋮` 手柄拖动调整块位置，一次 `Ctrl+Z` 完整还原
- 👻 **格式占位提示不落盘** — 无选区点「加粗」「标题」等只插入语法符号，占位文字改为灰色幽灵提示，直接输入即替换，不再残留进文件
- 🛡 **阅读焦点保持** — 折叠侧栏、拖窗口边缘、拖分屏分割条、开关大纲栏后视口内首段位置不变（含分屏 iframe 侧）；拖字号 / 行高 / 段间距 / 内容宽度时同样不丢焦点，设置窗口拖动期间变玻璃透明、取消立即还原
- 🎯 **专注模式 3 行窗** — 编辑 / 分屏亮区从单行扩为「上一行 / 当前行 / 下一行」
- 📅 **「打开的文件」显示创建时间**、ℹ️ **设置底部「关于 LightMD」**（版本号 + GitHub 地址）

**0.12.1 细节打磨**

- 🏷 **标题级别徽标（H1–H6）** — 阅读模式标题左侧改显 `H1`/`H2`… 徽标，点击展开 H1–H6 菜单改级别（大纲层级同步跟随）；输入 `#` 改级别完全保留
- ⌨️ **自动配对补全重做** — 三模式统一：右侧已有闭符号跳过输入、选中文本包围而非替换、空配对内退格一次删一对、配对内 `Tab` 跳出；词中间 / 英文撇号 / 转义态 / 代码块 / 公式内不介入；设置可按括号 / 引号 / 中文标点分别开关
- 📜 **编辑区滚动条贴最右**；🎬 **文件夹展开动画再放慢 50%**

**0.12.3 回车语义（0.12.1 首度引入、0.12.2 因观感回退、本版完整落地）**

- ↵ **阅读模式回车 = 换行** — 顶层普通段落内 `Enter` 为段内换行：**N 次回车 = N 个换行**，与阅读模式看到的行结构一一对应；`Shift+回车` = 新建段落
- 🛡 **段内换行往返保真** — 段首 / 相邻硬换行 / 表格 / 列表项 / 引用内的换行以显式 `<br>` 存盘；换行后写 `---` / `# ` / `- ` 等 21 类危险构造自动转义续行行首

### 2.2 问题修复

| 版本 | 问题 | 修复要点 |
|---|---|---|
| 0.12.2 | 打开含 Emoji 短码的文档白屏崩溃（P0） | 阅读模式 Emoji 改装饰实现（存盘仍是短码）＋编辑器创建兜底＋应用级错误边界，渲染异常给可重试提示页而非白屏 |
| 0.12.2 | 图片 `![alt\|300](src)` 宽度被静默抹除（数据丢失） | 根因是渲染管线插件装在编辑器共用的 markdown-it 单例上；改独立实例，导出不再污染解析 |
| 0.12.2 | 分屏右侧被双重缩放 / 不铺满分栏 | iframe 曾被外层 zoom 与内部 zoom 叠乘（200% 实约 400%）并被 `max-width` 钳制；现只由内部文档负责缩放与宽度 |
| 0.12.2 | `价格 $100`、`a == b` 存盘多出反斜杠 | 改与 `~`/`^` 同口径的真实配对判定，只有真能配对成公式 / 高亮才转义 |
| 0.12.2 | 改标题后锚点 / 目录失配 | 阅读模式改标题 `id` 重算（含重名去重），`[toc]` 与 `#锚点` 不再跳错 |
| 0.12.2 | 焦点保持三模式不一致 | 分屏右侧补齐排版锚点补偿；阅读模式进度百分比不再在分屏下恒显 100% |
| 0.12.2 | 导出样式不跟随应用设置 | HTML / PDF / PNG 导出的字号、行高、段间距、内容区宽度、字体与设置一致（此前全部硬编码） |
| 0.12.2 | i18n 穿帮 | 表格工具栏禁用提示、Mermaid 空图表与错误提示补英文 |
| 0.12.1 | 带图片文档切走再切回图片丢失 | 切标签时解析相对图片路径改用当前文档目录 |
| 0.12.1 | 标题徽标偏移 / 折行、任务复选框未对齐 | 徽标垂直居中对齐、修 H1 折行与溢出；复选框与首行文字中线对齐 |
| 0.12.1 | 光标卡在代码块末尾 | 光标在块尾（或整块选中）按 `→` 走到块后继续打字，块为最后块时自动新建空段落 |
| 0.12.3 | 阅读模式按 1 次回车切模式后多出空行 | 根因是阅读模式回车走 `splitBlock`（Markdown 段落间必须空行），一次回车写出两个换行；现改为段内换行，三模式换行数一一对应 |
| 0.12.3 | 阅读模式编辑文字行距过高 | 新建段落叠加 `0.8em` 上下 margin（实测 41px）；现段内换行只吃 line-height（实测 29px ≈ 编辑模式 28.8px），默认排版值未动 |
| 0.12.3 | 段内换行丢结构 / 拆块 | 段首两空格被当空行、相邻硬换行被拆块、列表/引用内换行截断列表；现这些边界统一写 `<br>`，往返稳定 |
| 0.12.3 | 换行后写 `---`/`===` 等吞掉上一段 | 续行行首按 21 类危险构造自动转义（0.12.2 回退时丢失的能力已补回），字面文本不再永久丢失 |
| 0.12.3 | 刚按完回车切模式源码出现 `<br>` | 顶层段落段末硬换行改两空格换行，且不再追加段落终止换行；列表 / 引用内保留 `<br>` 保结构 |
| 0.12.3 | 行高设置只作用于阅读区 | 编辑区 textarea 去硬编码 1.8 改消费变量；行高 / 段间距 / 内容区宽度三项注入分屏 iframe `:root`，实测三模式同为 35.2px（行高 2.2） |
| 0.12.3 | 跨块选区回车守卫（0.12.2 成果保持） | 非空选区一律交回 `splitBlock`，不会走 `replaceSelectionWith(hard_break)` 把两段合并 |

### 2.3 快捷键与行为变更

| 变更 | 说明 |
|---|---|
| `Enter`（顶层普通段落，0.12.3） | 现为**段内换行**（源码两行相邻、无空行）；连按两次回车才是新段落 |
| `Shift+Enter`（顶层普通段落，0.12.3） | 现为**新建段落**（源码空行）；列表 / 任务项 / 引用 / 标题 / 表格 / 代码块内回车行为不变 |
| 段末换行保存限制（0.12.3） | Markdown 无法表达段末换行：刚按完回车就保存 / 关闭，重开后该空行不保留（CommonMark 及其他编辑器同样如此）；想保留请连按两次回车或 `Shift+回车`。切换模式不会丢 |
| 排版设置作用范围（0.12.3） | 行高 / 段间距 / 内容区宽度现三模式全部生效；默认值未改，既有文档观感不变 |
| 缩放（0.12.0） | `Ctrl+滚轮` 文档整体缩放 50%~200%，重启保持 |
| 格式刷（0.12.0） | 双击入口进入持续应用模式（可连续刷，`Esc` 退出），单击仍为一次即失效 |
| 块级操作（0.12.0） | 阅读模式单击块选中、`Delete` 删除、`⋮⋮` 手柄拖拽调位，一次 `Ctrl+Z` 完整还原 |

## 四、已知范围

- **段末换行不随文件重开保留**（Markdown 语法限制，见 2.3）；列表项 / 引用内用 `<br>` 保结构因此会保留。
- **DOCX / EPUB / LaTeX 仍无样式定制入口**（PDF 有），属未实现功能，非缺陷。
- 未支持：跨文件全文搜索、标签、frontmatter、双链/反链/图谱、书签、Git 集成、合并单元格等（详见 README 清单）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）等本地数据全部保留。
- **回车手感变化（0.12.3）**：普通段落内回车不再「另起一段」而是换行；想要新段落请 `Shift+回车` 或连按两次回车。列表 / 任务项 / 引用 / 标题 / 表格内行为不变。
- **旧文档不受影响**：此前用回车产生的空行原样保留，不会被改写；只有新输入的回车按新语义保存。
- **换行后写块级语法**：已自动转义行首（`\- ` / `\# ` / `\---` 等），不会再被吞成列表 / 标题；若本意就是列表或标题，请先 `Shift+回车` 新建段落再输入。
