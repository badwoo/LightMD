## 一、新增

### 1.1 下划线与快捷键（E8）

- 新增**下划线**格式（此前 schema 无 underline，`Ctrl+U` 不存在）：
  - 阅读模式：`Ctrl+U` 或命令面板「下划线」→ 真实 toggle（与加粗等格式同源命令）；
  - 源码模式：`Ctrl+U` 插入 `<u></u>` 包裹（Markdown 无原生下划线语法，全应用统一以 `<u>` 表达）；
  - 序列化输出 `<u>文本</u>`，保存 / 重开往返稳定。
- 新增**插入链接**默认键位 `Ctrl+Shift+K`（`Ctrl+K` 已被 AI 对话占用）：阅读模式弹出链接对话框、源码模式插入语法，均可自定义改绑。

### 1.2 输入规则补全（E7，打字即所得）

| 输入 | 转换结果 |
| --- | --- |
| `$E=mc^2$` | 行内公式（输入闭合 `$` 即时触发，行中可用） |
| `$$` | 块级公式（行首） |
| `[文本](url)` + 空格 | 真实链接（危险 scheme 如 `javascript:` 不转换，保留字面文本） |
| `![alt\|300](src)` + 空格 | 图片节点（含尺寸，见 1.4） |
| `[^1]` + 空格 | 脚注引用（行中可用） |
| `[^1]:` + 空格 | 脚注定义（顶层段落行首） |
| `[toc]` / `[[toc]]` + 空格 | 自动目录（行首、独占一行） |
| `a \| b` ↵ `\| --- \| --- \|` | 两行表格语法 → 真实表格（表头 + 一行空表体，光标落首格，支持对齐语法 `:---:` / `---:`） |

> 说明：链接 / 图片 / 脚注 / 目录采用**空格触发**（与 Typora 一致）——自动配对会吞掉 `)` 按键，空格触发是最可靠的完成信号；表格在分隔行输入完成时转换，单独成行的 `---` 仍走水平线规则，互不干扰。

### 1.3 HTML 最小白名单（E10）

此前所有 HTML 标签一律字面显示。现在：

- **行内白名单**：`<u>`、`<br>`、`<sub>`、`<sup>`、`<mark>`（无属性形态）解析为对应格式结构，分屏预览同样渲染；
- **其他行内标签**（`<span>` 等）：标签剥离、内容保留；
- **块级 HTML**（`<div>`、`<table>` 等）：按字面文本保留（不丢内容）；
- **安全边界**：分屏预览 iframe 带 `allow-scripts`，渲染层对白名单外标签一律转义/剥离，`<script>`、`onclick` 等注入无效；导出 HTML（HTML/PDF/PNG）按 Typora 惯例全放行（内容来自用户自身文档），DOCX/LaTeX 导出维持字面文本不丢内容。

### 1.4 图片体验（E11）

- **尺寸属性**：`![alt|300](src)` 语法设置显示宽度（Typora 同款）；编辑器内即时生效，保存往返稳定，旧语法完全兼容；富文本粘贴的 `<img style="width:120px">` 也能还原；
- **alt / 宽度编辑**：阅读模式点击图片打开的编辑对话框顶部新增「替代文本」与「宽度(px)」输入框（裁剪 / 旋转 / 翻转功能保留），确认后写回文档；
- **拖拽落点**：拖入图片不再一律插到光标处——落点即为插入位置；若弹窗确认前文档又发生了编辑（落点失效），自动降级到光标处插入并给出提示。

## 二、兼容性

- 设置、快捷键自定义、会话等数据格式不变，从 0.9.2 覆盖安装即可；
- 快捷键默认表新增 2 条（`format.underline` / `insert.link`），已有自定义绑定不受影响；
- 旧文档无需迁移：不含 HTML / 新语法的文档解析行为零变化；含 `<div>` 等块级 HTML 的文档从字面显示变为"标签剥离或字面保留"，内容不丢失；
- 导出 HTML 中此前被转义的 HTML 现在按原样渲染（保真），如文档含 `<script>` 等标签将在导出文件中生效——请仅对可信文档使用。
