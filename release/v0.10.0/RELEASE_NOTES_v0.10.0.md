## 二、版本内容

### 2.1 渲染管线统一（R1）

- 新建 `src/core/renderPipeline.ts` 作为**单一配置源**：分屏预览、导出 HTML/PDF/PNG、DOCX/LaTeX 全部经由同一 markdown-it 配置（此前三处独立实例化，已出现配置漂移）
- **弯引号漂移修复**：导出管线此前 typographer:true，会把文档中的直引号 `"` 静默改写为弯引号 `“”`（与编辑器所见即所得不一致、污染用户内容）；现全管线恒 false，导出即所见
- **安全修复**：导出管线此前关闭链接白名单，`javascript:` 等危险 scheme URL 可进入导出 HTML；现 `sanitizeLinkHref` 白名单全管线强制（拒绝 javascript:/vbscript:/file: 与非图片 data:，放行 data:image，base64 图导出不受影响）

### 2.2 导出公式与图表保真（R2）

| 格式 | 修复前 | 修复后 |
| --- | --- | --- |
| PNG 长图 | 公式空白占位、图表为源码 | KaTeX 排版 + Mermaid 矢量图 |
| Word (.docx) | 公式退化为 LaTeX 文本、图表为代码块 | 渲染为高清图片（失败自动降级为原文本/代码块） |
| ePub | 公式**完全空白**（空占位元素） | 原生 MathML（EPUB3 阅读器直接排版）+ 内联 SVG |

- Mermaid 以 `htmlLabels:false` 渲染为纯 SVG（无 foreignObject），截图与 XHTML 序列化可靠；SVG 自动补 xmlns 与显式宽高（防 `width="100%"` 塌缩）
- 单个公式/图表渲染失败时保留原样（占位/代码块），**导出不中断、内容不丢**
- PNG / Word / ePub 导出过程中按钮显示逐项进度（`公式/图表 n/m`），大文档导出不再像假死

### 2.3 搜索替换支持正则（R4）

- 搜索框新增 `.*` 开关（与 Aa 大小写开关并列）：按正则语义匹配，变长匹配的高亮/替换区间全部按实际匹配长度计算
- 替换文本支持 `$1` / `$2` / `$&` 捕获组引用（如搜索 `(\d+)\.(\w+)` 替换为 `$2: $1`）
- 非法正则：输入框红框 + 「正则无效」提示，查找/替换自动禁用，不崩溃
- 源码（textarea）与阅读（ProseMirror）两条路径共用同一匹配/展开纯函数，行为一致；关闭开关时与旧版字面量行为完全一致

### 2.4 其他

- **大纲渲染上限 100 → 1000（R5）**：长文档大纲不再截断，超出时提示「仅渲染前 1000 项，还有 N 个标题」（中英双语）
- **PDF 导出增强（R3s）**：Edge headless `--virtual-time-budget` 5s → 10s，Mermaid 多图大文档不再截在渲染中途；浏览器缺失时错误提示更明确；浏览器路径查找限定 Windows 平台显式分支
