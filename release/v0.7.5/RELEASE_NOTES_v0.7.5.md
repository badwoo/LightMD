## 二、本次更新

### F1 · AI 对话浮动窗口（`Ctrl+K`）

- 三个入口共用同一窗口：状态栏 AI 抽屉「AI对话」按钮、`Ctrl+K`（macOS `Cmd+K`）、选区「问」气泡；命令面板已注册 `ai.chat`
- 自研轻量浮动层：标题栏拖拽移动、右下角拖拽缩放（最小 360×280）、`[—]` 折叠为输入条、`[×]`/`Esc` 关闭
- 多轮对话：发送时携带最近 3 轮历史（超出截断，历史恒以 user 开头）；文档上下文仅挂在当前这一轮，token 不随轮数线性膨胀
- 上下文三档一键切换：`选区 N 字` / `全文 N 字` / `无上下文`；选区丢失自动降级为全文并在 chip 明示；全文超 20000 字截断并标注
- 6 条快捷指令模板：生成图表 / 生成公式 / 生成摘要 / 标题与标签 / 改写全文 / 分析文档（点击预填，可编辑后再发）
- 结果动作条：插入光标处 / 替换选区 / 替换全文 / 复制 / 重新生成
- **插入即所见**：AI 输出的 ```mermaid 围栏与 `$$` 公式插入后立即渲染为图表与公式
- 安全链：回写一律使用发送时快照（非当前选区）；「替换全文」前做 DOC_CHANGED 校验；回写后 `Esc` 可恢复原文
- 窗口位置/尺寸记忆：拖拽/缩放结束时落盘，越界自动回落居中
- 修复体检报告 U1：`aiEnabled=false` 时 AI 对话入口由静默改为 toast 提示

### F2 · 选区 AI 气泡独立隐藏 + 「问」气泡

- 浮动按钮排由 [译][续][润][摘] 扩展为 **[译][续][润][摘][问]**
- 右键菜单改为按任务独立隐藏（「隐藏『润』气泡」只隐藏该个）；一排宽度按可见数计算，定位不偏移
- 状态栏 AI 齿轮面板新增四个独立勾选项，可逐一恢复；总勾选一键恢复全部
- 迁移：`aiAssistBubbleHidden=true` 的老用户升级后四个气泡均隐藏，可逐一恢复（旧字段保留以兼容回滚）

### F3 · 「译」气泡颜色设置

- 设置页「翻译设置」与「译」入口子设置面板新增颜色项（两处读写同一字段），空值 = 跟随主题
- 插件刷新循环统一重读「译」与 AI 气泡颜色，改色即时生效；清空即回退主题色

## 二之二、AI 功能细节优化（同日追加）

### 1. 修复按 Esc 关闭 AI 气泡 / 对话窗后文档跳回开头

- **根因**：气泡的 Esc 处理在 `window` 捕获阶段 `stopPropagation()`，编辑器 DOM 的**捕获 keydown 收不到该键**，但 keyup 不受影响仍到达编辑器；滚动跟随逻辑因此拿"上一次按键"遗留的 `savedScrollTop / savedCursorY / cursorWasOutside` 计算，命中分支后把 `scrollTop` 恢复成旧值 —— 上一次按键若在文档开头附近，文档就跳回开头（是否需要跳取决于上次按键位置与当前滚动位置的差值，故表现为"有概率"）
- **修复**：新增 `ScrollKeyBaseline`（keydown 记录 / keyup 消费），**只有见过配套 keydown 的 keyup 才允许进入滚动跟随**；提前消费基线避免陈旧 `seen` 被后续 keyup 误用；编辑器 blur 时作废基线
- 覆盖范围：阅读模式（ProseMirror）与源码模式（textarea 打字机滚动）同步修复，AI 翻译气泡 / 摘要 / 润色 / 对话窗的 Esc 全部受益

### 2. 气泡颜色同步到底部栏 AI 按钮

- 续 / 润 / 摘 / AI对话 四个抽屉按钮按任务注入 `--ai-entry-color`（取自对应气泡颜色）
- 鼠标悬停与按下时按钮以该色高亮；未设色时回退主题 accent，默认外观与旧版完全一致
- 颜色设置变更实时反映（无需重开抽屉）

### 3. AI 续写立即给出反馈

- 点击续写后**立即**在光标处渲染灰色占位 ghost「续写中...」（呼吸动画），首个增量到达即替换为真实内容
- 占位期间不可采纳：`Tab` 被消费但不插入（提示语不会被写进文档），且不显示「Tab 采纳 · Esc 放弃」提示
- 阅读模式与源码模式行为一致；占位与真实内容的 widget 指纹区分（不会出现提示语残留）

### 4. AI 对话窗口内嵌 AI 翻译

- 新增快捷指令「**AI翻译**」（模板总数 6 → 7）：通过选区打开对话窗时点击该指令即翻译选区文字，目标语言取自翻译设置（`auto` 为中英互译表述）；「替换选区」可把译文直接写回原文位置
- 每条回答新增「**译**」按钮：就地翻译该条回答并替换显示，再点「原文」还原；已翻译的回答带 accent 竖条标识
- 译文态下「插入光标处 / 替换选区 / 复制」均作用于译文，形成"选区 → 问 → AI翻译 → 替换选区"的窗口内闭环
- 回答超过 4000 字时提示而非静默失败；流式生成期间禁用「译」（避免抢占同一任务槽）

### 5. 打开对话窗口的拖动限制

- 拖拽移动不再受视口约束，可拖到屏幕任意位置（含边缘外、副屏）
- 仅保留尺寸钳制（最小 360×280，最大不超过视口）
- 位置记忆保留安全网：下次**重新打开**时若记忆矩形已完全落在视口外（换显示器 / 分辨率变小），回落默认居中，避免窗口"打不开"
