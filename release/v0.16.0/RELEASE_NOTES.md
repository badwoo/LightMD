# LightMD v0.16.0 发布说明

> 发布日期：2026-11-07 ｜ 基线：v0.15.6 ｜ 定位：**Tab / 缩进体系重构 + 侧栏 UI 重构**
>
> 本版两条主线。其一，`Tab` 键不再是「按块类型逐条链式分发」——旧链路
> `pairTabOut → tableTab → codeBlockIndent → sinkListItem` 全部返回 `false` 时会落到浏览器原生
> `Tab`，**焦点就此逃出编辑器**；根因不是漏了某个场景，而是链本身没有兜底。
> 本版引入「缩进」一等公民命令（`indent` / `outdent`），把焦点逃逸从「逐场景修复」变成结构上
> 不可能发生，并顺带修掉 16 项相关缺陷（含 2 项 P0）。其二，左侧栏从「文件树 + 内嵌收藏/最近分区」
> 重构为**三个互斥视图**（文件管理 / 收藏 / 最近打开），收藏支持多选批量添加。
>
> 与 0.15 系列「功能写了但真实交互不成立」的共性问题一致，本版全部结论以**真实 WebView2 实机探针**
> 取证，并如实记录唯一一项未达预期的行为（撤销粒度合并窗口，见「四、已知范围」）。

## 二、版本内容

### 2.1 新增功能

**Tab / 缩进体系**

- ⌨️ **「缩进」一等公民命令** — 新增 `core/indentCommands.ts` 的 `indent` / `outdent`，按块类型分派，
  **除表格分支外永不返回 `false`**；`Tab` 链改为 `chainCommands(pairTabOut, tableTab, indent)`。
  焦点逃逸从「逐场景修复」变成结构上不可能。
- ⚙️ **缩进单位可设置** — 设置 → 编辑器 → 「缩进单位」下拉（`Tab` / `2 个空格` / `4 个空格`，默认 2），
  修改**即时生效**，代码块与编辑区视觉宽度同步。
- 📐 **tab 宽度单源化** — 三处 `tab-size` 统一读全局 CSS 变量 `--lm-tab-size`，并补 iframe 与导出文档的
  变量注入；有/无语言标记的代码块与源码 textarea 现在是同一宽度。
- 📄 **源码模式也支持缩进** — 新增 `utils/sourceIndent.ts` 纯规划器 + `handleSourceKeyDown` 接线。
- 📖 **文档口径与实现对齐** — `USER_GUIDE.md` 新增「Tab 与缩进行为（0.16.0 起统一口径）」逐场景表
  （表格 / 代码块 / 公式块 / 图表块 / 列表 / 任务列表 / 引用块 / 普通段落 / 标题 / 配对符号 /
  AI ghost / 三模式一致）。

**侧栏 UI**

- 🗂 **三个互斥视图** — 文件管理 / 收藏 / 最近打开共用同一块侧栏区域，同一时刻只显示一个。
- ➕ **文件管理标题与新建按钮合并** — 顶部改为一个大按钮「＋ 新建」，复用原有 `file.new` 命令。
- 📌 **标题栏左侧侧栏按钮** — 文件管理视图下收起/展开侧栏；收藏 / 最近打开视图下关闭当前面板并
  **返回文件管理**（不连带收起侧栏）。
- 🎞 **全高视图与滑入滑出** — 收藏 / 最近打开为互斥全高面板，打开从左侧滑入、关闭向右滑出；
  切走后文件树**只隐藏不卸载**，展开的文件夹与滚动位置都还在。
- ⭐ **收藏多选批量添加** — 收藏面板「添加收藏」读取当前窗口**已落盘**的打开标签，支持圆形多选、
  取消、`Esc`、关闭标签联动；提交走新的原子批量动作 `addFavorites`，按 **50 条**容量接收并返回
  实际 `added` / `skipped`，**不为接纳新项而淘汰既有收藏**。
- ♿ **无障碍与偏好** — 遵循系统「减少动态效果」（停用滑移）；侧栏原宽恢复；按钮与计数文案中英文齐备。

### 2.2 问题修复

| 级别 / # | 问题 | 修复要点 |
|---|---|---|
| P0 / D1 | **代码块有选区时按 `Tab` 写坏代码**：旧实现 `insertText(unit, $from.pos)` 单点插入，`"line1\nline2\nline3"` 选中 `line2..line3` 后变成 `"line1\nl  ine2\nline3"` | 改为按**选区覆盖的每一行**逐行缩进（从后往前、单事务） |
| P0 / D2 | **源码模式 `Tab` 完全不缩进** | 新增 `utils/sourceIndent.ts` 纯规划器 + `handleSourceKeyDown` 接线；无论有无缩进产物都吞键（否则「无可删」场景仍会逃逸焦点） |
| P1 / D3 | 段落 / 标题 / 引用块按 `Tab` **焦点逃逸** | 由 `indent` 分派接管（段落给产物、标题吞键） |
| P1 / D4 | **`math_block` 漏配 `inCodeLikeBlock`**，按 `Tab` 焦点逃到 ⋮ 菜单 | 补入 `inCodeLikeBlock` 判定，焦点留在编辑器内 |
| P1 / D5 | 列表 / 任务列表**首项** `sinkListItem` 天然失败，按 `Tab` 逃逸焦点 | 提示「列表首项无法再缩进」并吞键 |
| P1 / D6 | **`pairTabOut` 抢走表格单元格内的 `Tab`**（单元格内是配对括号 `()` 时，按 `Tab` 只右移 1 个字符而不换格） | 拆出 `PAIR_TAB_DISABLED_NODES`（含 `table_cell` / `table_header`），**与 `DISABLED_NODES` 分离**以保住表格内自动补全 |
| P1 / D7 | **`mermaid_block` 未在 `DISABLED_NODES` 中**，与代码块缩进口径冲突 | 并入 `DISABLED_NODES`，与代码块缩进统一口径 |
| P1 / D8 | 代码块 `Shift+Tab` **吃掉行中空格**（`"a b"` → `"ab"`） | 改判「光标到行首全是空白」才删 |
| P2 / D9 | **真实 `\t` 缩进不被识别**：`outdentLen` 恒把 1 个 `\t` 当一个单位 | `outdentLen` 识别真实 `\t`，按其实际宽度计一个单位 |
| P2 / D10 | **有选区按 `Shift+Tab` 不按行处理** | 与 D1 共用 `lineStartsInRange`，按选区覆盖的行逐行减缩进 |
| P2 / D11 | **`NodeSelection` 状态下 `Tab` 走裸键** | 吞键，不再逃逸 |
| P2 / D12 | **同一份含 `\t` 的文件在编辑 / 阅读两面缩进宽度不同**（`code-theme.css` 为 2 但仅当代码块有语言标记才命中；`editor.css` 硬编码 4） | 三处 `tab-size` 统一改读 `--lm-tab-size`（兜底 2），变量由 `indentUnit` 驱动；并补 iframe 与导出文档的变量注入 |
| P2 / D13 | **文档与实现不符** | `USER_GUIDE.md` 新增「Tab 与缩进行为」小节并补列表快捷键限定；README 中「`pairTabOut` 抢占表格 Tab 是用户期望行为」的写法改写为**已确认缺陷** |
| P2 / D14 | **无缩进单位设置项** | 新增「设置 → 编辑器 → 缩进单位」（`Tab` / `2 个空格` / `4 个空格`，默认 2，即时生效） |
| P2 / D15 | **撤销粒度不确定** | 缩进事务统一 `closeHistory`，在 **ProseMirror 撤销栈内**每次缩进独立成步；但实机 `Ctrl+Z` 走统一时间线（`keymap.ts` 的 `hostUndoCommand`），该时间线只看 `pmAdapter` 的防抖窗口（`DEBOUNCE_MS=350` / `MAX_WAIT_MS=900`）、**不读 `closeHistory`**——间隔小于约 350ms 的连续缩进会被合并为一步。**已列为已知限制**（详见「四、已知范围」） |

README / README_EN / USER_GUIDE 中相应的旧描述已一并改写。

### 2.3 快捷键与行为变更

| 变更 | 说明 |
|---|---|
| `Tab` / `Shift+Tab`（0.16.0） | **不再把焦点移出编辑器**，任何块类型下都留在编辑区；缩进单位可在设置中改为 `Tab` / 2 空格 / 4 空格 |
| 缩进撤销粒度（0.16.0） | PM 栈内每次缩进独立成步；实机 `Ctrl+Z` 下**两次缩进间隔小于约 350ms 时会被并入同一步撤销**（实测：150/250ms 合并，400/500/700ms 独立成步），停顿后再缩进则独立成步（已知限制） |
| 普通段落 `Tab`（0.16.0 明确） | **在光标处插入缩进单位**，不是「缩进到行首」——光标在行首时即为行首缩进；光标在行中时缩进单位插在光标位置（实机取证：`"PMARK 普通段落文本"` 光标置于第 3 字符后按 `Tab` → `"PMARK 普通段  落文本"`）。对应 `indentCommands.ts` 的 `tr.insertText(unit, selection.$from.pos)` |
| 列表 `Tab`（0.16.0 明确） | 仅列表项内生效；**首项不缩进**，按下时提示「列表首项无法再缩进」 |
| 收藏 / 最近打开（0.16.0） | 工具栏星标 / 时钟图标改为**视图切换**语义：点击切到该视图，再点同一图标切回文件管理；不再是展开 / 收起 |
| 侧栏宽度与高度（0.16.0） | 文件夹栏高度仍可拖拽；**收藏 / 最近改为全高视图，不再有可拖的分区高度**；侧栏最小宽度 180px |
| 侧栏视图保持（0.16.0） | 收起 / 展开侧栏时**保留当前视图**；在收藏视图下收起再展开，回到的仍是收藏视图 |

## 四、已知范围

- **连续缩进的撤销合并窗口（本版唯一未达预期项）**：缩进事务统一 `closeHistory`——**PM 撤销栈内**
  每次缩进独立成步（实机验证两次 Tab 产生 2 个 `closeHistory` 边界）；但实机 `Ctrl+Z` 经
  `hostUndoCommand` 走**统一时间线**，该时间线只看 `pmAdapter` 的防抖窗口（`DEBOUNCE_MS=350` /
  `MAX_WAIT_MS=900`）且不读 `closeHistoryKey`，因此**两次缩进间隔小于约 350ms 时会被并入同一步撤销**
  （实测：150/250ms 合并，400/500/700ms 独立成步）。属**已知限制，不影响数据正确性**——需要
  「一次缩进正好一步撤销」时，请在两次缩进间稍作停顿（约 400ms 以上）。
- **侧栏 UI 的实机验收只在 Windows WebView2 上做过**，未在其它平台验证；`scripts/v0160-probe-sidebar-ui.mjs`
  的 15 项判据为真实 WebView2 下的 DOM / 几何 / 动画检查。
- **缩进单位对既有文档的影响**：改设置只改变显示与后续输入的缩进行为，不会重排已存盘的缩进字符。
- **导出文档的 tab 宽度**：`--lm-tab-size` 已注入导出文档，但外部编辑器渲染 `.md` 时按其自身
  `tab-size` 显示，LightMD 的设置不随之携带。
- **撤销历史仍是会话内的**：不跨重启持久化，上限 200 步 / 32MB 每文档。
- **工作区搜索只读**：不支持正则、不建索引、不支持全库替换、不解析 frontmatter。
- **表格合并仍用行内 HTML 扩展**：`<td colspan/rowspan>` 不是 GFM 标准，其它编辑器可能显示原始标签。
- **仅提供 Windows 安装包**；macOS / Linux 未构建。
- 未支持功能清单不变（双链 / 反链 / 图谱、标签、frontmatter、Git 集成等，详见 README）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）、
  窗口大小、阅读进度等本地数据全部保留。
- **`Tab` 行为变了**：现在任何块类型下 `Tab` / `Shift+Tab` 都不会把焦点移出编辑器。此前依赖
  「`Tab` 跳出编辑器」来切换焦点的用法需改用鼠标或其它快捷键。
- **缩进单位默认 2 个空格**：与历史行为一致，无需迁移；想改成 `Tab` 或 4 空格请到
  「设置 → 编辑器 → 缩进单位」。
- **侧栏交互变了**：收藏 / 最近打开从「内嵌分区展开」改为「互斥全高视图切换」。习惯旧入口的用户
  仍是点工具栏星标 / 时钟图标；关闭面板点标题栏左侧侧栏按钮或再点一次同一图标即可。
- **折叠过收藏 / 最近分区的老设置不再生效**：这两个面板已无独立分区高度，此前拖拽保存的高度值
  不再影响布局；文件夹栏的高度设置仍然有效。
- **收藏容量仍为 50 条**：批量添加不会淘汰既有收藏，超容量时会提示实际添加与被挡下的条数。
