# LightMD v0.16.0 发布说明

> 发布日期：2026-11-09 ｜ 基线：v0.15.6 ｜ 定位：**Tab / 缩进体系重构 + 侧栏 UI 重构**
>
> 本说明汇总 v0.16.0 的全部内容（四个提交）：`Tab` 键由「按块类型逐条链式分发」改为
> **「缩进」一等公民命令**，从结构上消除焦点逃逸并修复 16 项相关缺陷（含 2 项 P0）；
> 左侧栏由「文件树 + 内嵌收藏 / 最近分区」重构为**三个互斥全高视图**，收藏支持多选批量添加。
> 发布前两轮复测调整（侧栏头部还原、搜索面板动画、收藏候选扩大、选择器动画）已并入最终形态。

## 二、版本内容

### 2.1 新增功能

**Tab 与缩进体系**

- ⌨️ **「缩进」一等公民命令** — 新增 `indent` / `outdent` 按块类型分派，除表格分支外**永不返回 `false`**，把焦点逃逸从「逐场景修补」变成结构上不可能发生
- ⚙️ **缩进单位可设置** — 设置 → 编辑器 →「缩进单位」（`Tab` / 2 个空格 / 4 个空格，默认 2），修改即时生效
- 📐 **tab 宽度单源化** — 有 / 无语言标记的代码块、源码 textarea、iframe 与导出文档统一读 `--lm-tab-size`，两面缩进宽度一致
- 📄 **源码模式支持缩进** — 纯规划器 + 键盘接线，无论有无缩进产物都吞键，焦点留在编辑区
- 📖 **文档口径对齐** — 用户指南新增「Tab 与缩进行为」逐场景表，覆盖表格 / 代码块 / 公式块 / 图表块 / 列表 / 任务列表 / 引用块 / 普通段落 / 标题 / 配对符号

**侧栏 UI 重构**

- 🗂 **三个互斥全高视图** — 文件管理 / 收藏 / 最近打开共用侧栏，同一时刻只显示一个；打开左滑入、关闭右滑出，切走时文件树**只隐藏不卸载**，返回后展开状态与滚动位置不丢
- 📌 **标题栏侧栏按钮** — 文件管理视图下收起 / 展开侧栏；收藏、最近打开视图下关闭当前面板并返回文件管理（不连带收起侧栏）；成功打开工作区后自动回到文件管理
- 🧾 **文件管理头部** — 保持「文件管理」标题 + 六个功能图标的单行形态，新建文件为图标行第一项；极窄侧栏（约 <266px）自动隐藏标题让位图标，180px 最小宽度无横向溢出
- ⭐ **收藏多选批量添加** — 圆形多选、取消、`Esc`、关闭标签联动；原子批量动作按 50 条容量接收并返回实际添加 / 跳过数，**不淘汰既有收藏**，同名文件显示完整路径
- 🗃 **收藏候选扩为两组** — ①「已打开的文件」= 当前窗口已落盘标签；②「工作区文件」= 所有已打开文件夹**任意层子目录**里的可打开文件。递归枚举跳过隐藏条目与 `node_modules` / `target` / `dist` / `build` / `.git`，按完整路径去重；20000 条硬上限、每组最多渲染 400 条、读取失败静默降级为仅已打开文件；顶部过滤框按文件名或路径匹配且不清空已选
- 🎞 **搜索文件面板动画** — 高度 0fr↔1fr 让下方文件列表被平滑推下 / 回填，搜索框同步水平滑入滑出（220ms / 180ms），不再出现「点击瞬间下跳、收回后瞬间上跳」
- 🎞 **收藏选择器动画** — 点「＋」内容从标题栏下方滑入淡入（240ms，条目错峰入场）、图标旋转成「×」；取消 / `Esc` / 确认时反向滑出淡出（180ms）**播完才卸载**，列表平滑回填
- ♿ **偏好与文案** — 遵循系统「减少动态效果」（过渡停用、取消立即生效）；侧栏原宽恢复；按钮、计数与上限提示中英文齐备

### 2.2 问题修复

| 级别 / # | 问题 | 修复要点 |
|---|---|---|
| P0 / D1 | 代码块有选区时按 `Tab` **写坏代码**（单点插入把缩进插到选中内容中间） | 改为按选区覆盖的每一行逐行缩进（从后往前、单事务） |
| P0 / D2 | 源码模式 `Tab` **完全不缩进** | 新增源码缩进规划器并接入键盘链路；无论有无产物都吞键 |
| P1 / D3 | 段落 / 标题 / 引用块按 `Tab` **焦点逃出编辑器** | 由缩进命令分派接管（段落给产物、标题吞键） |
| P1 / D4 | 公式块漏配块类型判定，按 `Tab` 焦点跳到 ⋮ 菜单 | 补入判定，焦点留在编辑器 |
| P1 / D5 | 列表 / 任务列表**首项**缩进天然失败并逃逸焦点 | 提示「列表首项无法再缩进」并吞键 |
| P1 / D6 | 配对符号命令**抢走表格单元格内的 `Tab`**（只右移 1 字符而不换格） | 拆分禁用节点清单，表格单元格禁用该命令，同时保住表格内自动补全 |
| P1 / D7 | 图表块未纳入代码块缩进口径 | 并入同一口径，与代码块一致 |
| P1 / D8 | 代码块 `Shift+Tab` **吃掉行中空格**（`"a b"` → `"ab"`） | 仅当光标到行首全是空白时才删 |
| P2 / D9 | 真实 `\t` 缩进不被识别 | 反缩进按 `\t` 实际宽度计一个单位 |
| P2 / D10 | 有选区按 `Shift+Tab` 不按行处理 | 与 D1 共用行起点计算，逐行减缩进 |
| P2 / D11 | 整块选中状态下 `Tab` 走裸键 | 吞键，不再逃逸 |
| P2 / D12 | 同一份含 `\t` 的文件在编辑 / 阅读两面**缩进宽度不同**（2 与 4 分裂） | 三处 `tab-size` 单源化，并补 iframe 与导出文档的变量注入 |
| P2 / D13 | 文档与实现不符 | 用户指南补逐场景表与列表快捷键限定；README 把「抢占表格 Tab 是期望行为」改写为**已确认缺陷** |
| P2 / D14 | 无缩进单位设置项 | 新增设置下拉，默认 2 个空格、即时生效 |
| P2 / D15 | 缩进的撤销粒度不确定 | 缩进事务统一加历史边界；实机 `Ctrl+Z` 走统一时间线的合并窗口（见「四、已知范围」） |
| P2 / D16 | 配对符号判定缺输入法组合态 | 补齐组合态判断 |

**侧栏旧行为一并收敛**：收藏 / 最近打开不再是「点一下展开、再点收起」的内嵌分区，也不再需要「自动滚动到可见位置」把面板滚进视口——互斥全高视图从结构上消除了这两类问题；README、README_EN、USER_GUIDE 中的旧描述已同步改写。

### 2.3 快捷键与行为变更

| 变更 | 说明 |
|---|---|
| `Tab` / `Shift+Tab` | **任何块类型下都不再把焦点移出编辑器**；此前用 `Tab` 跳出编辑器切换焦点的习惯需改用鼠标或其它快捷键 |
| 缩进单位（新增设置） | 默认 2 个空格，可改 `Tab` / 4 个空格；只影响显示与后续输入，不重排已存盘的缩进字符 |
| 普通段落 `Tab` | 在**光标处**插入缩进单位（不是缩进到行首）；光标在行首时即为行首缩进 |
| 列表 / 任务列表 `Tab` | 仅列表项内生效；首项不缩进并给出提示 |
| 收藏 / 最近打开 | 工具栏星标 / 时钟图标由「展开 / 收起」改为**视图切换**：再点同一图标或标题栏侧栏按钮返回文件管理 |
| 侧栏高度与视图保持 | 收藏 / 最近打开改为全高视图，**不再有可拖的分区高度**；文件夹栏高度仍可拖；收起 / 展开侧栏保留当前视图 |
| 动画偏好 | 搜索面板、收藏选择器、视图滑入滑出均遵循系统「减少动态效果」 |

## 四、已知范围

- **连续缩进的撤销合并窗口（本版唯一未达预期项）**：PM 撤销栈内每次缩进独立成步，但 `Ctrl+Z` 走统一时间线，两次缩进间隔小于约 350ms 时会被并入同一步（实测 150 / 250ms 合并，400 / 500 / 700ms 独立）。需要「一次缩进正好一步撤销」时，两次之间稍作停顿即可；**不影响数据正确性**。
- **缩进单位只影响显示与后续输入**：不重排已存盘的缩进字符；外部编辑器打开 `.md` 时按自身 tab 宽度显示。
- **侧栏 UI 的实机验收仅在 Windows WebView2 上做过**，未在其它平台验证。
- **撤销历史仍是会话内的**：不跨重启持久化，上限 200 步 / 32MB 每文档。
- **工作区搜索只读**：不支持正则、不建索引、不支持全库替换、不解析 frontmatter。
- **表格合并仍用行内 HTML 扩展**：`<td colspan/rowspan>` 不是 GFM 标准，其它编辑器可能显示原始标签。
- **仅提供 Windows 安装包**；macOS / Linux 未构建。
- 未支持功能清单不变（双链 / 反链 / 图谱、标签、frontmatter、Git 集成等，详见 README）。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）、窗口大小、阅读进度等本地数据全部保留。
- **`Tab` 行为变了**：不再把焦点移出编辑器；依赖旧行为切换焦点请改用鼠标或其它快捷键。
- **缩进单位默认 2 个空格**，与历史行为一致，无需迁移；需要 `Tab` 或 4 空格请到「设置 → 编辑器 → 缩进单位」。
- **侧栏交互变了**：收藏 / 最近打开改为互斥全高视图切换，入口仍是工具栏星标 / 时钟图标；关闭面板点标题栏左侧侧栏按钮或再点一次同一图标。
- **折叠过收藏 / 最近分区的老高度设置不再生效**（面板已无独立分区高度）；文件夹栏高度设置仍然有效。
- **收藏容量仍为 50 条**：批量添加不会淘汰既有收藏，超容量时提示实际添加与被挡下的条数。
- **文件管理头部与搜索面板动画**：无大号「＋ 新建」按钮，新建文件入口回到第一个功能图标（命令与快捷键不变）；搜索面板改为「高度 + 水平」双通道动画，下方文件列表随展开 / 收回平滑移动。
