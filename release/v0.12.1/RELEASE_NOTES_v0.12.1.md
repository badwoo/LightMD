## 二、版本内容

本版共 **15 项需求**（第一轮 4 项 + 第二轮 11 项），其中「自动配对补全」为既有功能的整体重做；第二轮中「设置窗口动画」「排版预览」两项按后续反馈做了二次修订并已并入下文描述。

### 2.1 新增功能

**① 标题级别徽标（H1–H6）取代 `#` 井号**

- 阅读模式标题左侧不再显示 `#`/`##` 语法井号，改为 `H1`/`H2`… 徽标（二级标题即 `H2`）
- 点击徽标展开 **H1–H6** 级别菜单，选中即改级别；菜单为 200ms 顺滑展开动效（`scaleY` + 位移 + 淡入，easeOutExpo 缓动），当前级别高亮并标出等价的 `#` 语法，尊重系统「减少动态效果」
- 改级别为**一次事务 = 一次撤销**，标题内容与锚点 `id` 保留；原「输入 `#` 数量改级别」的方式**完全保留**
- 徽标绝对定位、脱离文档流 → 光标进出标题仍**零位移**（延续 v0.12.0 修复）
- 徽标与标题**垂直居中对齐**（`top:50% + translateY(-50%)`），字号按级别小幅递减（`clamp(9px,0.42em,13px)`）、宽高给足且禁止换行

> 范围说明：Markdown 标准只有 6 级标题（markdown-it 仅把 1~6 个 `#` 解析为标题，7 个 `#` 会被当作普通段落），故菜单只列 H1–H6，避免生成无法往返的语法。

**② 自动配对补全重做**

新增唯一规则源 `core/autoPairRules.ts`（纯函数）+ textarea 规划器 `utils/sourceAutoPair.ts`，**阅读（ProseMirror）/ 编辑 / 分屏三模式共用同一套判定**：

| 能力 | 说明 |
|---|---|
| 补全配对 | `(` `[` `{`、`"` `'` `` ` ``、中文标点 `“ ” ‘ ’ （ ） 【 】 《 》 「 」` |
| 跳过输入 | 右侧已有同一闭符号时不重复插入，光标直接跳过（typeover） |
| 包围选区 | 选中文字后输入开符号 → 用配对符号包住，而不是替换内容（含多行选区） |
| 退格删一对 | 光标停在空配对中间按退格，两个符号一起删 |
| `Tab` 跳出 | 光标停在配对中间按 `Tab` 跳到闭符号右侧（不在配对中时仍走原有缩进/导航） |
| IME 提交后补全 | 组合输入期间不介入；中文标点上屏后补闭符号 |
| 撤销粒度 | 补全 = 一次编辑 = 一次撤销（PM 单事务 / textarea 单次 `execCommand`） |

**新增设置**：设置 → 编辑器 →「配对范围」三个开关（括号 / 引号 / 中文标点），可只关引号而保留括号；总开关关闭时整组置灰。

**③ 编辑模式滚动条移到最右**

- 可滚动区域由「正文框」改为**整个编辑区**（滚动条贴最右），与阅读模式一致
- 正文位置**与旧版逐像素一致**（用真实 Chromium 在 1200 / 960 / 700px 三种宽度实测：正文列完全相同，仅滚动条位置改变）
- 分屏模式不受影响（其滚动条本就贴分栏右缘）

**④ 文件夹展开动画再放慢 50%**

- 子文件夹展开 0.675s → **1.013s**、收起 0.63s → **0.945s**；JS 常量（容器高度过渡）与 CSS 关键帧同步修改

**⑤ 任务列表方形 / 圆形两种图标**

- 复选框分**方形**与**圆形**：格式栏「☑」按钮改为下拉二选一；阅读模式下每个任务项复选框左侧有**浅色小样式手柄 `::`**（鼠标移入该项提亮），点开同样可选样式
- 圆形项写 `* [ ] `、方形项写 `- [ ] `——都是标准任务列表语法，别的编辑器打开只是列表符号不同，仍是任务列表
- **格式刷**会一并套用样式（源码模式改写行首前缀、阅读模式改 `task_item` 的样式属性），且样式随保存写回 `.md`

**⑥ 排版实时预览 + 玻璃透明 + 阅读焦点保持**

- 设置里的字号 / 字体 / 行高 / 段间距 / 内容区宽度**拖动时文档立即变化**。实现上走一个**非持久化预览 store**：拖动期间不写 localStorage、不发跨窗口广播；点「保存设置」才落盘，点取消 / `✕` / 遮罩 / `Esc` 立即还原（拖动过程不产生任何写入）
- 拖动滑条期间设置窗口的底盘变**玻璃透明（透明度 85%，底板 alpha 0.15）** + 背景模糊 12px，文字与滑条本身保持原样清晰——满足「除了滑条颜色不变，窗口变玻璃透明色」
- **阅读焦点不动**：与「拖窗口 / 折叠侧栏不丢阅读焦点」同一套锚点机制——写 CSS 变量前后在**同一个 layout effect** 内「先量旧位置 → 写新变量 → 立刻量新位置 → 补 `scrollTop`」（阅读模式用块锚点、编辑/分屏左侧用 textarea 内容锚点、分屏右侧 iframe 单独补偿）

**⑦ 设置窗口开关动画**

- 打开：从**屏幕上方之外** `translateY(calc(-50vh - 50%))` 平滑滑进来，落位处轻微「果冻」回弹（过冲 +14px → -7 → +3 → -1 → 0，640ms）
- 关闭：先向下**轻压蓄力** +14px，再**纯位移**滑出屏幕上方（520ms）
- 弹窗本体**全程不透明、不做淡入淡出**（明暗变化只由背景遮罩负责，遮罩退场延迟 200ms 等弹窗滑走后才亮起）

**⑧ 编辑模式的书本悬浮按钮**

- 编辑模式右上角也显示**小书本**悬浮按钮，点击直接回阅读模式（阅读=羽毛笔、分屏/编辑=小书本）

### 2.2 问题修复

| 问题 | 修复要点 |
|---|---|
| 词中间乱插配对 | `abc\|def` 中输入 `(` 只插单字符（右侧是单词字符不配对） |
| 右侧紧邻闭符号仍配对 | 输入 `(` 而右侧已是 `)` → 只插单字符 |
| 孤儿闭符号被"跳过" | 输入 `)` 而左侧无未闭合的 `(` → 只插单字符（轻量栈扫描判定） |
| 引号被补成 4 个 | 自配对引号（`"` `'` `` ` ``）右侧已有同一字符时只移动光标 |
| 英文撇号误配对 | `don't`、`it's` 不再补全 |
| 转义态误配对 | `\(` 不配对 |
| 行内公式漏判 | `$...$` 内不再配对（旧实现只挡了代码块/行内代码/块级公式） |
| 中文标点补全靠巧合 | 旧实现依赖输入法恰好派发单字符 `keydown`；现改为 `beforeinput` + `compositionend` 双路径，可靠生效 |
| 标题徽标与标题不对齐 | 徽标只有 `right:100%`、没有 `top`，垂直方向落在 inline-flex 基线静态位置上——真机实测比标题中线**高 7px**。改为 `top:50% + translateY(-50%)`，实测中线偏差 0px |
| H1 徽标「H」与数字分成两行 | 旧规则 `min-width:1.7em` + `padding:0 .28em` 在 H1（2em=32px）下算出 19.84px 字号、内容区仅 22.9px，而 600 字重的 `H1` 宽约 25.6px，叠加 `.ProseMirror` 的 `word-break: break-word` 后折成两行并溢出盒子。改为 `clamp(9px,0.42em,13px)` + 足够宽高 + `white-space: nowrap` |
| 改级别后大纲没有层级缩进 | 大纲的标题去重键是 `pos:text`，而点徽标改级别只改 `attrs.level`（`pos`/`text` 不变）→ 键相同 → `setHeadings` 被跳过，条目类名与 `paddingLeft` 不刷新。键补上 `level` |
| 带图片的文档切走再切回图片消失 | `schema.image.toDOM` 用**模块级全局** `currentDocPath` 解析相对路径，而 App 层「设路径」与「投内容」都是 React 状态：**子组件 effect 先于父组件执行**，切标签时解析用的还是上一个文档的目录。改为解析内容前按 `filePath` 同步一次（文件切换 effect + 首次挂载各一处），App 层切标签再兜一层 |
| 任务复选框与文字不对齐 | 段间距规则给任务项首段也加了 0.8em 上边距，而复选框只有硬编码 `margin-top:5px`——实测偏高 13~14px。首段上边距归零 + 复选框改自绘并按「行高 × 字号」算首行盒中线（实测偏差 0.4px） |
| 代码块末尾按 `→` 走不出去 | 两层原因：① 块级选中里的 `preventDefault()` 吃掉了浏览器「点击 contenteditable 自动聚焦」，`activeElement` 停在 `BODY`，**之后所有按键都到不了编辑器**（`Delete` 删块同样受影响）→ 块级选中后显式 `view.focus()`；② 新增 `ArrowRight` 命令：整块选中、或光标已在块内容末尾时退出到下一个块，末块则新建空段落并把光标放进去（单事务可撤销） |
| 阅读模式文字凭空多出空行 | 阅读模式回车走的是 `splitBlock`（新建段落），序列化后端每行之间多一个空行，而阅读模式视觉上只是普通行距 → 三模式观感不一致。改为**普通段落内回车 = 段内换行**（`hard_break`，源码两空格硬换行、无空行） |
| 设置窗口动画像"淡化消失" | 退场原本是「边移动边淡出」。改为**纯位移**滑出屏幕（去掉弹窗本体的透明度动画），明暗只由遮罩负责且延迟到弹窗滑走后；动画整体放慢（入 640ms / 出 520ms） |
| 格式刷图标不像刷子 | 旧图形是斜置的抽象笔刷，14px 下辨识度差；重绘为「带圆角端头的刷柄 + 刷箍 + 向下收拢的刷头」小油漆刷 |

## 四、已知范围

- **标题级别只到 H6**：Markdown 标准上限，H7/H8 无法在 Markdown 中往返，故菜单不提供（经确认）。
- **自动配对仍只对 Markdown 文件生效**（`.txt` 等非 Markdown 文件在编辑模式不配对），与 v0.12.0 及之前一致。
- 源代码模式（编辑/分屏）下无法"点击徽标改级别"——那里显示的就是 Markdown 原文，改级别仍靠输入 `#` 数量或格式栏按钮。
- **任务列表样式编码**：圆形用 `* [ ]`。同一份文档里方形与圆形**混用时**，部分第三方渲染器可能把两种列表符号视为两段相邻列表（渲染上有轻微断档），LightMD 内不受影响。
- **回车语义变更**：阅读模式普通段落内回车由"新建段落"改为"段内换行"（经确认）。需要新段落请按 `Shift+回车`。
- **排版预览不写设置**：拖动期间的值只存在于内存中的预览 store；关闭设置弹窗（未保存）不会保留。
- 尚未支持（详见 README 清单）：跨文件全文搜索、标签、frontmatter、双链/反链/图谱、书签、Git 集成、合并单元格等。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）等本地数据全部保留。
- 新增的三个「配对范围」开关默认全开，与旧版行为一致，无需手动配置。
- 若你此前习惯在标题左侧看到 `#` 井号：现在改为 `H1`/`H2`… 徽标，点击即可改级别；输入 `#` 数量改级别的方式未变。
- 阅读模式回车改为段内换行：需要新建段落请按 `Shift+回车`；列表 / 引用 / 标题内行为不变。
- 任务列表若需圆形图标：用格式栏「☑」下拉或阅读模式的 `::` 手柄切换（会写入 `* [ ] `），原方形任务项不受影响。
