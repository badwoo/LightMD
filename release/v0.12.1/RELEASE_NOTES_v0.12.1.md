## 二、版本内容

本版共 **4 项需求**（全部来自本轮反馈），其中 1 项为既有功能的整体重做。

### 2.1 需求 1 — 标题级别徽标（H1–H6）取代 `#` 井号

- 阅读模式标题左侧不再显示 `#`/`##` 语法井号，改为 `H1`/`H2`… 徽标（二级标题即 `H2`）
- 点击徽标展开 **H1–H6** 级别菜单，选中即改级别；菜单为 200ms 顺滑展开动效（`scaleY` + 位移 + 淡入，easeOutExpo 缓动），当前级别高亮并标出等价的 `#` 语法，尊重系统「减少动态效果」
- 改级别为**一次事务 = 一次撤销**，标题内容与锚点 `id` 保留
- 原「输入 `#` 数量改级别」的方式**完全保留**（inputrule 未改动）
- 徽标绝对定位、脱离文档流 → 光标进出标题仍**零位移**（延续 v0.12.0 修复）

> 范围说明：Markdown 标准只有 6 级标题（markdown-it 仅把 1~6 个 `#` 解析为标题，7 个 `#` 会被当作普通段落），故菜单只列 H1–H6，避免生成无法往返的语法。

### 2.2 需求 4 — 自动配对补全重做

新增唯一规则源 `core/autoPairRules.ts`（纯函数）+ textarea 规划器 `utils/sourceAutoPair.ts`，**阅读（ProseMirror）/ 编辑 / 分屏三模式共用同一套判定**：

| 能力 | 说明 |
|---|---|
| 补全配对 | `(` `[` `{`、`"` `'` `` ` ``、中文标点 `“ ” ‘ ’ （ ） 【 】 《 》 「 」` |
| 跳过输入 | 右侧已有同一闭符号时不重复插入，光标直接跳过（typeover） |
| 包围选区 | 选中文字后输入开符号 → 用配对符号包住，而不是替换内容（含多行选区） |
| 退格删一对 | 光标停在空配对中间按退格，两个符号一起删 |
| `Tab` 跳出 | 光标停在配对中间按 `Tab` 跳到闭符号右侧（不在配对中时仍走原有缩进/导航） |
| IME 提交后补全 | 组合输入期间不介入；中文标点上屏后补闭符号 |
| 撤销粒度 | 补全 = 一次编辑 = 一次撤销（PM 单事务 / textarea 单次 `execCommand`） |

**修复的既有缺陷**

| 缺陷 | 修复要点 |
|---|---|
| 词中间乱插配对 | `abc\|def` 中输入 `(` 只插单字符（右侧是单词字符不配对） |
| 右侧紧邻闭符号仍配对 | 输入 `(` 而右侧已是 `)` → 只插单字符 |
| 孤儿闭符号被"跳过" | 输入 `)` 而左侧无未闭合的 `(` → 只插单字符（轻量栈扫描判定） |
| 引号被补成 4 个 | 自配对引号（`"` `'` `` ` ``）右侧已有同一字符时只移动光标 |
| 英文撇号误配对 | `don't`、`it's` 不再补全 |
| 转义态误配对 | `\(` 不配对 |
| 行内公式漏判 | `$...$` 内不再配对（旧实现只挡了代码块/行内代码/块级公式） |
| 中文标点补全靠巧合 | 旧实现依赖输入法恰好派发单字符 `keydown`；现改为 `beforeinput` + `compositionend` 双路径，可靠生效 |

**新增设置**：设置 → 编辑器 →「配对范围」三个开关（括号 / 引号 / 中文标点），可只关引号而保留括号；总开关关闭时整组置灰。

### 2.3 需求 3 — 编辑模式滚动条移到最右

- 可滚动区域由「正文框」改为**整个编辑区**（滚动条贴最右），与阅读模式一致
- 正文位置**与旧版逐像素一致**（用真实 Chromium 在 1200 / 960 / 700px 三种宽度实测：正文列完全相同，仅滚动条位置改变）
- 分屏模式不受影响（其滚动条本就贴分栏右缘）

### 2.4 需求 2 — 文件夹展开动画再放慢 50%

- 子文件夹展开 0.675s → **1.013s**、收起 0.63s → **0.945s**
- JS 常量（容器高度过渡）与 CSS 关键帧同步修改，避免"容器到位、子节点还在飘"的错位

## 四、已知范围

- **标题级别只到 H6**：Markdown 标准上限，H7/H8 无法在 Markdown 中往返，故菜单不提供（经确认）。
- **自动配对仍只对 Markdown 文件生效**（`.txt` 等非 Markdown 文件在编辑模式不配对），与 v0.12.0 及之前一致。
- 源代码模式（编辑/分屏）下无法"点击徽标改级别"——那里显示的就是 Markdown 原文，改级别仍靠输入 `#` 数量或格式栏按钮。
- 尚未支持（详见 README 清单）：跨文件全文搜索、标签、frontmatter、双链/反链/图谱、书签、Git 集成、合并单元格等。

## 五、升级说明

- **直接覆盖安装即可**，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）等本地数据全部保留。
- 新增的三个「配对范围」开关默认全开，与旧版行为一致，无需手动配置。
- 若你此前习惯在标题左侧看到 `#` 井号：现在改为 `H1`/`H2`… 徽标，点击即可改级别；输入 `#` 数量改级别的方式未变。
