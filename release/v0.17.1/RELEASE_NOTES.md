## 二、版本内容

### 2.1 新增功能

- **源码编辑区升级为 CodeMirror 6** —— 语法高亮、行号、代码折叠、括号匹配、当前行高亮、
  矩形选择、多光标（`Ctrl+Alt+↑/↓`）、搜索命中高亮、长行软换行。
- **大文档编辑性能提升** —— 5MB 文档加载 19.3s → **3.3s**，输入延迟 274.1ms → **16.4ms**。
- **智能回车** —— 列表 / 任务项 / 引用内按 `Enter` 自动续出标记，有序列表编号递增；
  空列表项按 `Enter` 退出列表；行首 `Backspace` 一次删净标记。
- **代码块语言高亮** —— 围栏代码块按语言逐 token 上色，语言按需加载，不增加启动负担。
- **选中词高亮与多点同改** —— 双击选中词即高亮全文同词；`Ctrl+D` 逐处累加多光标，
  多处同时改写。
- **空文档占位与编辑辅助** —— 空白文档显示输入提示；拖动文本显示插入位置竖线；
  文末留白让每行都能滚到视口顶部（打字机模式末行可居中）。
- **导出保真** —— Word / LaTeX / ePub 导出接入统一文档模型，公式、图表、图片按排版输出。

### 2.2 问题修复

- **含 mermaid / 数学公式的文档进入编辑模式崩溃** —— 预览页面未就绪即写入内容的问题已修复。
- **反复切换阅读 / 编辑后阅读进度丢失** —— 分屏同步把程序自身的滚动误判为手动滚动，
  导致阅读位置被写回文档顶部；现已按写入值识别并忽略回声。
- **格式刷无法「去格式」** —— 选中无格式文本可正常作为来源，刷到有格式文本即清除其格式。
- **格式刷只能整段应用** —— 选中文本后只作用于该范围内的行内格式，行首前缀保持不变。
- **开关预览后左右两屏不对齐** —— 主动对齐不再受逐帧防抖限制，切换后立即对齐。
- **模式切换时原文被改写** —— 公式转义、Setext 标题、定义列表内代码块等保持原样。
- **重启后阅读进度被清零** —— 新增启动恢复保护，恢复完成前不写进度。
- **源码编辑切换初期的稳定性问题** —— 搜索框崩溃、撤销失效、逐字重建编辑器、Tab 焦点
  逃逸、占位提示不可见等均已修复。
- **大纲、列表与折叠等交互细节** —— 标题折叠计时、大纲滚动跟随、搜索高亮定位等已校正。

### 2.3 行为变更

- **超过 5MB 的文件仅支持编辑模式**（源码面）：大文件不再进入阅读 / 分屏，避免卡死。
- **折行时 `Home` 两段式**：先到视觉行首，再按一次到逻辑行首（与主流编辑器一致）。
- **格式刷的作用范围**：有选区时作用于选中文本的行内格式；无选区时沿用整段语义。

## 四、已知范围

- 源码面的配对增强手势（Tab 跳出配对 / 成对删除）尚未接入；Tab 缩进、撤销、专注模式正常。
- 打字机模式在源码面不生效（阅读与预览不受影响）。
- 多光标可建立、可输入，但格式化 / 替换 / AI 操作只作用于主选区。
- 超过 5MB 的文件仅支持编辑模式。
- 分屏对齐在视口外的行高为估算值，长段落软换行时可能有少量偏差。
- 两项紧凑列表的第二个空项按 `Enter` 变为松散列表而非退出（Markdown 编辑器通用语义）。

## 五、升级说明

- 直接覆盖安装即可，无破坏性变更；设置、快捷键、收藏、最近打开、会话（含未保存标签）、
  窗口大小、阅读进度等本地数据全部保留。
- 超过 5MB 的文件会以编辑模式打开，并提示不支持阅读 / 分屏预览。
- 源码编辑区已更换实现，折行时 `Home` 键行为与旧版略有差异（见「行为变更」）。
