## 二、缺陷修复（用户问题1）

### 含 mermaid / 数学公式的文档进编辑模式崩溃

- **现象**：打开含 mermaid 图 / LaTeX 公式的文档 → 双击 Ctrl 进编辑模式 →
  `TypeError: Cannot set properties of null (setting 'innerHTML')`。
- **根因**（实机逐帧采样定位，`scripts/v0171-lead-i1-cause.mjs`）：iframe 写入流程在
  `doc.close()` 后**立刻**提交 init 状态，造出「init 已更新、`body` 仍为 null」的窗口
  （解析器停在 `<head>` 等 mermaid/katex 脚本，body 最长 ~100ms 后才就绪）；窗口内
  effect 二次运行会走增量分支 → 对 `doc.body.innerHTML` 赋值 → 崩。
- **为什么只有 mermaid/公式的文档崩**：纯文本文档每次都走整篇重写分支（结构上
  进不了增量分支）；破坏性对照已验（纯文本文档 body===null 帧数 = 0）。
- **修法**：init 提交推迟到 body 真正就绪（窗口内二次运行自动回安全的整篇重写）；
  增量分支再加 body 守卫兜底。

## 三、CM6 能力适配第一批（P0 六项）

### 3.1 智能回车（A1）——本版用户价值最高的一项

源码面按 Enter 不再只是普通换行：

| 场景 | 旧行为 | 新行为 |
|---|---|---|
| 列表 / 任务项 / 引用行尾 Enter | 光标顶格，手动补 `- ` | 自动续出标记（`- ` / `- [ ] ` / `> `） |
| 有序列表 `3. xxx` Enter | 不续编号 | 自动 `4. ` 递增 |
| 空列表项 Enter | 残留空项 | 自动退出列表 |
| 行首 Backspace | 与上一行粘连、破坏结构 | 一次删净列表/引用标记（取消条目） |

- 任务项续行自动重置复选框（`- [x]` → 新项 `- [ ]`）。
- **撤销口径不变**：命令不装 CM6 `history()`，事务经统一时间线上报（typing），
  一次回车 = 一步撤销，跨模式撤销不回退。
- 键位优先级不回退：Slash 命令确认（Enter）走捕获监听、优先于智能回车；
  IME 组合中的 Enter 交输入法。
- 已知边界（CM6 官方语义）：两项紧凑列表的**第二个空项**按 Enter 是"插空行变
  松散列表"而非退出；三项及以上列表的空末项正常退出。行为已由测试锁定。

### 3.2 代码块内嵌语言高亮（A2）

围栏代码块（```` ```js ```` / ```` ```python ```` 等）按语言逐 token 上色
（此前整块只有一个颜色）。语言来自 `@codemirror/language-data` 注册表，
**按需懒加载**：未打开过的语言不进主包，加载完成自动重解析，不增加启动负担。

### 3.3 选中词即高亮 + Ctrl+D（C1 / C2）

- **选中词即高亮**：双击选中一个词，全文相同文本自动亮起（点别处即消失）。
  与搜索面板互补：面板管"主动检索/替换"，这个管"边读边看"。
- **Ctrl+D**：选中下一处相同文本，逐次累加多光标 → 多处同时改写
  （批量改名场景）。已过滤 defaultKeymap 中 emacs 习惯的 Ctrl-d（删字符），
  避免 Windows 上抢键。

### 3.4 空文档占位 / 拖拽落点 / 文末留白（E4 / E5 / E6）

- **占位提示**：空白文档显示「开始输入 Markdown…（/ 唤起命令）」，打字即消失。
- **拖拽落点光标**：拖动文本/文件时插入位置显示竖线，落点可视。
- **文末留白**：每行都可滚动到视口顶部 —— 打字机模式**末行居中**自此成立
  （此前文档最后一行永远贴底、居中失效）。滚动进度 100% 仍对应文档末行。

## 五、已知限制

- 多光标仍是"能建能打字，但格式化/替换/AI 只认主选区"的半开状态（v0.17.0 遗留，
  见 CM6 适配清单 I1），Ctrl+D 的多处同改覆盖"打字覆盖全部选区"场景；
  多点格式化待后续版本。
- 行内配对（Tab 跳出配对 / Backspace 成对删除）在 CM6 路径仍是 v0.17.0 已知
  缺口（TODO v0.18），本版未动。

- 空文档占位文案跟随**挂载时**界面语言，运行中切换语言不即时刷新（极低频组合）。
