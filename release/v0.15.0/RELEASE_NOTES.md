### 实施中发现并修复的真实缺陷（均为单测覆盖不到、由实机探针或审查发现）

1. **PDF 导出会让应用崩溃**（wry IPC）：初版用 `postMessage` 上报导出就绪，wry 的 IPC 处理器对 `file://` 源执行 `Uri::unwrap()`，在 `extern "system"` 边界不可 unwind → 进程直接 abort。改为 Rust 侧 `eval_with_callback` 轮询。
2. **跨文件撤销在切换文档时丢条目**：切标签调用 `begin(docKey, content)`，内容与时间线基线不一致时整条重置，跨文件替换条目被丢弃。改为"已有时间线则 rebase 保留、无历史才 begin"。
3. **搜索替换不进撤销栈**：替换提交前未对齐时间线基线，`commit` 静默拒绝。改为提交前按当前真实文本 rebase。
4. **撤销 bridge 双入栈风险**：阅读模式写回原为 `addToHistory:true`，与统一时间线会双记录 → 一次 Ctrl+Z 撤两步。改为 `false` + `historyBridge` 标记。
5. **撤销后立刻恢复永远失败**：跨文件护栏只比对 `after`，未按方向区分。改为方向敏感（undo 比 after / redo 比 before）。
6. **iframe 滚动映射坐标系多算 scrollTop**：等价于 `rect.top + 2*scrollTop`。已修正为 `rect.top + scrollTop`。
7. **阅读↔编辑锚点采集永不生效**：切换时阅读面已 `display:none`，几何全 0。改为滚动期缓存。
8. **工作区扩展名 whitespace 未清洗**：`" txt "` 清洗顺序错误导致匹配不到文件。已修（单测抓到）。
9. **i18n 双花括号违规**：指令模板变量是双花括号，不能进 `t()` 字典。改为模板正文放代码常量、界面文案用单花括号。
10. **`[[bin]]` 污染打包**：`pdf_smoke` 真机烟测被 tauri 当产品目标打包 → `failed to bundle project`。改为 `[[example]]` + features 门控。

## 四、安装与试用建议

1. **优先用 NSIS 安装包**（`LightMD_0.15.0_x64-setup.exe`），安装后覆盖旧版本即可；也可以直接双击 `lightmd.exe` 免安装试用。
2. 建议重点试这几个新功能：
   - **撤销统一**：在编辑模式改几个字 → 切到阅读模式 → 按 Ctrl+Z，应能撤回编辑模式的操作。
   - **AI 连接档案**：设置 → AI 连接 → 新增一个档案（本地 Ollama 可直接选预设；火山两个端点已预填 baseUrl 与协议，模型 ID 需按你的账户文档填）。
   - **PDF 导出**：导出 PDF 时应看不到 msedge/chrome 进程，页眉页脚不含临时文件 URL。
   - **工作区搜索**：Ctrl+F → 切到「工作区」→ 看进度、取消、点击结果跳转。
   - **标题折叠**：阅读模式点标题左侧的折叠三角；确认导出时内容仍完整。
   - **图片灯箱**：阅读模式点图片 → 滚轮缩放、拖拽、左右键切图、Esc 关闭。

## 五、已知取舍（诚实声明）

1. **工作区搜索不支持正则**（Rust regex 与 JS RegExp 语义不等价，首版明确拒绝而非静默降级）。
2. **撤销历史是会话内的**（不跨重启持久化），默认上限 200 步 / 32MB 每文档。
3. **表格合并仍用 `<td colspan/rowspan>` 行内 HTML 扩展**，非 GFM 标准（本版只加了提示，未改变存储格式）。
4. **AI 的 Anthropic 协议不做 `reasoning_effort` 映射**（无官方对应能力，UI 标"不适用"）；不做 400 后自动换参重试（避免重复计费）。
5. **PDF 导出的离屏窗口在特定多显示器/缩放配置下**理论上有被 Windows 钳回屏幕内的风险（本机未复现）；如遇白屏请反馈。
6. **阅读区折叠状态仅在会话内保留**（重启不恢复）。
