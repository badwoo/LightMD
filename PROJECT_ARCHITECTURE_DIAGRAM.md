### 5.1 双层代码块（CodeBlockView）

```
┌─────────────────────────────────────────┐
│           代码块渲染结构                  │
├─────────────────────────────────────────┤
│  ┌─────────────────────────────────┐   │
│  │  高亮层 (highlightLayer)         │   │  ← PrismJS 渲染（只读，用户可见）
│  │  ┌─────────────────────────┐    │   │
│  │  │  function greet() {     │    │   │
│  │  │    return "Hello";      │    │   │
│  │  │  }                      │    │   │
│  │  └─────────────────────────┘    │   │
│  └─────────────────────────────────┘   │
│  ┌─────────────────────────────────┐   │
│  │  编辑层 (contentDOM)             │   │  ← ProseMirror 管理（透明文本）
│  │  ┌─────────────────────────┐    │   │
│  │  │  function greet() {     │    │   │  ← color: transparent
│  │  │    return "Hello";      │    │   │  ← caret-color: auto
│  │  │  }                      │    │   │

```

├─────────────────────────────────────────┤

│                                         │

│                                         │
│  > 这是引用块（光标在此行）               │  ← 显示 ">"
│                                         │
│  ```javascript                          │  ← 显示 "```"
│  const x = 1;                           │
│  ```                                    │
│                                         │
└─────────────────────────────────────────┘
```

## 九、关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 桌面框架 | Tauri v2 | 安装包小(~5MB)、启动快、内存低、Rust安全 |
| 编辑器核心 | ProseMirror | 结构化文档、Transaction机制、可扩展插件系统 |
| Markdown解析 | markdown-it | 插件丰富、GFM支持、性能优秀 |
| 状态管理 | Zustand | 轻量、无样板代码、支持持久化 |
| 代码高亮 | PrismJS | 200+语言、主题丰富、双层渲染方案 |
| 数学公式 | KaTeX | 渲染快、支持行内/块级、编辑态实时预览 |
| 图表 | Mermaid 11 | 20+图表类型、工具栏内置模板 |
| 构建工具 | Vite | 快速HMR、Tree-shaking、TypeScript原生支持 |
| AI翻译 | OpenAI兼容API | 流式SSE响应、reqwest+rustls避免OpenSSL依赖 |
| API Key存储 | Windows凭据管理器 | 安全、系统集成、keyring库封装 |
