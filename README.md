# LightMD

> 一款轻量、高性能、所见即所得的 Windows Markdown 编辑器，基于 Tauri v2 + React + ProseMirror（阅读面）+ CodeMirror 6（源码面）构建。

**当前版本：v0.17.1**

中文 | [English](./README_EN.md) | [用户指南](./USER_GUIDE.md) | [更新历史](./CHANGELOG.md)

## 产品简介

LightMD 面向 Windows 平台，把 Markdown 的简洁与富文本编辑器的直观结合在一起：阅读时是排版好的文档，编辑时是源码与实时预览并排。安装包约 9MB，启动毫秒级，不依赖额外运行库。

- **两种模式**：阅读模式（所见即所得，光标所在行显示语法标记）与编辑模式（左源码 + 右实时预览）
- **一个文档一条时间线**：阅读、编辑、预览共用同一份撤销记录，跨模式撤销不失效
- **按内容对齐**：阅读 ↔ 编辑、源码 ↔ 预览均以内容锚点对齐，同一段落始终落在同一屏位置
- **本地优先**：文档、图片、快照全部保存在本机，不上传云端

## 界面与模式

- **阅读模式**：排版视图，标题、列表、表格、图表、公式按最终效果呈现；光标进入的行显示 Markdown 语法。
- **编辑模式**：左侧源码编辑区 + 右侧实时预览；预览可一键收起为纯源码，也可从编辑区右缘的竖条滑回。
- **模式切换**：双击 `Ctrl` 在阅读与编辑之间切换；双击 `Shift` 在编辑模式内开关右侧预览；标题栏与底部按钮同样可切换。
- **位置保持**：来回切换、关闭标签后重新打开、重启软件后，阅读位置都停留在原处。
- **分屏联动**：左右任一侧滚动，另一侧把对应内容对齐到视口顶部双向联动。

## 功能特性

### 编辑与输入

- **源码编辑区**：语法高亮、行号、代码折叠、括号匹配、当前行高亮、矩形选择、多光标、搜索命中高亮、长行软换行。
- **智能回车**：列表、任务项、引用内自动续出标记，有序列表编号递增，空列表项退出列表，行首 `Backspace` 一次删净标记。
- **代码块语言高亮**：围栏代码块按语言逐词上色，常用语言内置，其余按需加载。
- **选中与多点编辑**：双击选中词即高亮全文同词；`Ctrl+D` 逐处累加多光标，多处同时改写。
- **自动配对补全**：括号、引号、中文标点成对补全，支持包围选区、`Tab` 跳出、成对删除，可按类别分别开关。
- **打字即所得**：行内公式、块级公式、链接、图片、脚注、目录六类输入规则，输入即转换；Emoji 短码 `:smile:` 输入即补全。
- **Markdown 感知粘贴**：粘贴 Markdown 文本或网页富文本会自动还原为真实结构；粘贴 URL 自动生成链接。
- **格式刷**：单击应用一次、双击持续应用；可对选中文本做行内格式，也可把有格式刷成无格式。
- **块级操作**：代码块、公式、图表、表格、图片段落支持拖拽换位、块级复制剪切、一键删除，均以一次撤销为一步。
- **批量注释**：`Ctrl+/` 对选中多行或当前块添加注释，导出时自动剔除。
- **文档缩放**：`Ctrl+滚轮` 或右下角缩放尺，50%~200%，三种界面同步。

### 阅读与预览

- **标题折叠**：标题前折叠按钮收起该标题下全部内容，只影响显示，不改文件。
- **标题级别徽标**：点击 `H1`~`H6` 徽标直接改级别。
- **图片灯箱**：双击图片全屏查看，支持缩放、拖拽平移、前后切换。
- **大纲面板**：随文档实时同步，点击跳转，可折叠、可拖拽排序、悬停搜索。
- **文内跳转**：相对路径打开目标文档、`#锚点` 平滑滚动、外链交给系统浏览器。
- **排版设置**：内容宽度、行高、段间距、字号、字体即时生效。

### 富文本与插入

- **表格**：可视化增删行列、列宽行高拖拽、整列对齐、单元格合并与拆分；调整后的尺寸随文档保存。
- **图片**：粘贴、从文件插入、拖入即插入；支持替代文本、宽度、左中右对齐；图片管理面板可转换内联 / 文件形态、重命名同步引用、清理未引用文件。
- **Mermaid**：20+ 种图表，工具栏内置常用模板一键插入。
- **数学公式**：行内 `$...$` 与块级 `$$...$$`，编辑态实时预览。
- **代码块**：语言下拉切换、一键复制、无语言标注时自动识别。
- **其他语法**：任务列表、高亮、上下标、脚注、定义列表、自动目录 `[toc]`、锚点链接、Emoji。

### 文件与工作区

- **标签页**：多标签、固定标签、右键菜单（重命名 / 打印 / 另存为 / 关闭其他等）；临时文档不立即写盘。
- **文件树**：同时打开多个文件夹，独立浏览区域；新建、重命名、删除（进回收站）、拖拽复制 / 移动、同目录排序、外部改动实时同步。
- **快速切换**：`Ctrl+P` 按已打开标签、最近文件、工作区文件分组模糊匹配。
- **收藏与最近**：收藏常驻侧栏，支持多选批量添加；最近打开记录文件与文件夹。
- **多窗口**：最多 8 个对等窗口，各自独立标签与状态；支持在新窗口打开、拖拽合并、会话恢复、文件冲突检测。
- **启动恢复**：自动恢复上次打开的标签、文件夹与阅读位置。

### 搜索

- **当前文档**：`Ctrl+F` / `Ctrl+H` 浮动搜索，支持全词匹配、匹配大小写、选取范围内、正则与 `$1` 捕获组。
- **所有打开文件**：结果条幅按文件分组列出命中行，可一键全部替换，替换结果可撤销。
- **工作区全文搜索**：搜索所有已打开文件夹的正文，流式返回结果并可取消，点击命中直达位置。

### 导出与打印

- **HTML**：自包含样式，公式与图表随文件渲染，离线可打开。
- **PDF**：应用内直接打印，无需安装外部浏览器，页眉页脚逐页齐全。
- **PNG**：整篇文档导出为长图，公式与图表按矢量渲染。
- **Word / ePub / LaTeX**：公式、图表、图片按排版输出，ePub 按标题拆分章节。
- **打印**：按当前文档样式直接打印。

### AI 功能

- **翻译**：选中翻译与全文翻译，支持直接替换或双语对照，流式展示、可取消、可一键恢复原文。
- **助手**：续写、润色、摘要、对话四类任务；选区旁浮动按钮，对话窗支持多轮与快捷指令。
- **连接配置**：独立连接档案，支持 OpenAI 兼容与 Anthropic 协议、Ollama 等本地部署；模型列表可动态获取，上下文与输出预算可配。
- **指令库**：自定义指令支持 `{{selection}}` / `{{document}}` 变量。
- **密钥安全**：API Key 存入 Windows 凭据管理器，按厂商 / 档案独立存储。

### 外观与效率

- **主题**：6 套主题一键循环（`Ctrl+Shift+T`）。
- **专注模式**（`F8`）与**打字机模式**（`F9`），三种界面通用。
- **沉浸式全屏**（`F11`）：自动收起四周栏，只留文档。
- **自定义快捷键**：按分类改键，冲突提示、单项恢复、一键恢复默认，多窗口实时同步。
- **检查更新**：设置面板末尾可检查、下载并安装新版本。

### 数据安全

- **自动保存**：写盘前先读盘比对，磁盘被其他程序改动时放弃写盘并提示。
- **外部修改处理**：可选仅提示 / 三选一（取最新、保留本地、另存为）/ 每次询问。
- **撤销独立**：撤销 / 重做严格按当前文档独立，不跨文档乱撤。
- **版本快照**：保存时自动记录最多 5 个历史版本，可差异对比与一键恢复。
- **回收站**：删除文件进入系统回收站，误删可还原。

## 已知限制

- 源码面的配对增强手势（`Tab` 跳出配对、成对删除）尚未接入；`Tab` 缩进、撤销、专注模式正常。
- 打字机模式在源码面不生效；阅读与预览正常。
- 多光标可建立、可输入，但格式化、替换与 AI 操作只作用于主选区。
- 超过 5MB 的文件仅支持编辑模式（源码面）。
- 分屏对齐在视口外的行高为估算值，长段落软换行时可能有少量偏差。
- 工作区全文搜索为只读，不支持全库替换；不解析双链、标签与 frontmatter。
- 未支持：标签系统、双链 / 反向链接、关系图谱、插件系统、Git 集成、批量导出文件夹。

## 安装

### Windows

前往 [Releases](../../releases) 页面下载对应版本：

- **`LightMD_0.17.1_x64-setup.exe`** — 安装包，免管理员权限，推荐
- **`LightMD_0.17.1_x64_en-US.msi`** — MSI 安装包，适合企业分发
- **`lightmd.exe`** — 免安装单文件，下载后可直接运行

### 系统要求

- Windows 10 / 11（64 位）
- 无需安装额外运行库

## 快速上手

1. 下载并安装 LightMD
2. 新建或打开 Markdown 文件
3. 在阅读模式阅读，双击 `Ctrl` 进入编辑模式
4. 行首输入 `/` 唤起快捷插入菜单（标题、列表、代码块、表格、图表、公式等）
5. `F8` 专注写作，`F9` 打字机模式，`F11` 全屏
6. 详细用法见 [用户指南](./USER_GUIDE.md)

## 从源码构建

```bash
git clone https://github.com/badwoo/LightMD.git
cd LightMD
npm install
npm run tauri dev      # 开发模式
npm run tauri build    # 打包发布版本
```

打包产物位于 `src-tauri/target/release/bundle/`。
