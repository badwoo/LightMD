# LightMD

> 一款**轻量级**、**高性能**、**所见即所得**的 Windows Markdown 编辑器，基于 Tauri v2 + React + ProseMirror 构建。

**当前版本：v0.7.5**

中文 | [English](./README_EN.md) | [用户指南](./USER_GUIDE.md)

## ✨ 为什么选择 LightMD？

LightMD 是一款**专为 Windows 平台**打造的轻量级 Markdown 编辑器，融合了传统 Markdown 的简洁和现代 WYSIWYG 编辑器的直观。安装包仅 **~5MB**，启动毫秒级，深度集成 Windows 桌面体验。

## 🎯 核心特性

### 📝 三种编辑模式

- **阅读模式** — 所见即所得，光标所在行显示 Markdown 语法标记
- **源码模式** — 纯文本编辑，配合工具栏快捷插入语法
- **分屏模式** — 左右同步滚动，编辑与预览实时联动

### 📊 富文本支持

- ✅ 标准 Markdown（标题、列表、引用、代码块、表格、链接、图片）
- ✅ **GFM 任务列表**（`- [x]` / `- [ ]`）
- ✅ **Mermaid 图表**（流程图、时序图、甘特图、类图、状态图等 20+ 种，工具栏内置 7 种模板一键插入）
- ✅ **KaTeX 数学公式**（行内 `$...$` 与块级 `$$...$$`；块级公式编辑态实时预览，0.5.0 新增）
- ✅ **代码语法高亮**（PrismJS，200+ 语言，0.2.0 新增 PHP/Swift/Kotlin/Dart/Lua/Ruby/R/Scala/Perl/PowerShell；0.5.0 新增无语言标注代码块自动识别语言）
- ✅ **高亮标记** `==文本==`（0.2.0 新增）
- ✅ **上标 / 下标** `^文本^` / `~文本~`（0.2.0 新增）
- ✅ **Emoji 表情** `:smile:` 自动补全（0.2.0 新增）
- ✅ **脚注** `[^1]` + `[^1]: 说明`（0.2.0 新增）
- ✅ **定义列表** `术语\n: 定义`（0.2.0 新增）
- ✅ **自动目录** `[toc]` 或 `[[toc]]`（0.2.0 新增）
- ✅ **锚点链接** — 标题自动生成 id，支持 `[链接](#标题)` 跳转（0.2.0 新增）

### ✨ AI 翻译

- **选中翻译 / 全文翻译** — 选中文字右键或点击「翻译」按钮进行局部翻译；无选区时默认全文翻译（`Shift+F6` 或悬浮按钮/命令面板触发）
- **结果模式** — 支持「直接替换」与「双语对照」两种回写方式
- **翻译气泡** — 流式翻译结果展示，支持取消（`Esc`）与一键恢复原文（0.6.1 新增）
- **效率优化** — 纯符号/URL/邮箱/纯图片段落自动跳过；链接、行内代码、图片以占位符整体保护，不被误译（0.6.2/0.6.4/0.6.5）；全文翻译 3 路并发提速（0.7.3）

### 🤖 AI 助手与 AI 对话

- **选区 AI 气泡** — 选中文本后浮动 [译][续][润][摘][问] 一排小气泡（0.7.4 新增，0.7.5 扩展）：续写（光标处 ghost 预览，`Tab` 采纳 / `Esc` 放弃）、润色（替换选中）、摘要（可拖拽浮窗）、对话

## 🚀 快速上手

1. **下载并安装** LightMD
2. **新建 / 打开** Markdown 文件
3. 开始书写 — 在光标所在行直接输入 Markdown 语法
4. 行首输入 `/` 唤起 **Slash 命令**，快速插入标题/列表/代码块/表格/Mermaid 图表等

#### v0.7.5 细节优化（同日追加）

**1. 修复按 Esc 关闭 AI 气泡/对话窗后文档跳回开头**
- 根因：气泡的 Esc 处理在 `window` 捕获阶段 `stopPropagation()`，编辑器 DOM 的**捕获 keydown 收不到该键**，但 keyup 不受影响仍到达编辑器；滚动跟随逻辑因此拿"上一次按键"遗留的 `savedScrollTop / savedCursorY` 计算，命中分支后把 `scrollTop` 恢复成旧值 —— 上一次按键若在文档开头附近，文档就跳回开头（是否需要跳取决于上次按键位置与当前滚动位置的差值，故表现为"有概率"）
- 修复：新增 `ScrollKeyBaseline`（keydown 记录 / keyup 消费），**只有见过配套 keydown 的 keyup 才允许进入滚动跟随**；焦点离开编辑器时作废基线；阅读模式（ProseMirror）与源码模式（textarea）打字机滚动同步修复

**2. 气泡颜色同步到底部栏 AI 按钮**
- 续 / 润 / 摘 / AI对话 四个抽屉按钮按任务注入 `--ai-entry-color`（取自对应气泡颜色），鼠标悬停与按下时以该色高亮；未设色时回退主题 accent，外观与旧版一致

**3. AI 续写立即给出反馈**
- 点击续写后**立即**在光标处渲染灰色占位 ghost「续写中...」（带呼吸动画），首个增量到达即替换为真实内容
